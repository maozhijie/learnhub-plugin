本节点：等差数列求和（基础）
正文三节要点（AI 追问与反馈只对照这些，不超纲）：
  • s1 概念：等差数列 = 任意相邻两项之差恒定（公差 d）；首项 a₁、末项 aₙ、项数 n。
  • s2 推导：求和 Sₙ = (a₁+aₙ)×n÷2 —— 倒序相加，每一对（首+末、次首+次末…）和相等，共 n 对，每对出现两次故 ÷2。
  • s3 应用：末项 aₙ = a₁ + (n−1)d；已知 a₁、d、n 先求 aₙ 再套求和。

实现形态（原型假设）：面板输入框（打字）或语音转文字；上下文包 = 该节点正文要点 + 图位置 + 本次讲稿，走既有 discuss 宿主通道。此处演示以打字讲稿进行。

这轮想看的：AI 是不是在「真不懂」地追问（protégé effect 的机制 = 被要求讲清楚逼出检索与重组），而不是夸「讲得不错」。上面两版里，追问逼出了 n−1 与 ÷2 的配对来源——这正是学习者原讲稿里含糊/跳跃/说错的地方。

讲解告一段落：给「哪里含糊 / 哪里跳了 / 哪里说错」的定位，不是打分
【A 版讲稿的定位反馈（对照 s1–s3 要点）】
含糊「差一样的数列」→ 精确说是「任意相邻两项之差恒定」；你也用反例自纠了 3,6,12，很好，把这句话补进你的讲稿。 跳跃你提到求和「倒过来加」，但没说出「第二项比 a₁ 多 d、倒数第二项比 aₙ 少 d → 每对和都等于 a₁+aₙ」这一步——追问后半段你自己补上了，值得留一句在讲稿里。 说错末项公式中途说成「乘项数」→ 应是 a₁+(n−1)d（到第 1 个不加，到第 n 个加 n−1 次）。你已改对。 总评（非评分）：这版讲稿缺的正是求和公式「÷2」的为什么；把它讲清楚，这节才算真的归你。
【B 版讲稿的定位反馈（对照 s1–s3 要点）】
说错末项公式写成了「首项+项数×公差」→ 应为 a₁+(n−1)d；以 3 开头公差 2 数到第 5 个是 11（=3+4×2）可自验。 跳跃求和公式你只报了结论；没讲「为什么 ÷2」。建议补一句：倒序相加，每对和都等于 a₁+aₙ、n 个配 n 对但每对算两次。 这版讲稿「背公式」味很重——公式没错但原理是空的；原理不讲，换个样子你就认不出了。

反馈原则（#33 边界内）：给对/错/部分对 + 定位 + 「可怎么补」，不判分、不入账；判词存档进 E1 档案。

STEP 4 · 存档为 E1 自注卡
「把这版讲稿存成我的卡」——看存档这步顺不顺手
等差数列：相邻两项差恒定，这个差叫公差 d。末项 aₙ = a₁+(n−1)d（到第 1 个不加，到第 n 个加 n−1 次）。求和 Sₙ=(a₁+aₙ)×n÷2：把数列倒序写一遍，每一对（第 i 个 + 倒数第 i 个）的和都等于 a₁+aₙ，因为一头多 d、一头少 d 抵消了；n 个数配成 n 对，但每对算了两次所以 ÷2。像 1,3,5,7,9 首加末=10，5 对=50，÷2=25。
末项公式：a₁+(n−1)d——到第 1 个不加公差，到第 n 个要加 n−1 次，别背错成 n 次。求和：倒序相加每对都是 a₁+aₙ，n 对但每对算两次所以 ÷2。我的口头禅：忘记公式就从 1,3,5,7 数一遍。
