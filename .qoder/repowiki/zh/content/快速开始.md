## 简介
LearnHub 学习中心插件为 DeepSeek Harness（dsh）提供“学习引擎 + Web 面板 + Agent 工具”的一体化能力。通过一次构建与简单配置，即可在 dsh 宿主中启用学习中心，完成课程生成、题目练习、复习调度、图谱分析与可视化等核心功能。

## 环境要求
- Node.js：>= 22（由包元数据强制约束）
- npm：用于安装依赖与执行脚本
- dsh 宿主：用于加载插件与提供 webServer/llm/tools 扩展点
- Obsidian Vault：作为事实源，插件在其下维护“学习中心”数据

## 安装与构建
1) 克隆仓库并安装依赖
- 在项目根目录执行：
  - npm install
- 说明：prepare 钩子会尝试从 dsh monorepo 链接 peer 依赖；若未找到，请确保 DSH_MONOREPO 指向正确的 dsh 仓库路径或按 README 的说明准备环境。

2) 构建产物
- 执行：npm run build
- 产出说明：
  - lib/index.js：服务端 ESM（插件主入口，注册工具面与 HTTP 路由）
  - lib/engine.js：独立引擎产物（供脚本与 UI 复用）
  - lib/client.js：客户端侧边栏入口（CJS，由宿主模块系统加载）
  - web/dist：Vite 构建的面板 SPA 静态资源
  - web/vendor：交互件所需 vendored 库（katex/three）
  - skills/*：技能随构建同步到 <dshHome>/skills/（DSH_HOME 可覆盖 home）

3) 校验构建
- 执行：npm run check
- 作用：对 lib/index.js 与 lib/client.js 进行语法检查

## 基本配置
插件本身不硬编码机器路径，所有机器差异通过 cordis patch 注入。

- 在机器的 profile patch（~/.dsh/profiles/web/cordis.patch.yml）中为 id: dsh-learnhub 行追加 config：
  - vault：必填，vault 根目录绝对路径
  - centerRel：可选，学习中心相对 vault 的路径（默认“学习中心”）
  - provider/model：AI 生成/判卷的模型提供者与模型名
  - fastEffort/deepEffort：控制不同场景的思考档（off/low），影响速度与质量权衡
  - quizAuditRate：出题第二意见门抽样率（0–1），0 表示关闭
  - corpusDir：生成语料落盘目录覆盖（默认写入本 vault 的 state/生成语料）

- bundle 层自动插入 time-context 与 schedule 能力，使会话具备定时提醒与时区上下文。

注意：
- 首次启动时，若学习中心目录不存在，会直接报错（fail loud）。
- 全新 vault 会在首次启动时写入 schema 版本信息，避免重复迁移。

## 开发环境搭建
目标：在不启动完整 dsh web 的情况下，用本地服务器直调引擎，浏览器走查面板与 API。

步骤：
1) 先构建项目
- npm run build
- 确保 web/dist 与 web/vendor 已生成

2) 启动开发服务器
- 命令：node scripts/dev-server.mjs <vault> [port]
- 参数：
  - <vault>：vault 根目录（引擎在其下查找“学习中心”）
  - [port]：端口号，默认 3210

3) 访问面板
- 浏览器打开：http://localhost:<port>/learnhub
- 说明：dev-server 仅实现部分只读/写接口；涉及 AI 判卷与生成的接口不可用（无模型 seam）

4) 前端独立开发（可选）
- 进入 ui 目录：cd ui
- 安装依赖：npm install
- 启动 Vite 开发服务器：npm run dev
- 构建产物输出至 ../web/dist（与 host 同构）

提示：
- 若 node_modules 缺失，构建脚本会自动补装 ui 依赖。
- Windows 工作副本 CRLF 会被统一为 LF，避免 whitespace 门禁失败。

## 运行学习任务和查看面板
- 将插件以 link 方式加入 dsh profile，并重启宿主后，可在 dsh 中使用 learnhub_* 工具与 /learnhub 面板。
- 常用入口：
  - 面板：/learnhub（今日/课程/洞察/项目/实践区）
  - 工具：learnhub_status、recommend、lesson、rebuild、question_*、generate 等
- 基本流程：
  - 使用 generate 触发“大纲 → 逐节正文 → 自动出题”三段管线
  - 在“今日”页签查看推荐与复习队列，进入节点学习视图进行练习
  - 在“课程”页签查看生成队列与提案收件箱
  - 在“洞察”页签查看记忆健康、XP 时间账本与运行环境

注意：
- 面板与服务端同源，资产带永久缓存，index.html 不缓存。
- 交互件通过 /learnhub/api/vendor/* 获取 katex/three，满足沙箱 CSP。

## 常见问题排查
- 无法加载插件或报 Cannot find package '@deepseek-ai/dsh-llm'
  - 原因：peer 依赖未链接
  - 处理：确保 DSH_MONOREPO 指向 dsh 仓库，或按 README 说明准备环境；重新 npm install

- 启动时报 config.vault 缺失或目录不存在
  - 原因：未在 profile patch 中配置 vault，或路径错误
  - 处理：在 ~/.dsh/profiles/web/cordis.patch.yml 中为 dsh-learnhub 添加 config.vault，并确保目录存在

- 面板 404 或资源加载失败
  - 原因：未构建或构建产物缺失
  - 处理：执行 npm run build，确认 web/dist 与 web/vendor 存在

- dev-server 某些 POST 接口不可用
  - 原因：开发服务器无模型 seam，AI 相关接口受限
  - 处理：使用完整 dsh web 环境或使用冒烟/e2e 脚本验证

- 构建时报 vendor 源缺失
  - 原因：ui/node_modules 未安装或文件不完整
  - 处理：进入 ui 目录执行 npm install，再回到根目录执行 npm run build

- 技能未生效
  - 原因：未同步到 <dshHome>/skills
  - 处理：执行 npm run build 同步技能；可通过设置 DSH_HOME 指定 home

## 性能优化建议
- 调整思考档
  - fastEffort：大纲/节正文初跑默认 off，可提速；当路由不支持该档位时自动降级
  - deepEffort：高复杂度节点的大纲与修复轮默认 low，可按需调整为 off 进一步提速
- 控制出题审计
  - quizAuditRate：降低抽样率可减少二次意见调用，提升生成速度
- 减少不必要的网络请求
  - 面板资产带永久缓存，确保使用构建产物而非源码
- 合理管理生成任务
  - 关注生成队列与任务状态，避免并发过高导致负载过大
