- 路由采用纯 hash 方案：`parseHash`/`navigate`/`navigateCourse`/`syncHash`/`onRouteChange` 集中管理，视图键（ViewKey）作为保活与轮询门的唯一口径。
- API 客户端统一通过 `api.ts` 中的 `http<T>(method, path, body)` 发起请求，错误包装为 `ApiError`，响应类型一律从 `types.ts` 的 `CommandOutput<id>` 或宿主模块返回值派生，禁止手工镜像引擎 schema。
- 页面按区（today/courses/insight/projects/practice）分目录组织，`ZoneBody` 依据 VIEW_KEYS 集合懒渲染已访问页面，未激活页面保留 DOM 仅隐藏以实现状态保活。
- 全局共享态通过 `AppFrame` 接口自顶向下注入，子组件不直接持有 status/tree/course 等原始状态，而是消费 frame 提供的 goto/openCourse/openLesson 等动作方法。
- 常量型枚举（ZONE_KEYS、COURSE_SUBS、WORKBENCH_SUBS、VIEW_KEYS）集中声明于 `lib/router.ts` 并以 readonly const 数组形式导出，配合 as const 保证类型安全。
- 组件样式通过 CSS 类名组合（如 `zone-view zone-view-active`、`app-shell app-fatal`）区分状态，主题色与 token 集中在 `tokens.css`，Arco 主题通过 `arco-theme` 属性切换 light/dark。
