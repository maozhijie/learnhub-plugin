本模块为纯文档仓库，按用途划分为四个子目录：
- `adr/`：编号递增的架构决策记录（0001–0078），每个文件对应一次架构裁决或工程妥协，被 `docs/agents/architecture.md` 引用的 R1–R7 分层规则、G1–G9 架构门、命令注册表八道门等强制约束所引用。
- `agents/`：面向 Agent 的工作章程，包含 architecture、domain、issue-tracker、parallel-sessions、triage-labels，定义 Agent 如何解读并执行上述规则族。
- `design/`：面向未来的设计规格（如 learning-expansion、project-artifact-design），与 ADR 形成「已裁决 vs 待实现」的分野。
- `research/`：研究语料与实验产出，含 quality-corpus、quality-review-*、spike-* 等带时间戳的 JSON/Markdown 快照，以及 vault-audit、industry-scan 等背景调研。
依赖方向单向：`agents/architecture.md` 引用 ADR 作为裁决来源；`design/` 与 `research/` 不反向引用代码，仅作为人类可读证据留存。
