`scripts/link-peers.mjs` 由 npm `prepare` 钩子自动执行，需先 `npx @deepseek-ai/dsh --version` 让 npx 缓存就绪，或通过 `DSH_MONOREPO` 环境变量指向 monorepo 源；`scripts/dev-server.mjs <vault> [port]` 启动本地开发服务（默认端口 3210），需预先 `npm run build` 产出 `web/dist`；`scripts/export-db.mjs <vault>` 将旧 `state/learnhub.db` 的 journal/practice 表追加写入 `state/*.jsonl`。
