本模块为扁平的 CLI 脚本目录，每个 `.mjs`/`.mts` 文件即一个独立可执行入口，通过 `process.argv` 解析参数并直接调用 `../lib/engine.js` 暴露的 `LearnhubEngine` API 或 Node 内置模块完成工作。内部按职责自然分组：
- 质量门禁：`scan-types.mjs` + `arch-baseline.mjs`/`arch-baseline.json` 构成「tsc 逐文件错误统计 → 基线棘轮比对」的门控链路；`scan-undefined.mjs` 委托 `undefined-scan.mjs` 做运行时未定义标识符探测。
- 静态扫描族：`scan-deps-face.mjs`、`scan-host-state.mjs`、`scan-invariant.mjs`、`scan-ui-types.mjs`、`scan-write-unit.mjs`、`scan-budget.mjs`、`scan-adapter-face.mjs` 各自针对依赖面、宿主状态、不变量、UI 类型、单元测试覆盖、预算、适配器接口等维度进行静态检查。
- 数据迁移与导出：`migrate-v1.mjs`、`migrate-v2.mjs`、`export-db.mjs`、`ensure-notes.mjs` 负责旧 SQLite/JSONL 数据格式转换与注入。
- 运行期验证：`smoke.mjs`/`e2e.mjs`/`smoke-panel.mjs` 以真实 vault 驱动引擎读路径；`dev-server.mjs` 用原生 `http` 模块搭建本地开发服务，将 `web/dist` SPA 与 `/learnhub/api/*` 路由桥接到 `LearnhubEngine`。
- 辅助工具：`link-peers.mjs` 在 `npm install` prepare 钩子中把 `@deepseek-ai/dsh-llm`、`dsh-tools` 软链进 `node_modules`；`prompt-bump.mts`、`gen-smoke.mjs`、`spike*.mts`、`quality-review.mjs`、`bank-corpus-extract.mts`、`diversity-baseline.mts` 等用于提示词版本管理、样本生成、质量评审与语料提取。
依赖方向单向向外：脚本 → `lib/engine.js` / Node 标准库 / 第三方 CLI，脚本之间不互相 import（除 `scan-undefined.mjs` 委托 `undefined-scan.mjs`），保持各命令可独立运行。
