模块以 `src/main.tsx` 为入口，使用 Arco Design 的 ConfigProvider 包裹全局中文语言包后挂载 App；`App.tsx` 作为根组件维护全局状态（status/tree/course/lesson/focusNode/focusJob），负责初始加载、主题切换、无课程守卫以及将状态封装为 `AppFrame` 向下注入。

路由层位于 `src/lib/router.ts`，采用纯 hash 路由：`parseHash`/`navigate`/`navigateCourse`/`syncHash`/`onRouteChange` 构成零 DOM 解析核与 window 薄绑定，视图键（ViewKey）是保活与轮询门的统一口径；`ZoneBody.tsx` 根据已访问过的 ViewKey 集合渲染对应页面，实现「首访后常驻、非激活隐藏」的保活策略。

页面按区组织在 `src/pages/`：TodayPage、CoursesPage（含 GeneratePage/ProposalsPage）、WorkbenchPage（graph/coach/queue/proposals/bank 五栏）、InsightPage、ProjectsPage、PracticePage，每个页目录内再拆分子组件。

UI 原子组件集中在 `src/components/`（如 CoachCockpit、QuestionCard、GraphDagView、TutorDrawer 等），并通过 `widget-bus.tsx` 进行跨组件事件广播；`hooks/` 提供 useCommand、useGenJobActions、usePolling 等共享行为；`lib/` 除 router 外还包含 md-chain、quiz-rules、rec-events、rounds、settle-context、svg-uri 等纯函数工具。

数据层由 `src/api.ts` 统一封装，所有请求走 `/learnhub/api/*`，返回类型通过 `types.ts` 从引擎命令注册表 `CommandOutput<id>` 派生，避免手工镜像；`active-tab.ts` 暴露当前活跃视图键供各页面轮询门判断是否取数。构建产物输出到 `../web/dist`，由宿主 dsh 以相对路径 `base: './'` 伺服。
