根目录是 dsh-learnhub 插件的发布边界：`package.json` 通过 `main`/`exports` 暴露三个入口——服务端 `lib/index.js`（Cordis 插件：工具 + /learnhub HTTP 路由）、客户端 `lib/client.js`（宿主模块系统加载的 CJS 单文件）与独立引擎 `lib/engine.js`；`build.mjs` 串联 ui/Vite SPA 构建、vendor 资源拷贝、ESBuild 三产物编译、空白行清洗与 skills 同步到 DSH_HOME，是所有子模块产物的唯一装配点。子模块职责由该装配契约划定：`ui/` 仅产出静态 SPA 并通过 `/learnhub/api` 与 `src/` 下的引擎通信；`scripts/` 提供跨子模块共享的类型门、扫描、迁移、冒烟测试与 peer 链接命令；`tests/` 基于 Node `node:test` 对引擎、宿主路由、UI 组件与架构门进行回归；`docs/` 集中 ADR 与 Agent 章程，被 `scripts/` 的门与 `AGENTS.md` 的提示词纪律引用；`preset_skills/` 定义 Cordis preset 组合与 SKILL 规范，随构建同步到宿主 skills 目录供所有 dsh 会话消费。运行时依赖通过 `peerDependencies` 声明并以 `link:` 注入宿主 profile，使本插件与宿主私有包在同一 node_modules 解析域工作；`cordis.patch.yml` 在宿主启动时注入 vault/provider/model 等机器级配置。
