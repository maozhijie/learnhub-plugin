# 终点纯标记化与完成判据折叠

ADR-0033 把课程唯一的结构承诺收缩进终点锚，但终点节点一直被当「最后一个课程节点」对待：种子提示词把起点资格判据（单一行为单元）泛化到一切节点名（硬约束 7），完成判据读终点自身 mastery（`foldCompletion`），ADR-0055 生成门更进一步裁决「终点照常被学」。三者合谋出系统性窄化：多面向的宽目标没有单一节点能承接，模型只能静默压缩——实机证据（「数学」课建课种子，2026-09-13）：四面向目标（软件开发/游戏开发支撑 + 机器学习常识 + 物理/金融等学科基础）被压成「把软件或游戏里的一个真实问题写成数学问题，并算出可检验的答案」，三个面向在提案里不留痕迹；而终点出生宽度是唯一承诺时机（扩承诺走 reseed，ADR-0055），出生即窄、兑现即偏。

理由：宽与窄的张力不在措辞在结构——承诺句要宽（覆盖目标全部主要面向），台阶要窄（每级可教可考），两者不该由同一个名字同时承担。一旦完成判据不再读终点自身 mastery，终点就没有理由继续当课程节点：正文、题库、调度、推荐、mastery 全部失去对象，终点还原为它本来的身份——锚所锚定的图上位置、教练改扎与收尾裁决的靶标。可教可考性整体下放到终点的 pre 集（最后台阶），「承诺宽、台阶窄」由改扎机制（ADR-0055 方向不变式）统一；教练的收尾裁决（「既有节点已兑现承诺」）成为承诺与台阶之间唯一的语义桥梁，故必须落成结构事实而非罗盘散文。

关键裁决：

- **终点纯标记。** 终点节点零正文、零题库、零调度、零推荐：生成门对终点恒拒（不看就绪，修订 ADR-0055 生成门「就绪解锁、终点照常被学」原案），学习者就绪清单与推荐剔终点，教练就绪存量照剔。终点在图上只剩结构职责——改扎靶标与闭包健康的收敛点。锚保护范围不变。
- **完成判据折叠自最后台阶。** `foldCompletion` 的 mastery 读数从终点节点改为终点.pre 集（全部 ≥ 阈值）；能力锚定另要求闭包健康（不动）、覆盖锚定另要求工作表核销（不动）；两种目标类型都以已收尾为前提。
- **收尾事实 sealed 进锚。** 收尾接线批（ADR-0055 裁决③）apply 时往锚写收尾宣告（iso 日期），教练再开含 add_node 的主线接线批时清除——「教练认定承诺已兑现」从罗盘散文升级为结构事实；锚读取放行可选字段，旧锚（无字段）照读不炸。收尾后最后台阶 mastery 达标即完成，无需教练再出手。
- **种子提示词 v3：终点资格与起点资格分家。** 终点是承诺句不是台阶句（不直接教不直接考）；面向覆盖或显式取舍——目标主要面向逐一点名进终点句，无法同课兼容的必须写进 reason 的取舍，禁静默丢弃；禁窄化算子——「一个/某个/一次」类限定词出现须自问目标原文是否真只要求一个；reason 从「定位一句话」扩为「定位与取舍」（覆盖了哪些面向、缓议了哪些、为何同课兼容或不兼容）；可兑现性判据——教练能据此长出主线、并能在某时刻基于既有节点裁决收尾，空泛口号（「精通数学」「建立数学思维」）不合格。操作化正反例以实机「数学」课案例入册。拆课不自动化：目标横跨不同学科时由 reason 建议，建不建课是学习者的决定。

边界：

- 终点仍在图上（入图理由见 ADR-0055：改扎靶标、闭包健康、收尾接线都要真实节点承载），只是零产料零学习消费。
- 不追溯清档照旧（ADR-0055 边界）：存量已生成的终点正文保留，交异常态恢复路径处理。
- 队列摘要行与人审面板的展示格式不在本裁决范围（reason 扩容后自然承载取舍披露）。

替代方案（否决）：

- **毕业综合节点（ADR-0055 生成门原案：宽终点照常教考）**——承诺句不是可考对象：题库对着「能读懂机器学习与物理/金融入门材料里的数学」出题，出什么都是错的粒度；完成判据被钉死在语义空转的节点上。
- **维持窄终点 + 提案自动建议拆课**——同学科多面向拆课是线性代数学三遍（概念表/题库三套），且学习者明示拆课自己做。
- **完成读「当前前沿已掌握」、不设收尾事实**——前沿掌握是常态中间态，教练可能还想继续长；没有收尾宣告，完成会在教练两批之间误触发。
