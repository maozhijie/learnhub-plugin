# 名称建课、手动多终点与生长停摆判据

建课原先只有种子提案一条通道（`kind=seed`）：面板一次填齐课程名 + 目标 + 类型，跑一次模型站产 1–3 起点 + **1 个**终点，人审 apply；终点唯一性是硬约束（单锚文件、拒改终点、必接线到那一个终点，ADR-0055/0056）。实机症状（2026-09-14「数学」重建）：目标描述成了**建课门票**，节点数不可预测却要当场承诺一个终点，加第二个方向没有入口（换终点只能整课 reseed）。

理由：终点只该说清生长**朝哪去**与**何时能停**；「承诺物 + 完成判据锚点」只在完成态存在时才需要，而完成态不是学习者要的东西。方向本来就是一张网，同一台阶朝几个方向推进是**正常结构**，多终点因此是常态。人加终点比任何起草都便宜准确，故人手加的终点不过 AI 资格门。分工不变：人给方向、教练长台阶，结构事实仍由受理门守。

关键裁决：

- **建课 = 名称即空图。** 面板只收课程名；同一写单元落：注册表条目 + 课程根 + 零节点区 `data/00_未分区.yaml`（空图的载体）+ 空登记表 + 空锚册 + 罗盘骨架。空图仍走现有读取路径（fail loud 只对「目录不存在／为空」）。删旧建课路径：面板表单字段、`mode=new`/`reseed` 的 `initCourse`、`SeedDraftRequest.goal` 必填。建课**不自动初始化**：零节点图不入任何自动触发点，第一次生长由学习者显式下发。
- **终点由学习者手动增删，可任意多个。** 添加（零 pre 节点 + 一条锚，可选一句目标描述）与删除（锚与节点一并移除，已铺台阶留图上成末端，UI 确认一次）都立即写盘、不等队列。**不提供改名**（破坏既有生成路径语义）也**不提供「把已有节点设为终点」**（撞纯标记红线）。终点本体不变：零正文零题库零调度零推荐，终点性仍从锚读侧派生（ADR-0055 不动）；未接线也不阻塞学习（零消费，只影响逐终点读数与罗盘）。
- **锚 schema v2 与断裂 v3。** 锚册改 `{version: 2, anchors: [{endpoint, goal_note?, goal_type, declared, sealed?, worksheet?}]}`——收尾宣告与工作表逐终点独立，`goal_type` 默认能力锚定且人加时不露出表单。走宣告式断裂（ADR-0034）：脚本整体归档课程树、戳 `version: 3` 记 `breaks`、登记表豁免存活，**零兼容读**。
- **教练启动条件与接线触发。** 教练回合要求 ≥1 终点（零终点时 UI 明说「先加一个终点」；空锚是合法空态，不再是「未播种」）。**不为「未接线终点」另设受理门义务**——改依赖关系本就是教练的生长能力〔已由文末 §修订（#240）取代〕。
- **生长停摆 = 就绪存量达标 或 所有终点已达成。** 逐终点三档：未接线 → 已铺通（锚上 `sealed`）→ 已达成（已铺通且最后台阶全部 ≥ 掌握阈值）。**课程完成态删除**：`foldCompletion` 降为停摆输入与逐终点读数，UI 的 `🎉 已完成` 横幅删掉；就绪存量口径**不变**（仍全图计数）。
- **多终点裁决与接线门。** 生长批 note 增加 `target_endpoints: []`，「主线批必接线」门改为**对每个声明的终点**跑同一套覆盖检查。**同一新节点可同时充当多个终点的最后台阶**（交汇节点）是合法形态；`add_node` 以终点为 pre 仍直接拒（禁长过目标）。逐终点状态进教练上下文包，据此优先选能同时推进多个终点的台阶（提示词纪律，非机器规则）。
- **罗盘按终点分节。** 「剩余路线」一节一个终点，节头写成 `- **终点名**：`——终点名也是图上节点名，节头天然「有锚」，#231 的对账机械一行不改（不用 `###`，否则被 `validateRouteBody` 放过、被对账记成漂移）。同一交汇节点可出现在多节；初画与沙盘 ETA 逐终点化。
- **结构读数正名。** 图屏与审计报告的「主线深度」正名为**图深度**（口径不变：全图最长路径——多终点下没有单一主线可指），另给逐终点三读数（已铺通/已达成/闭包已学）。
- **交汇节点是读侧派生。** 节点落在 ≥2 个终点的前置闭包内即交汇：零写侧字段、不落盘（与 Mastery 同款纪律）。消费方：教练裁决纪律、图与终点列表读数、审计与生成注入。
- **种子降职为「给已注册课程起草结构」。** `kind=seed` 只能作用于已存在的课程（不再建课、不再 `initCourse`）；面板不再露出种子入口（agent 通道与反编译仍用），反编译改为**要求课程先已注册**。起点资格判据（ADR-0040）与终点资格判据（ADR-0056）降为起草通道的提示词纪律，不约束人手加的节点。

边界：

- **不追溯**：存量课程的图、锚与产物不动；断裂整体归档课程树，引擎读侧永不读归档区（ADR-0034）。
- **空目录仍 fail loud**：空图的载体是零节点区文件、不是缺目录；Missing 与 Broken 的区分不动。
- **就绪存量口径与 FIFO 不插队照旧**：零节点闸只关自动触发点，面板「生长一步」照常即时入队。
- **手加终点与删除都是即时写盘**：不走提案、不走人审（人是权威），但重名/断边/环等结构门照旧在前生效。

替代方案（否决）：

- **保留种子建课、只砍面板字段**——建课仍要跑一次模型 + 一次人审，「一次成型承诺」还在，病根未动。
- **放行空目录当空图**——搅浑「图是空的」与「图不存在」（Missing/Broken 的基石），空目录 git 也不跟踪。
- **加节点→终点的加权归属边（像 enc）**——多一层图语义就要配新门/新审计/新生成注入，而消费方（细粒度归属读数）现在不存在；交汇由前置闭包自然表达。
- **每终点一个锚文件**——读侧要扫目录聚合、断裂脚本与 Data Check 都要分叉。
- **引擎在添加终点时自动连线**——伪造 pre 边等于替教练裁决「哪些是最终台阶」（沿用 ADR-0055 否决）；接线走教练回合。
- **保留课程完成态**——课程可永远停在「暂时不用再长」，宣告「完成」会把停摆误读成终结。
- **就绪存量只数「朝未达成终点」的节点**——波及就绪卡、冷启动折算、周复盘对账与沙盘 ETA，精度现在没有消费方。
- **终点可改名 / 可把已有节点设为终点**——改名破坏生成路径（文件名、题库、罗盘引用）语义；「设为终点」撞纯标记红线。

## 修订（#240，2026-09-14）：加终点只声明方向，放行归「生长一步」

**取代上节 §教练启动条件与接线触发。**

实机症状：加到第一个终点即自动拉了一轮接线回合（学习者想先声明完方向再放行）；那轮又因 `force` 只在入队侧生效，被停摆短路吃成 `idle`。

- **加终点 = 纯声明。** 落锚 + 零 pre 节点，立即写盘，**不触发生成、不拉回合**（`/endpoint/add` 不再有教练回合受理态，`coach_round` 响应字段退役）。理由：逐终点各拉一轮会中途开始生成，且教练看不见还没声明完的方向（交汇优先要看全部方向）。放行学 **#238 Story 4** 的字面口径。
- **`force` 随任务进执行侧。** 显式重新裁决的豁免必须跟着那一轮任务走（`growthForce` 随注册表持久化与恢复），否则「生长一步」在停摆图上恒空转。自动触发点不带它。
- **未改**：停摆判据（端点只有终点节点仍判 `exhausted`）——它正是「先声明、后放行」的闸（不判停摆则自动触发点会在未放行时拉起回合）；代价是停摆文案读起来像「无事可做」，属已知措辞债。
