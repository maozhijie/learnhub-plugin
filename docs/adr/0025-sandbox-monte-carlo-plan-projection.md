# 沙盘：现有模型的蒙特卡洛计划推演，只读、分布输出、非承诺

决议（#73 Not-yet-specified 收口，2026-09-09，grill 会话）：D-3 预测沙盘的展示口径落定为**沙盘（Sandbox）**入 CONTEXT.md——用现有 FSRS+mastery 模型对学习计划做蒙特卡洛推演的只读视图。不叫「预测」：预测在词汇表已有两义占坑（JOL Prediction=学习者预测、FSRS 预测保留率=模型校准仪），第三义再叫预测必混。裁决细目：

1. **输入**：每日学习分钟目标 × 推演时长（默认六周）+ 意向节点/课程集合。
2. **模型（与调度同源）**：现有 FSRS 的可提取性 R 作伯努利抽样推进 + mastery 派生原样复用，蒙特卡洛约 200 次；**不引入任何新记忆模型**——沙盘的诚实度上限就是现有模型。模型错了沙盘跟着错，这是特性：推演与调度同源，永远不会出现「仪表盘与沙盘打架」。
3. **展示口径**：推演终点的 mastery 地图（课程×节点）+ 总掌握曲线带 50/80% 分位带；措辞固定预期管理口径（「模型推演，非承诺」，沿需求池 D-3 原文）；v1 只做单计划，多计划对比不做（登记后续方向）。
4. **红线**：零写侧——不进门禁、不进调度、不改账本。输出是分布不是承诺，支持**计划谈判**（学习者据此调自己的计划），但不给「可行性判定」，引擎不据沙盘拒绝或推荐任何计划。

同批被拒：确定性外推（给不出不确定性，伪承诺）；独立仿真记忆模型（破坏与调度同源原则，两套模型必然漂移）；多计划对比进 v1（范围控制）；用沙盘输出做调度或门禁输入（Goodhart——推演一旦变成方向盘，计划本身失真）。
