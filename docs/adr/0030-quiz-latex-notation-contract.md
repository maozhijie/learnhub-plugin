# 题面数学一律 LaTeX 记法，违规拒收而非自动转换

题干、选项、解析中的一切数学一律 KaTeX 记法（行内 `$…$`、独立式 `$$…$$`），禁止 ASCII 记号（`x^2`、`a_1`）与不带定界符的裸 LaTeX 命令。渲染框架只认 `$` 定界符（remark-math 链），这是面板的单一约定；生成端违反约定时选择程序检测 + 拒收重出（复用防相似的拒收通道），不做 ASCII→LaTeX 的自动转换——正则分不清正文与数学，静默改写是在伪造内容（同 ADR-0004 底线），误报的代价只是一次重出。YAML 双引号标量把 `\t`/`\a`/`\f` 等解释成控制字符造成的公式损坏（`\times` → tab+`imes`）在解析后按「控制字符 + 已知命令片段表」做确定性修复并计数留痕，修不好的题拒收；不为此换 JSON（`\t` 在 JSON 里同样是合法转义，问题只会更糟）。检测器只认高精度信号（裸 `^`、裸 `_`、裸命令、控制字符），宁可漏过纯 ASCII 数学（`6x3y` 无 `^`）也不误杀正常题面。
