# C2 Anki 互通：双向但 Anki 是纯作答通道，vault 始终唯一调度者

决议（#43，2026-09-08）：Arc C2 立项为「到期题目导出到 Anki / AnkiConnect，手机刷完回写答案」的**双向**互通，但架构上 Anki **只是作答通道（conduit），不是调度器**。

数据主权（延续 ADR-0004「vault 是唯一事实源」）：跨界的只有**原始作答事件**（Anki 的 Again/Hard/Good/Easy 映射为答错/忘记/复习自评档，作原始证据导入），调度永远由 learnhub 自己的 ts-fsrs 在 vault 内重算——Anki 侧自己的排期输出**不作数**，每次会话前由 vault 把到期/卡状态推给 Anki 并校准/重建镜象卡组。因此不存在「同一题两套 FSRS」的双调度器分裂（那会是 #19 式口径分裂）；Anki 卡组是可丢弃的镜象：与 vault 不同步时按 vault 覆写/重建，不判 Broken（镜象非事实源）。

协议要点：导出 = 未归档且 due ≤ 今日的到期卡（卡片带 learnhub 卡 id，便于回写归属）；回写导入 = 先导后重算，并守住「一题一天只推进一次调度」不变量——vault 当日已推进的题，其同日 Anki 事件跳过调度只留档；导入事件同时写入既有作答流水（state/practice.jsonl，kind=review），使未来 A2 参数优化器/记忆仪表盘能把 Anki 来源的作答也计入数据回流。复习语义映射为近似（Anki 无 5 秒忘记门控，Again 覆盖答错与忘记；复习自评档位对应 Hard/Good/Easy）。节点 stage/R 联动与站内复习同语义（节点聚合代表卡回刷仍依赖 #52）。
