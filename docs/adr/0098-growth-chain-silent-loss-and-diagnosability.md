# 生长链路的静默丢弃与可诊断面收口（#313 第三次审计：A/B/C/D/E 五组的裁决）

2026-09-17 四路并行审计（#312 阻断组 + #313 高危组）里，本票管 A/B/C/D/E 五组。五组病灶不同，但落在同一条因果链上：**门零错误、回执全绿，而数据没了、或模型读不到死因**。A 组是「数据没了」（静默丢弃），B 组是「读不到死因」（不可诊断），C 组是「状态没回来」（残留与近互锁），D 组是「文档在说谎」，E 组是「没有面」。逐条落地记录归票面与门册，本 ADR 只裁其中**改变了原方向或有取舍**的七处。

## 裁决

**一、`del_node` 的记账口径从「按名字」改为「按节点身份」，且不再静默摘边（A1/A3）。** 旧实现在批末按**名字**过滤被删节点：同批 `del_node X` + `add_node X`（模型改写概念字段组的唯一写法——概念字段组只随 add_node 出生）会把**新节点**一起滤掉，原节点归档、journal 写着 del+add、diff 报「新增」。按身份记账后「删的是此刻图上那个节点」，同名后来的新节点不算被删。同时 `del_node` 不再顺手剪掉指向被删节点的 pre/enc 入边（对照终点移除与在途复诊剪除两处都显式做摘边恢复，说明那是漏的）：断边由既有的「变更后断边」门报出，错误行给两条真能走的出路（显式接线摘桥，或改改名保节点）。**否决**「保留静默摘边、只在 diff 里报涟漪」——涟漪是发生在学习者前置集合上的**权威变更**，看得见不等于它被同意了；这条选 fail loud 与 ADR-0082/0083 的可达性纪律同侧。

**二、误解封顶改增量判据（C9）。** 旧的绝对计数（合并视图全课程超上限即 ERROR）会砖死课程：概念合并（#265）把两条目的误解并到同一个 canonical 名下，存量当场越界，此后该课程**任何** edit 提案都被同一行错误拒——连与误解无关的批也拒，而错误行建议的「并入既有条目文字」在 op 词汇里不可表达（只有 add_node 能写概念字段组）。现在只报「本批把某概念推过封顶或存量水位」，错误行给两条可表达的路（换节点承载／同名 del+add 重建时少写一条——后者靠裁决一才成立）。**否决**「新增一个编辑既有节点概念字段的 op」：那是出生/覆盖层分家的边界（ADR 的 schema v2 契约：概念字段组是出生层），开这个口要连着改图 YAML 写侧契约与审计口径，代价远大于收益。

**三、判决面按 canonical 归一（C12）。** 同名同义纪律此前只兑现到对表门（canonical ∪ aliases 放行），而**按名比对**的两处判据仍拿原始串：巩固门的「已教」集合（图上写别名 → 误判「不是已教概念」无谓拒收）与误解封顶的计数（同一概念折成两半，实际可放 4–6 条）。归一收在一处实现、只此一份。图侧的反向映射仍以原始串为键（它是读侧映射，改键影响面大），归一发生在判决点。

**四、sealed 谓词要求接线非空，且终点不许出现在任何 op 的 pre 里（C10）。** `set_pre {node: 终点, pre: []}` 是清空前置，不是收尾接线——旧谓词只看 op 形态，于是「pre 空 = 未接线」的终点被标成 sealed（与上下文包里读出的状态自相矛盾，而 sealed 一旦落锚一直留着）。`set_pre {node: X, pre: [终点]}` 同罚（终点是方向锚不是台阶；接线写 `set_pre {node: 终点, pre: [台阶]}`）。

**五、审计门从「只在 apply」提到受理序列（B5），且拒收带明细。** 此前 `draft_audit` 可以报「通过」而 apply 每轮拒，明细只写进 `课程根/审计报告.md`——草稿会话的模型只有读图工具，读不到文件，只能烧轮次。门序列新增审计门回调（propose 与草稿试算同判据消费），拒收快照随行带上 ERROR 明细；审计本身增「只算不落盘」模式（报告落盘仍归 apply 侧那次真跑）。行为变化：课程存在审计 ERROR 时**任何**提案在受理处即被拒（旧行为是受理通过、apply 拒）——终态相同、诊断提前，且 `propose` 拒收信息与 apply 逐字同源。

**六、语料补标的判据从「站最近一条」改为「本轮真的产过捕获」（B7）；`coach.gate.reject` 接线兑现（B6）。** 前者：取消／轮次预算耗尽／熔断前零调用／空手结束都是非模型失败且可能本轮零调用，旧口径会把上一轮甚至上一个会话的成功件改名 `bad-` + `outcome: failed`（bad 桶被质量评审抽样，失败详情那句「语料 …/<件>」还指向成功件）。修法是 `annotateLast` 收「本轮开始前的 `lastRef` 令牌」（令牌相等 = 本轮零捕获 = 不补标）+ 取消豁免；**D20 点名的「零消费死 API」正是这块缺的零件**，不是该删的死代码。后者：ADR-0080 点名的主验收物 文档点名的三个主验收物事件全仓零发出点（按文档 grep 会得到「没跑过重裁」的**假否定**），而真发点在发一条没登记过的名字——现由 `coach.gate.reject` 统一承担（两个教练站的每一处门拒绝），退役与补登都进 ADR-0091 附录（只增不改），ADR-0080 追 §修订更正指针。

**七、计划契约的两处收紧（C15/C16）与「非停摆必给台阶」的提示词同步。** 计划门此前不要求 steps 非空，`operator: 前进` + `steps: []` 被静默读成停摆（返回 idle、理由丢弃），而「计划不完整」与「裁决停摆」是两件事。门收紧的同时**必须改提示词**（模板原文写着「steps 为空 = 停摆」）——这是本票唯一的模板文本变更，走 §8 的登记 + bump（两键 v1→v2）+ 过门记录（check ✓；replay/compare 未做，理由见登记条目）。`course` 键改为按归一后的课程名比对（照抄上下文包标题不再白烧一轮重裁，真写错课仍在拒），`steps` 未知键 fail loud（`est` ≠ `est_hint` 此前无声蒸发）。

## 不做什么

- **不给 `del_node` 加「级联删」语义**：删一个还有人在依赖的节点照旧被门拒，模型/人必须显式摘桥——这不是疏漏，是裁决一的一部分。
- **不动草稿取消的工具/路由面**：归 #312（并行在途），本票只在其上位面上补了「取消生成任务」（`learnhub_generate_cancel`）。
- **不做单节重写进队列**（C14 只补了并发闸）：让重写走 `phase` 与面板呈现是更大的动作，本票只切断「与在管线任务并写同一节」的静默覆盖，取消可达性如实登记为缺口。
- **不给 `run`（agent 工具面）加 corpus 补标**：E25 只补 `engine.call.fail` 留痕；工具失败不是语料样本（模型侧会话本身就是材料）。
- **不把「自动重拉生长批」的判据改成结构缺口**（#312 的 B1 面）：本票不碰入队阻尼。

## 边界与已知缺口（如实登记）

- **路径化风险**：本票判据多处依赖「站点标签」「概念名归一」「本轮捕获令牌」，都是**运行期约定**而非类型约束；四者中任一被绕过（新站不引常量、绕过 `canonicalizerOf`、绕过令牌取 ref）都会静默回到旧病症。已补一条门（引擎侧站常量必须全在宿主词表里）；其余靠 `tests/README.md` 门册的行为登记 + 人审。
- **未做**：E22 的「读草稿状态」（归 #312）、E23 的「批量生成正文面板入口」（需 UI 新控件 + 面板测试，另票）、C14 的取消可达性。
- 存量处置：**已越界的存量误解条目不被本票改写**（裁决二只让它们不再砖死课程）；模型可用「同名 del+add 重建」逐条收敛。事故草稿/半途落盘的课程按 ADR-0095 的口径处理（reject 后按现状重提、或 `draft_revert` 重开）。
