# 题库清理只归档不删除，跳过节点即归档其题目

题库清理（一键清理休眠题/跳过节点残留题）与「过于简单」归档的处置语义统一为：写 `archived` 可逆 flag 并记录归档原因（`archived_reason`：skip/cleanup/too_easy/erratum），**永不物理删除**。跳过节点（stage=skipped）时引擎自动归档该节点全部未归档题（原因=skip）；取消跳过不自动恢复——跳过只能说明「现在不需要」，不能说明「这些题永远不该回来」，恢复是学习者的显式动作（题库按原因筛出恢复，或重生成）。一键清理的范围 = 跳过节点的全部未归档题 + 已完成节点（review/mastered）的休眠题（错过了 nodeComplete 的一次性纳管、此后无调度入口的题），预览分组确认后才落。不删除的理由：题目与其作答史/调度史是学习证据与作者资产，删除不可逆、违背「证据不为便利消失」的底线（ADR-0004 同精神）；归档已让题退出全部调度与统计读侧，删除没有额外收益，只有不可逆风险。跳过即归档是惊悚但正确的默认：跳过的语义是「视同已通过、退出推荐与阻塞」，其题库若原样留着，休眠题永远占着软上限额度、已调度题永远在题库视图里制造噪音——与其靠使用者记得清理，不如让跳过动作自带完整的状态收缩，代价由可逆归档与按原因恢复兜底。
