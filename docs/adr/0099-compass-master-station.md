# ADR-0099：罗盘升格为大师站——战略分解与写权反转

日期：2026-09-17 ｜ 状态：已裁决（实施归 #316）｜ 取代：ADR-0097 的「route 写权归生长批」裁决方向

## 裁了什么

**教练与罗盘分立为两层**：教练（思路官 + 执行官）是**局部最优求解器**——每生长批只裁一步方向，不背全局责任；罗盘升格为独立的**战略站（大师站）**——由「领域大师」针对终点锚声明的程度目标，操刀产出专业、完整的方向分解。三站编排：罗盘站 → 思路官 → 执行官。

- **写权反转**：「剩余路线」的写权从生长批（ADR-0097）反转为罗盘站独占。教练只有**重画建议权**：思路官计划可携带结构性的重画建议，经入队去抖 + 每课程最小间隔拉起罗盘站——频率不匹配且「又当玩家又当裁判」，故教练不得直接改弧。
- **罗盘站输入 = 大面读数**：终点锚（含目标描述）、图全景、逐终点粗粒度状态（未接线/已铺通/已达成 + 闭包进度）。细粒度行为读数（行为摘要五件套、窗口流水）归教练，不进大师站——学徒的战术波动不构成重画战略的理由；弧的个人化经由终点锚注入，不经由读数注入。
- **罗盘站输出 = 散文弧 + 阶段标题机器锚点**：人读主体是大师的散文结论；阶段标题列表可解析，供教练的对齐字段引用（软起步：指认留痕进日志，连续指认不出才升级告警，不设门拒）。弧对生长批裁决是**优劣标尺**——方向承诺、路线可修。
- **主权分治**（继承 #316 修订分治，理由重述）：专业权归大师——增量修订自动生效；方向权归人——改向/减量走提案确认。人审对象不是「大师对不对」，是「这还是不是我要的方向」。
- **终点锚语义澄清**：目标描述是**程度声明**（终止在什么程度——深度/广度到哪档），不是用途问卷；特例用途（如应试）须由用户显式写明，系统不做承诺。弧五清单的「向用」条款相应改为「向程度」：每弧段须能指认它推进程度声明的哪个维度。

## 为什么

- **回声病是制度性的，不是手艺性的**：罗盘词条原定位「非承诺路线草图」+ 模板硬约束（条目钉在图近旁、禁专业展开）共同禁止罗盘做它该做的事——既然承诺不了任何东西，复述节点就是最优策略。#317 B1 的「节点近景回声」实证由此而来。
- **D1 的事后观察点只有这两处**：终点手动添加被接受的前提是事后读数立得住（#317 D1 评论），罗盘（看路）与收尾宣告（判完成）正是仅有的两处；罗盘不给战略，人就没有任何「看路」的窗口。
- **「排斥专业立场」是规训残留**：禁专业展开类规则只是在排斥应试教育风格的规训，与系统立场无关；战略层值得 deep effort 的贵 token。

## 否决了什么

- 思路官随生长批顺手重写弧（现状形态）：频率与专业度都不匹配，且教练写罗盘 = 又当玩家又当裁判。
- 弧全结构化：大师产出全结构化会退化成又一个 schema，人读主体必须是散文。
- 细粒度行为读数进大师站：详细读数是教练的工作面。
- 把「为什么学」塞进终点锚（#317 待裁决 4 的原建议）：终点锚答的是「到什么程度」，该建议作废。
- 「考试型目标」等例子驱动的机器分支或提示词特判：例子只是辅助理解的例子，终点锚按自由文本理解。

## 不做什么

不新增提案 kind；不为目标类型建机器分支；罗盘站初画/重画两族的模板拆分与 route 字段退役的实施细节归 #316 票面。
