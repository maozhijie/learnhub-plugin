# 错误对比卡域：错答挖矿的独立错误 deck（FSRS 汇入复习队列、无绑定 XP）

决议（#82，2026-09-09，交付实现收口）：从作答流水挖高频错误模式（同一题 ≥2 次实质答错；忘记申报与空作答不是错法证据），AI 据此生成「三选一、其中一项是学习者自己的错法」辨别卡，入课程根 `错误卡/<节点>.yaml` 的独立错误 deck 走 FSRS（错误管理训练：错法本身成为复习对象）。呈现汇入 canonical 复习队列——与 ADR-0021 我的卡同一结构：队列合并、测量面不扩、无绑定 XP。

## 裁决细目

1. **独立卡域，不入题库**：错误对比卡不进题库九题型（AlloKind）、不进 Mastery/作答正确率/练习证据 EMA/完成门禁/节点定价的任何消费面（独立目录 = 结构性隔离，同我的卡先例）。每卡带 `source_q` 软引用回源题（题被归档/重生成后悬空按 Missing 展示，不 Broken；归档旧卡后原题重新可挖）。
2. **自动判分，不走自评**：三选一答案唯一（正确做法项），辨别对错是客观事实——选对推卡 rating 3、选错 rating 1，无忘记申报、无复习自评档。区别于我的卡（自注内容无客观答案，只能自评）。
3. **调度隔离 + 一卡一学习日**：FSRS 走默认参数（`sched(null)` 通道，参数优化器不训）；`advanceStrict` 守一卡一学习日一次推进；复习日志（review-log）与 practice 流水零写入。
4. **队列合并，测量面不扩**：错误 deck 汇入 `reviewQueue`（source='error'，队列键 `err:` 前缀防撞），同 R 风险排序与单节点定向入口；队列卡面只带题面与选项，答案/错法项/解析随 `errorCardAnswer` 判分揭晓（同 questionView 泄露纪律）。JOL 抽查、复习日志、Anki 导出均不含错误卡。
5. **无绑定 XP（`kind='xp_error'`）**：选对按与题卡同公式入账（`max(1, round(难度))`），选错 0 XP 同样留净行保 streak 口径；落中心级 journal 行（course='*'/node='*'），只计总账、每日目标、streak，不进逐课程/逐节点报表。创建零 XP、零 canonical 写入。
6. **生成走挖矿门禁**：挖矿纯函数（practice 流水投影，零依赖可单测）；生成入口候选对照门（模型产出的 (node, source_q) 必须命中系统给出的候选）+ schema 门禁（恰好 3 个互异选项、answer/mine 必在其中且相异）；模型产出不可解析/未过门禁时抛错零落盘。批上限硬帽 5 张/次（max 参数只能下调），错误 deck 缓慢累积防批量注水。`errorCardMine` 只读预览是「错误模式人工抽查合理」的验收面。
7. **Broken 双腿纪律**（ADR-0004）：文件缺失 = 合法空卡组；存在但坏 = 抛 Broken——队列/清单/生成侧跳过不阻塞其他卡，`data-check` 错误卡体检段负责显式报出。

## 为什么自动判分而非自评

我的卡自评是因为「学习者自己的话」没有客观对错；错误对比卡的卡面是答案唯一的三选一，判分确定且可复核——把判分换成自评会凭空造出一个自评-实际偏差源（ADR-0022 的反面）。被拒替代：把对比卡直接写进题库（喂节点作答正确率与 EMA——错法复习是矫正练习不是节点掌握证据，裁决 1 排除）；对比卡进复习日志（测量面扩，裁决 4 排除）。
