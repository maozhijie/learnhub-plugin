# 日界可配置：学习日口径取代午夜切日

决议（2026-09-09，日界 grill 会话裁决）：软件里全部「今日」、跨日结算与按日到期不再按本地午夜切日，改为可配置**日界（Day Cutoff）**（默认凌晨 02:00）切出的**学习日（Learning Day）**——熬夜到午夜之后的学习仍归属前一天，与 Anki 的 next day starts at 同款动机。裁决细目：

1. **口径二分**：到期判定（`due <= 今天`）、同日守门（一卡一学习日一次推进）、按日聚合（XP / streak / 真实保留率 / FSRS 训练链 / 打卡热力图 / True Retention 每卡每日首推）、「今日」视图（推荐、到期数、今天学它 pin 的当日有效）一律以学习日为单位。**出处戳除外**：generated_at、trained_at、备份与回收站目录名、运行日志保持日历日——它们记录真实世界哪天发生，不参与学习口径。
2. **配置面**：`state/learnhub.json` 新增 `day_cutoff`，格式 `"HH:mm"`、00:00–23:59 全开（`"00:00"` = 退化为日历日口径，兼作回归基线）；读-校验-写三件套仿 `daily_xp_goal` / `jol`：非法静默回落默认、原子写；当前生效值经 views/status 暴露可见；默认值入 `params.ts`。
3. **推导规则**：某时刻的学习日 = 该时刻减去日界所得的日历日。流水 ts 保持真实本地时间不变，按日键一律从 ts 实时推导；持久化的日字符串（`stats.last`、`fsrs.last_review`、`due`）切换后按学习日解读。
4. **历史数据不迁移**：派生聚合重解读是特性而非缺陷——历史 00:00–02:00 的事件自动改记前一学习日，无需迁移脚本。一次性伪影备案：切换当夜，旧日界下午夜后已推进的卡可能被判为新学习日而再推进一次，此后自洽，不作修补。
5. **不对齐 Anki rollover**：ADR-0011 的 vault 唯一调度者成立。Anki 事件的学习日按我方日界从事件 ts 推导，Anki 侧的排期输出与它自己的 rollover 设置一律不作数。
6. **UI 与 e2e 不自算日界**：引擎在 views/status 暴露当前学习日与生效日界值；`BankPage` 删除本地 todayStr 副本改消费引擎字段，e2e 脚本副本同步。

为什么默认 02:00、静默回落而非 fail loud：02:00 覆盖绝大多数「午夜后还在学」的作息（Anki 同业默认即 4 点档、02:00 取更保守值），且 00:00 保底严格等价旧行为；静默回落与 learnhub.json 现行配置三件套一致——ADR-0004 的 fail loud 针对用户数据损坏，不是配置笔误，生效值可见补足静默的代价。同批被拒：读 Anki 的 rollover 设置对齐（外部应用反客为主，还得多读一份外部配置）；放 cordis 机器级配置（作息是人的属性不是机器属性，换机器不该丢）；历史迁移脚本（派生数据无键可迁，持久化日串伪影一次性、无害）。

工程影响（供实现票 #101 消费，非本决议约束）：全引擎「今天」单点产生于 `dates.ts:todayStr`，facade 约 30 处 `today` 默认参数是现成注入缝、签名不动；散布约 10 处的 `ts.slice(0, 10)` 按日切片须收敛为统一的「由 ts 推学习日」原语；`BankPage` 与 `scripts/e2e.mjs` 各有一份 todayStr 重复实现待撤。测试无 fake timers，沿纯函数注入 today 串的既有缝补：dayOf 边界（23:59 / 00:00 / 01:59 / 02:00）、`day_cutoff="00:00"` 与旧行为等价性基线、配置非法回落、跨日界事件归属前一学习日（XP / streak / 守门）。
