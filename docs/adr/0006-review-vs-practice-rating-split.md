# 复习与练习的评分语义刻意分岔

复习刷卡流与学习练习流对同一道题的作答入口采用不同评分语义：复习流是自评语义——答错等价「忘记」（不作答直接翻面、按答错记、0 XP，受 5 秒主动回忆门控），答对后由学习者自评 Hard/Good/Easy 三档推进 FSRS（自评只进记忆参数与掌握度，不参与 XP 定价）；练习流保持自动映射——对=Good、错=Again，无忘记、无自评、无门控。理由：首次学习追求节奏与题量，逐题自评会打断心流；调度保真度由复习流独自承担，且「忘记」给了不会的人一个不靠乱猜的诚实出口（乱猜惩罚只兜底练习流残留场景）。这是刻意分岔而非待修复的不一致：两处作答语义若被未来重构「统一」，要么牺牲学习节奏、要么污染调度证据——都不要做。
