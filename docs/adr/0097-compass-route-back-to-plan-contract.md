# 罗盘「剩余路线」恢复生产者：route 回到思路官的计划契约

> **状态更新（#316，2026-09-17）**：本篇的 route 归属裁决已被 [ADR-0099](./0099-compass-master-station.md) 取代——写权反转归罗盘站独占，route 随 #316 从计划契约/提案链路整链退役。

`#273` 把 route 划出执行官时**没有交给思路官**——两族思路官的输出契约都没有 route 字段，执行官提示词只留一句「route 不归本站」。此后「剩余路线」只由罗盘初画/重画产出，而初画是一次性动作：**随生长批重写的通道事实上断线**（2026-09-17「数学基础」连初画都没跑，该段至今是 `ROUTE_PENDING` 占位）。同一时期，受理门规则、apply 写入路径、对账（`reconcileRoute`）、周复盘现状区、罗盘脚手架文案五处仍在假设这条通道活着——「冻结的旧稿」与「每批重画的规则」并存，对账读数因此恒定失真。

裁决：**route 恢复进思路官的计划契约**（计划交接契约增一个可选 route 字段），不新增角色、不新增站。

关键裁决：

- **零额外 LLM 调用**：思路官同一轮已在读全图摘要与旧罗盘（教练包罗盘尾段）并在裁决方向，顺手重写路线只多一百至三百输出 token。
- **同作者、同一次裁决产出**：避免「计划朝终点 A、罗盘写终点 B」的分叉——路线是非权威草图，没有第二个面会对账它。
- **门同源**：计划门用**同一个**路线门（初画与重写共用的那一个）校验 route，失败走既有回灌重裁。理由是 #309 刚修好的那类病——「计划门过、apply 门拒」等于开了一条静默丢弃通道。
- **义务与缺省**：前进/换向**必写**（方向变了路线就该跟着变）；停摆/插入/巩固可省略——**缺省 = 不改写、保留旧稿**，绝不是清空。
- **透传不进草稿字段**：计划 → 交接块 → 批规格；route **不落草稿档**——落进去会被续建当成「本批产物」带回，与「旧稿当新产物」同类风险。
- **有先例**：#273 之前 route 就是恒写字段（连零 op 的回合都照写），门与写入路径现成，本次是恢复既有形状而非新造机制。

替代方案（否决，保留复查触发条件）：

- **复用现有罗盘站 + 自动触发**：契约更干净、刷新节奏可与批节奏解耦，但每次刷新多一次调用（要重新注入整份上下文），且**必须跑在 apply 之后** → 「与图 apply 同一次写入」这条强承诺要降级为弱承诺，上述五处口径全得改。**触发改用本方案的条件**：实测 YAML 与散文同出导致格式契约不稳（route 段被压成一行、被围栏包住、挤坏 steps），或需要稀疏刷新以省 token。
- **独立新站**：与上一方案同价，只多一份要维护的提示词、语料桶与登记，无增量收益。

后果：三站提示词同票登记（两族思路官各升一版、执行官升一版）；计划交接契约是对外类型，加**可选**字段不破坏既有消费方（图上只有生长批与草稿回路两个消费方）；罗盘「剩余路线」自本裁决起随方向批刷新，对账读数重新有意义；缺 route 的前进/换向计划被计划门拒收，从此不会「计划过了、罗盘没写」。
