# 终点纯标记化与完成判据折叠

ADR-0055 把终点性收进锚的单源派生，但终点仍被两股旧账拖着：生成门原案「进入学习前沿即解锁」让终点照常被产料（学习者就绪与推荐也照常含它——终点照常「被学」），完成判据 `foldCompletion` 读终点自身 mastery，迫使终点当可教可考的课程节点。grill 会谈（2026-09-13）的实机案例把两处一起证伪：种子提案把「数学」课的四面向目标（软件开发/游戏开发支撑 + 机器学习常识 + 物理/金融基础）压成「把软件或游戏里的一个真实问题写成数学问题，并算出可检验的答案」——三个面向静默丢弃。根因有二：① 种子提示词只有起点资格判据（ADR-0040），终点零判据零正反例，且硬约束把「一次独立的学习行为单元」泛化到节点名，宽目标只能压窄；② 终点自身持 mastery 读数，宽承诺句无处安放——它是「课程里最深的一课」，而承诺不是一课。

理由：终点的结构职责（改扎靶标 + 闭包健康收敛点）在 ADR-0055 已成立，剩下的一切「课程节点」残余（产料、调度、推荐、自身掌握度）都在诱导把承诺物当课程终点站。方向只有一条——把终点剥到只剩承诺标记：零正文零题库零调度零推荐，完成判据整体折叠到「教练认定的最后台阶」上，种子起草面给终点自己的资格判据。终点名是承诺句不是台阶句，这不再只是措辞偏好，而是判据结构的要求：只有承诺句装得下多面向的合成，台阶句天然单面向。

关键裁决：

- **终点纯标记。** 终点豁免一切产料：`enqueueGeneration` 对终点恒拒（不看就绪状态，手动与自动同认这道门，文案可读）；`contextPack` 不为终点组装产料上下文（管线侧兜底）；T1/T2 后继触发清单不登记终点；整课重生成链跳过终点。学习者账双侧剔终点：`readySet` 的消费面（status 就绪存量/清单、软闸清单）与推荐面（recommend 的 new 事件）都不含终点——终点不出现在任何「今天学什么」面上。不追溯清档：存量已生成的终点正文保留，门只约束未来生成动作（「数学」课存量歪态由 #201 恢复演练覆盖）。
- **完成判据折叠自最后台阶。** `foldCompletion` 的 mastery 读数从终点节点改为终点.pre 集（全部 ≥ `COMPLETION_MASTERY_THRESHOLD`）；pre 集为空（悬空/未接线）= 不达标。能力锚定另要求闭包健康（不动）；覆盖锚定另要求工作表核销（不动）；两种 goal_type 都要求已收尾。
- **收尾事实 sealed 进锚。** 收尾接线批（#198 受理语义：零 add_node 的纯终点 set_pre）apply 时往锚写 `sealed`（iso 学习日）——「收尾即宣告承诺兑现」，停摆裁决从罗盘散文落成锚上的结构事实；教练重开含 add_node 的主线接线批时清除（承诺重新在途，完成宣告随之回到未完成）。`validateAnchor` 放行可选 `sealed`（旧锚无字段照读，version 不动）；`writeAnchor` 的调用面从「唯一种子 apply」扩为「种子 apply 整份覆盖 + edit apply 的 sealed 维护」——其余锚字段仍只走种子提案人审。`renderEndpointAnchor` 呈现已收尾/未收尾。
- **种子提示词 v3——终点资格与起点资格分家**（版本注释 `learnhub:prompt/v2` 升 v3）。终点是承诺句不是台阶句：面向覆盖或显式取舍（禁静默丢弃、禁窄化限定词——「软件或游戏里的一个真实问题」这类「或/A 者 B」措辞就是窄化）；reason 扩「定位与取舍」（起点为什么放这里 + 终点覆盖/显式舍弃了哪些面向）；可兑现性判据（教练能长出主线、能据既有节点裁决收尾，空泛口号不合格）；操作化正反例用本次「数学」课案例（四面向输入 → 窄化输出 ✗ → 多面向终点句 ✓）；终点名不受「单一行为单元」约束（那是起点资格）。队列摘要行不动；拆课不自动化——目标横跨不同学科时由 reason 建议，建不建课是学习者的决定；`seedRepairPrompt` 不携带资格判据（回灌修复只对门错误）。

边界：

- #198 承接收尾接线批的受理语义（纯 set_pre 合法、主线批必接线、禁以终点为 pre），本票只管 sealed 的 apply 侧副作用与消费面。
- 完成宣告消费面（`courseCompletion`、status 的 `completion` 附带、面板完成卡）随新判据结构同步：`criteria.last_steps` 取代 `endpoint_mastery`，`sealed` 进判据。
- 教练账口径不动：前瞻深度需求/存量双侧剔终点照旧（ADR-0055）；终点感知面与统计口径（isEndpoint 读侧派生、图上样式、教练面恒标）归 #200。

替代方案（否决）：

- **终点保留 mastery 判据（现状）**——迫使终点当可教可考的课，宽承诺句无处安放；实机已证明它会反向压窄种子目标（终点要「可教」，所以目标先压成「一节课」）。
- **sealed 独立成档（state/收尾宣告.json）**——收尾事实与承诺物同源：锚是「课程唯一结构承诺物」，兑现宣告拆出去就是第二事实源，reseed 时还要多一处清理。
- **完成判据读终点.pre 的 mastery + 时间衰减门**——闭包健康已经覆盖结构破损，时间衰减是复习调度的职责；完成判据叠多一层就多一处与调度账打架的口径。
