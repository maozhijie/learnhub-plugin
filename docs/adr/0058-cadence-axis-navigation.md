# 导航节奏轴：五区页签、两级路由与供给卡——面板信息架构改版

#164 池票的「学习者/作者双身份信息架构分区」候选拉起的 grill（2026-09-13，四轮收敛）裁决：面板信息架构改按**学习节奏**切，不按身份、也不按功能域。裁决前的实况：10 个平铺页签是逐票功能直接进面板的堆积（ADR-0038 把图生命周期全搬进 UI 的副产品），`global.css` 95 行之外视觉全靠 Arco 默认皮与组件内内联 style，无自有设计 token；三周真实使用推演暴露五条身份轴与域轴都解不掉的裂缝——学习日的「接下来学什么」卡在生成队列后面、维修动作（恢复队列/失败重试）闯进学习日开头、周循环页（Kata/沙盘/实验）数据来自课程机器而动作属于学习者、项目页记执行与修里程碑相邻发生、新手第一天全程戴着作者帽。

关键裁决：

- **五区页签**（10→5）：**今日**（Learn 收窄：复习横幅/推荐流/XP·streak/供给卡/闸门计数）、**课程**（Graph+Generate+Bank+Proposals 合体，三入口：我的课程→单课工作台、生成队列全局面、提案收件箱全局面）、**洞察**（Stats+Kata+沙盘+N-of-1+睡眠开关）、**项目**（原样迁入，内部不重组）、**无界实践区**（原样迁入，canonical 词条即页签名）。能力指南退役为壳级帮助抽屉；铃铛通知中心只留壳位（实现仍在 #164 池）。
- **轴的判据**：分区切**节奏**（日循环/课程机器/周期循环）不切身份——本系统的作者劳动几乎全部由学习事件拉起、为学习流服务，「作者是另一种坐姿」的假设不成立；单用户系统里人审闸门没有第二个人可推，身份分区只会把闸门藏进学习者自己积压的地方。否决的替代：**身份轴（#164 原候选）**（五条裂缝如上，转正动议经本场 grill 被取代）；**纯域归并**（学习/内容/实践/洞察四区——生成与提案继续与学习路径同层暴露，供给心智无解）。区名避讳词条红线：「复盘」「实践」单独形态分别被周复盘、无界实践区词条列为 Avoid，故观测与自我实验区名「洞察」、实践区用词条全名。
- **两级路由**（ADR-0052「参数段留形不实现」预留位的兑现）：`#/today`、`#/courses`、`#/course/<id>/…`（单课工作台子路由：罗盘+图首屏，教练台/生长队列/提案/题库分栏）、`#/queue`、`#/proposals`、`#/insight`、`#/projects`、`#/practice`。路由缝（lib/router.ts）仍是唯一改动点，TAB_KEYS 唯一出处不变；旧深链（`#/learn` 等旧键）回落默认页签，登记为自用工具可接受的已知断裂。页签保活（display:none + active-tab 轮询门）机制不动，只减页签。
- **供给卡与今日页边界**：今日页唯一的新功能件是**供给卡**（在酿 n/停摆原因/恢复队列/失败重试，走既有 usePolling 与任务注册表轮询缝，零新后端）+ 待审闸门计数（深链提案收件箱）。课程卡列表不进今日（住课程区首屏，「今天学什么」由推荐流回答）；习惯自报不进今日（Habit 词条「无推送不提醒」纪律）；人审动作只在提案收件箱，今日只放计数。**罗盘回家**：单课工作台首屏=罗盘（学习者的进度语义装置，含批注区）+图视图，教练台降为分栏——罗盘每周附沙盘 ETA、学习者批注作教练软输入的既有语义零改动。
- **视觉：Arco 留守 + 自建 token 层**：ConfigProvider 收敛色板 + tokens.css（间距/字号/灰阶/圆角/亮暗双主题 CSS 变量），内联 style 逐页迁语义 class，学习正文（md-body）阅读排版单独强化。否决换组件库：深绑成本（Arco 变量 fallback 遍布内联 style）+ ADR-0051 运行时依赖论证制默认否决；丑的根源是「没有设计意图」不是组件库。

边界与后果：

- **门册判据修订随实施票走**：文案逐字锁降级为语义锁（canonical 词条词出现 + 交互行为断言 + Avoid 词反断言）；页签三表门按五区+两级路由重建（唯一执法者地位不变）；SSR 冒烟冻结表新页显式归类；api 调用点棘轮随票显式迁移。照章程「门红了先裁决」：判据修订=修门，登记 tests/README 门册并带 ADR-0047 自检，禁止静默放宽。单文件 500 行硬预算不动，新页全部目录化拆分。
- **与 #200（终点感知面与统计口径）协调**：#200 是本改版前最后一张压在图页/学习页上的 UI 票，先行落地或吸收进改版壳票，票面登记取舍；改版不改终点性语义本体（ADR-0055/0056）。
- 语义级细节（供给卡形态、工作台分栏明细、token 取值）在改版 spec 票面，不进本 ADR；CONTEXT.md 零改动——节奏三循环是 IA 结构不是领域概念。
