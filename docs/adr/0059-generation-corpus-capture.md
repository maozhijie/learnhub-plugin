# 生成语料捕获 + token 计量（缝合点）

决议（#213 收口，2026-09-13）：宿主 LLM 适配器的缝出口全量捕获真实模型调用，落「生成语料」（CONTEXT.md 词条）——解析器回归 fixture 源、质量评审抽样池、模型/供应商更换时的格式漂移体检标本。本票是 #212 生成质量工作流的测量底座（#215 冒烟、#216 工具调用 spike、#220 语料回放、#222 离线评审器都消费它）。裁决细目：

1. **捕获点 = host/llm.ts 缝出口（`withCapture`），不是 AgentSeam.onCall**：LLM 调用分两族——六策略站经 AgentSeam（带站名），大纲/节生成/拆节/出题/判卷/笔记出题/错误对比卡/回执评审/讲解反馈/自注反馈等走裸 LlmComplete 注入（`llmSeam`/`llmSeamStripped` 工厂直出，不经 AgentSeam）。onCall 只能看见前一族；适配器出口（`llmComplete` + `llmStreamSeam` + 教练讲解的两处 `llmComplete` 直调）是唯一全覆盖点。dsh 耦合仍 100% 收在 host/llm.ts（ADR-0044 不变），捕获器本体住新文件 host/corpus.ts。
2. **站标签两级贯通**：端口 `LlmComplete` opts 加可选 `station`/`kind`（complete/repair/loop，对齐 AgentCallMode），`LlmStream` req 加 `station`、返回加 `usage`。AgentSeam 调端口时恒传站名与形态；多站共用缝实例的管线调用点（jobs.ts 内容管线一个 complete 贯穿大纲/节/拆节/出题四站）在调用处传 `opts.station`；单站注入点（handlers/tool-handlers 的一路由一站）由工厂第二参闭包携带（`llmSeam(ctx, capture, '判卷')`）。优先级：`opts.station` > 工厂闭包站名 > `'未知站'`。站名词表 = PROMPT_KINDS 站名（课程大纲/课程节生成/课程节拆分/题目生成/笔记出题/错误对比卡/回执评审）∪ 判卷/申诉判卷/讲解反馈/自注反馈/老师辅导/讲给我听 ∪ AgentSeam 六站（种子起草/教练生长/罗盘/目标反编译/计划草案/里程碑草案）。
3. **token 计量**：dsh 的 usage 是 finish 之前发出的独立 chunk（顺序有保证），现状被丢弃——`streamDshTurn` 收进返回值并投影成端口中立 `LlmTokenUsage`（inputTokens/outputTokens/reasoningTokens，字段名恰同直通）。消费两路：补全缝经 `opts.usageSink` 回程上浮进 `AgentCallRecord.usage`（观测面 console/运行日志带 tok 数）；语料 frontmatter 记 `usage: { input_tokens, output_tokens, reasoning_tokens }`。端口返回类型不变（LlmComplete 仍返 string，零波及十五处裸缝调用点）。
4. **outcome 三态与补标**：捕获时初标——成功 `ok`（截断随 truncated 标记）；调用级失败（流稳定错误码/空闲超时/空输出/降级重试后仍败）当场标 `failed`+稳定码后**原样上抛**（捕获不吞错、观测不挡调用）。解析级失败/容忍在捕获之后发生，由宿主可达点补标（`annotateLast(站, {outcome, code})`，frontmatter 行级补丁 + ok/bad 桶间迁名）：失败经宿主 catch 点（大纲修复轮/节终局/拆节/出题门/图域任务 phase→站映射/生长批）；**容忍命中经 `outlineApply`/`splitApply` 的返回值通道出引擎**（返回形状 `SectionManifest[]` → `{ sections, tolerated }`——两方法返回值此前无消费者，零波及）。站内对齐语义：队列泵单并发 + catch 紧随该站调用，「最近一条」即死因样本；面板判卷与队列并发时站不同不干扰。**v1 边界（如实登记）**：引擎内循环的容忍/失败不出宿主——判卷重问、出题逐题修复（repairInvokesOnce）、块级修补成功等中间态的捕获停留 ok；这些形态的精确补标待后续票（捕获本体已在案，原料不丢）。
5. **落盘与环形**：`<学习中心>/state/生成语料/<站>/`，一调用一文件（frontmatter：ts/station/kind/effort 语义档/outcome/code/truncated/duration_ms/usage/provider/model + `## 提示词` + `## 原始输出`；回路的提示词段是逐轮可读渲染，工具调用只记名）。保留：失败与容忍必存但环形封顶（bad 桶 **200/站**，票面「突破环形单独封顶 200」的可执行读法——必存区防无界增长），成功环形 **25/站**（ok 桶）；桶编码进文件名前缀（`ok-/bad-<ISO>-<站内序号>.md`），修剪是纯目录操作零内容读，补标迁桶时同步改名。写盘异步 fire-and-forget、站内串行链（record 后立刻 annotateLast 的真实形态下补标不会读不到文件）、故障静默；`lastRef` 登记同步（失败详情取引用不等写盘）。GenJobFailure 加可选 `corpusRef`（语料区相对引用），面板失败横幅带出便于回看死因。
6. **G9 裁决**：语料写入是单文件遥测写、无跨文件一致性——**不入 runWriteUnit 站点表、不写 journal**（journal 只记领域事实，不记观测面；语料本身就是逐调用的完整留痕）。G8 不受影响（engine 侧零新增 fs/时钟直读；捕获器住 host 直用 node:fs）。行为快照的 calls 记录注入缝闭包的函数源码文本，llmSeam 工厂体与管线 lambda 变化随本票重录（tools 4 条 / routes 17 条，status/text 零漂移、diff 逐条人审）；G5 基线同提交迁移（corpus.ts 新登记）。

工程影响：端口类型加宽（engine/llm.ts）、AgentSeam 传站/形态/usage（engine/agent.ts）、适配器捕获（host/llm.ts）、捕获器（host/corpus.ts）、runtime 装配 `rt.corpus`、管线/路由/工具面站标签与补标接线、`GenJobFailure.corpusRef`、UI 失败行带语料引用。实测链：`tests/corpus.test.ts`（捕获器七态：落盘形态/双桶环形/补标迁桶/静默语义）、`tests/llm-capture.test.ts`（适配器捕获/失败上抛/AgentSeam 贯通/回路/装配端到端）、`tests/agent-seam.test.ts` +1（usage 回程与站/形态下行）、`tests/host-runtime.test.ts` +1（容忍补标全链：outlineApply tolerated → 管线补标 → 落盘 tolerated）。
