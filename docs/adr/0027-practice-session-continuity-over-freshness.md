# 练习会话连续性优先于数据新鲜度

练习会话曾会被三类数据事件整页打回开头：切页签的组件卸载、「AI 再出题」的非静默刷新、后台生成完成边沿的整页刷新——生成内容一变化，正在作的题就从头再来。我们决定页签 keep-alive 常驻（首访后不卸载、非激活隐藏、后台轮询跳过），且会话存续期间题目集与正文不热替换：用户主动「再出题」走增量并入（新题按节追加进轮次、已有进度不动），后台生成/修订一律冻结到本课结束后重进生效、只给轻提示。备选的弹窗询问每次打断节奏、全静默热替换让正在阅读/作答的内容脚下移动，均否决。代价是会话期间可能短暂练习旧版内容，由轻提示显式告知；已推进题的直通披露口径见 CONTEXT「直通卡」。
