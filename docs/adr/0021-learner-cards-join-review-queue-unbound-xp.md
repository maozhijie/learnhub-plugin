# 学习者产出卡汇入复习队列：呈现统一、账本分家（无绑定 XP）

决议（#102，2026-09-09，grilling 会话收口）：E1「我的卡」汇入 canonical 复习队列——同一「待复习」入口、同一风险排序、同一复习会话流；复习入账走**无绑定 XP**。本决议修正 ADR-0009 在 Learner Card 上的两条隔离条款（「隔离自调度、永不汇入 canonical」与产出零 XP），ADR-0009 其余产出（讲解稿、自注解释判词、JOL 预测、目标偏好）与掌握度排除逻辑原样不动。

## 裁决细目

1. **队列合并，测量面不扩**：我的卡进 `reviewQueue`（跨课程 R 风险排序、单节点定向入口同样并入），复习会话按卡种分面渲染（题卡=作答+AI 判卷；我卡=重述→翻面对照→自评）。我卡的 FSRS 维持默认参数（与笔记源同一 `sched(null)` 通道，参数优化器暂不训它）；真实保留率、JOL 抽查、Anki 导出、复习日志（review-log）均**不含**我卡——它们是测量与调参通道， populations 不因呈现合并而改变。
2. **掌握度面零掺入（ADR-0009 该条保留）**：不进 Mastery、作答正确率、练习证据 EMA、完成门禁、settle 定价；不写题库卡/节点代表卡任何调度统计字段。合并的边界=「到期就是到期」的学习者视角，不是证据升级——自造卡与节点的关联仍未校准（ADR-0009 §证据校准性），升格为练习证据仍需单独决议。
3. **无绑定 XP（Unbound XP）**：我卡复习按与题卡同公式、权重 1 入账（`max(1, round(难度))`，难度取卡自身 FSRS difficulty、未调度取中性 5；自评不过/忘记 0）。账目落中心级 journal 行（`kind='xp_learner'`，`course='*'`/`node='*'` 不绑实体），`detail` 带卡 id + source_node 出处。计入总账、每日目标、streak（聚合层 `sumXp`/`activityCounts` 本就不看归属，零改动）；不进逐课程/逐节点报表（`journalTail(course)`/`sumXpByCourse` 按真实课程名过滤，`'*'` 天然出局）。「手动归账」**不做**：出处已在 detail 里，未来归账是视图层查询，不是数据迁移。
4. **笔记源卡同权**（同批裁决）：笔记源复习是真作答（AI 判卷有对错），恒 0 XP 与 ADR-0019「真专注不记=账本系统性低估」相悖。改同权入账：作答时按题卡同公式结算（含乱猜负 XP），落 `kind='xp_notesource'` 无绑定行（笔记源绑的是伪课程，本就不进节点账）；忘记申报落 0 XP 行保 streak 口径一致；挂起路径（答对等自评）XP 在作答时即落——与题卡 practice 流水同时点。
5. **UI 收敛**：「我的卡」横幅与「刷我的卡」独立入口撤除，「管理」面收进「待复习」区块；`learnerQueue` 引擎面保留（管理面与 agent 清点用）。

## 为什么不绑到节点

每张我卡都有 `source_node`，XP 按卡归节点看似更精确，但节点侧账本三处消费面会被污染：`practice.jsonl` 必绑 course+node+题号且喂作答正确率与练习证据 EMA（掌握度原料，裁决 2 排除）；journal 按节点聚合的 `xp` 进 settle 差额（改变节点定价）；逐节点报表混入自评专注造成「为什么这题没 XP」的归因混乱。无绑定条目让「总账诚实、归属干净」同时成立：真实专注都记了（ADR-0019 立场），但只记在该记的口径里。

同批被拒：会话混排但 XP 绑节点（污染面见上）；真合并一套语义（我卡拿作答正确率/进 Mastery——证据校准性不过关）；为无绑定 XP 即刻建手动归账功能（无失败案例支撑，出处已备）。

工程影响（供执行票消费，非本决议约束）：CONTEXT.md 五处随本决议修订（Review Queue / Learner Card / Learner Output / XP / 新增 Unbound XP）；`learnhub_learner_queue` 等 agent 工具描述同步。未来方向：JOL 抽查扩我卡（自评校准的天然数据源，#100 同款直觉）、Anki 导出含我卡、参数优化器纳入我卡、按 detail 出处归账的视图。
