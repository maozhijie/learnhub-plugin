# 生长链路的四个阻断收口：判据与动作同量纲、插入批的预注册写入面、取消与预算的真出口

2026-09-17 第三次审计（四路并行）的阻断组（#312 B1–B4）。四处都是**判据与动作错位**或**文案指向不存在的动作**这一类：系统在无人值守下自己把自己卡住，而消息里给出的出路没有接面。本 ADR 记裁决与理由；施工面（行号、按刀叙述）归票面。

## 裁决

**一、就绪判据换量纲：`unstarted`（未开始存量）判达标，`ready`（正文存量）降为学习面读数（B1）。** 事故形态：`queue_idle` 检查点判「正文存量 < 前瞻需求」→ 入队生长批 → 生长批**只落结构**（ADR-0078 撤了正文自动入队）→ 存量永不上涨 → 队列排空again → 再入队，无人值守地连续跑「思路官 fast + 执行官 deep」（实机 35k token、零结构发布）。判据挂在动作**改变不了**的量上，环就闭不上。修法：`readyDepthCheck` 的两个存量同源一出——`unstarted` = 图上还没开始的节点数（除终点），`ok = unstarted ≥ required`；`ready` 保留为「就绪前沿里有多少条已生成正文」的读数（结构达标而正文为零时单出一行告警，指明显式下发通道）。宿主入队闸与教练回合的停机短路共用这一个 `ok`，量纲因此唯一。
**为什么不是「就绪前沿」（可立刻开学的节点数）**：生长批追加的台阶挂在未开始的节点后面，**不涨前沿**（`readySet` 要求非 opt 前置全部达标）——挂在它上，判据与动作仍是两个量纲，自激照旧（这一版实现过、被本票自己的复审打回）。`unstarted` 是生长批**每次**都必然追加的量（每个新节点出生即未开始），也是最贴词条「前瞻步数」的口径：**路还剩多长**。

**二、插入批的复诊预注册补上写入面（B2）。** 受理门要求「`operator=插入` 且有 `add_node`」必须携带 `note.recheck`，而草稿侧三处都没有它：`draft_patch` 无该参数、`EditProposalNoteLite` 无该字段、提案形态装配不透传——**六算子里的「插入」经执行官站结构性不可发布**，与它背后的复诊账本（#146）一并不可达。修法：`EditProposalNoteLite` 增 `recheck`；`draft_patch` 增 `note_recheck`（取值域与 clamp 走提案侧同一个 `recheckPreregOf`，校验先于任何变更、拒收即整批回滚）；提案形态在 `batchSpecOf` **单点装配**时落它——试算 / 审计 / 发布三处同调（#309 建立的同源不改），且「本批是插入批而草稿 note 没写」时用思路官交接计划里的那一枚兜底、并在**补丁期就地落进 `doc.note`**（只靠发布时读当时的计划兜底，跨轮续建的批次会被后一轮的计划换掉判据甚至换没）。工具 description 与交接块都写清取值域与「写哪儿」。

**三、`cancelled` 与 `failed` 同权：显式请求可覆盖（B3）。** 取消分支在 `force` 判定**之前**无条件返回，而文案写「可等下一次触发」——下一次触发命中的是同一条分支：一门课取消过一次就锁死整个终态保留期（24h），连面板显式下发都进不来。修法：取消与失败同权（自动触发照旧被挡，面板「生长一步」/生成页「重试」可覆盖）；文案改成点名真实存在的动作；生成页对 `cancelled` 也挂「重试」，不再只给 `failed`（同款「交互诚实性」）。

**四、轮次预算从「入口抛」挪进回路，并给草稿取消一条生产出口（B4）。** 命中预算的入口抛让每次触发**先烧完思路官两轮**再当场失败，而文案里的「显式取消」当时零生产调用点（无路由、无面板、无 agent 工具）——该课程此后除手删磁盘文件外无出路。修法两条：① 预算提示改在草稿站内生效：入口不再抛（照进站），`draft_patch` 追加被拒并点名收束动作（`draft_finish` 发布已备好的批、`draft_revert` 撤掉卡住的增量），收束动作与撤销一律放行；② `coachDraftCancel` 接生产出口——注册表一条命令两个通道（agent 工具 `learnhub_coach_draft_cancel` + 面板路由 `POST /coach/draft/cancel`）＋ 教练台「取消草稿」按钮（只丢未发布增量，已发布的批次已落图）。错误文案只许指向真实存在的动作。

## 替代方案（否决）

- **B1 改为「把 `applied` 并入重拉阻尼」（票面另案）** —— 三行就能断环，但判据与动作仍然错位（检查点继续拿正文存量判「低于前瞻」，只是被阻尼压住不再触发），且成功一批之后自动生长全线停摆：学习者推进使结构变薄时也拉不起来（要等人工「生长一步」）。量纲错位的账迟早再还一次，故取换量纲。
- **B1 用「就绪前沿」（可立刻开学的节点数）当判据** —— 本票第一版实现如此，被复审打回：追加在未开始节点**身后**的台阶不进前沿（`readySet` 要求非 opt 前置全部达标），判据对最常见的「前进批」毫无反应，自激原样保留。判据必须是生长批**每次都会**改变的量。
- **B1 保留 `ready` 为判据、另加一个「结构缺口」字段** —— 两套判据并存，宿主与教练要各自记得用哪一套（本票的病根正是两处口径漂移），且 UI 的达标语义分裂。废弃。
- **B2 只加工具参数、不做计划兜底** —— 执行官忘了写就整批被补丁期门拒（#309 落地后 schema 面在补丁期就查），白烧一轮；而计划里的那一枚本来就是这一批的判据来源。反过来说，兜底**只兜底不覆盖**：执行官显式写的那一枚优先。
- **B2 让 `draft_patch` 从 `doc.note` 之外再存一份 plan 快照** —— 草稿里多一份与计划同步的状态，计划换了它不换，又多一处漂移面。计划当轮就在 `opts.plan` 里，就地取。
- **B4 直接删掉轮次预算** —— 预算防的是回路空转（真金白银的护栏），本票的病是「撞上预算后没有出路」，不是预算本身。
- **B4 取消即删记录（票面另案）** —— 取消记录是面板可见的中止意图，即时删除会让「上一批为什么没了」不可查；取同权豁免 + 文案写实。
- **给面板加「草稿在途」状态读数再据此显示按钮** —— 状态面没有这个读数，加它要动 `statusJson` 形状与两面基线；本票按「最小出口」只给按钮 + 路由 + 工具，按钮在无草稿时如实回「没有在途草稿」（合法空态，不是错误）。

## 不做什么

- **不动** `readyDepthCheck` 的 `exhausted`（尾段前沿清空）与冷启动 `required` 口径；不断言「正文存量」为无意义读数（它仍是学习面读数与结构达标而正文为零时的告警源）。
- **不追**「一批 op 全是不加节点的改接」这类残余：那种批不涨 `unstarted`，队列排空仍会再拉一轮——教练自己的「停摆/暂不产结构」裁决与 #309 的回路预算、同错误熔断是这一层的兜底（本票不再另设阻尼）。
- **不动**重拉阻尼的其余分支（`idle` / `no_structure` / `failed` / 在途防重入）与 `inject` 的豁免语义。
- **不动**提示词文本（`src/engine/prompts/` 一字未动，故不过 prompt-bump 两道门）；本票新增的模型可见文本都在引擎侧工具 description 与交接块渲染里。
- **不做**草稿的部分撤销语义、不做摘要级草稿状态机——撤销归 #309 的 `draft_revert`，本票只保证预算耗尽时它照常可用。
- **不追**事故草稿与历史作业记录的迁移：存量在途草稿按现行读侧照常续建。
