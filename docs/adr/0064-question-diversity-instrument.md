# ADR-0064: 出题多样性仪表与基线测量

日期：2026-09-13 ｜ 票：#230 ｜ 总纲：#212 ｜ 证据：#225 报告 §5、§9（docs/research/2026-09-generation-methodology.md）

## 背景与问题

#225 调查列出的四个真缝隙之一是**多样性轴全仓零测量**：防相似门（#119）只防字面近似（归一化精确 + trigram ≥0.8 的近乎逐字重复），对「同构题」（换皮不换结构）与「众数化干扰项」（四个选项里三个是填充物、正确项位置固定）完全不可见。而格式约束的多样性坍缩是有实证的威胁（arXiv:2607.18476：仅加一句「Reply with JSON only」使众数答案占比 41%→64%），#212 §五又把「格式敏感度」写进了结构化路线的判据——**没有基线，三轴判据里「创造力」那一轴只能靠感觉**。

## 裁决

### 1. 三指标 + 第二读数（`src/engine/question-diversity.ts`）

纯函数、零副作用、无门禁、不写盘。口径逐条写死（改口径 = 改基线，基线随测试执法）：

- **批内题型分布熵**：按 `kind` 计数的香农熵（bit）；定义域 = 本批实际出现的题型，故上界 = log2(不同题型数)。八题型分布的实测熵落在 (2,3) bit。
- **干扰项对编辑距离**：单选/多选题单题 `options` 两两**归一化后**的 Levenshtein 距离（插入/删除/替换各 1），题内取均值、批内按题量平均；另报范围内**最差一题**（`min` + 题面点名）——「哪个选项组最像」可直接定位。归一化剥标点，所以 0 是合法读数（选项仅靠标点区分，是真发现，不是指标故障）。
- **题面 self-BLEU**：每道题相对批内**其余**题面的多参考 BLEU（1–4 阶、**加一平滑**、标准 BP，参考长度 = 其余题面平均长度）；按题面长度加权平均。**平滑是必需的**：中文短题的 4-gram 频繁零匹配，不平滑会把分数机械压到 0，指标就变成「句子够不够长」而不是「像不像」。
- **平均对相似度**（同轴第二读数 = **跨批漂移的读数**）：字符 trigram Jaccard、按题面长度加权——与查重门同源算法（trigram），读法直接可比。

**为什么漂移读数落在第二读数而不是 self-BLEU**（代码评审实测，写进裁决以免被误读）：BLEU 的多参考定义逐 gram 取各参考的最大计数，**参考集越大命中越容易**——同一份语料取前 k 道实测 self-BLEU k=2→0.061、k=12→0.370、k=40→0.505，而平均对相似度同区间只从 0.000 走到 0.036。所以题库变大本身就会推高 self-BLEU，「题库累计 self-BLEU 在涨」不能直接读成「越来越趋同」。**跨批比趋势用平均对相似度；self-BLEU 是同量级样本之间才可比的读数**（两批题量相近时的批内 self-BLEU 对比是合法读法），报告随身带样本量正是为此。

**缺席 ≠ 0**：样本不足的指标**不落键**（单题批没有 self-BLEU、无选项批没有干扰项距离），报告面如实写「无样本」。0 是「测到了、确实趋同」的正读数，两者混一起会把「这道轴本批没有测量对象」读成「多样性为零」。

### 2. 两个范围，一个报告（批内 + 题库累计）

`questionGenerate`/`questionGenerateSections` 返回值增 `diversity: { batch, bank }`：

- `batch` = 本批**入库**题（被查重/门禁丢掉的题不构成学习面，不计入）；
- `bank` = 入库后**全库非归档题**（与查重基线 `bankStemList` 同口径；归档 = 不参与学习）。

分开报是为了让**批间漂移**可读：批内读数回答「这批生成得像不像话」，题库累计回答「这个题库长成什么样」。批内只在批大时才有分辨力（1 道题报不出题面轴），题库累计是随库增长的那一份快照；**跨批比趋势看平均对相似度**（见上一条：self-BLEU 随参考集题量偏高，不宜单独承载趋势）。

### 3. 报告面（不改门禁、不改生成行为）

- 出题任务消息追加「多样性 熵 x（n=…） / 干扰项距离 y（n=…） / self-BLEU z（n=…） / 相似度 w（n=…）」，数字取**题库累计**范围并**每项带样本量**（避免把 2 道题算出来的 0.4 读成 30 道题的值；缺席项写「无样本」，因为缺席与 0 在这一轴是两件事）；
- agent 工具 `learnhub_question_generate` 返回值带完整 `diversity`（两范围全字段），供会话侧分析；
- **不进门禁**：三指标不参与任何调用的成败判定、不影响 `added/duplicates/rejected`。全批被查重丢光时沿用既有「一道都没入库」fail loud 语义（零入库没有返回值，批内读数自然不入报告面——这是「不进」而非「报 0」）。

**行为探针面登记（ADR-0045 §零漂移纪律；代码评审抓出的漏登记，补记如下）**：本改动**没有**动工具名、schema 与路由响应形状，动的是两处探针网**照不到**的地方，逐条如实登记以免被读成「已覆盖」——

1. **出题任务的 `done` 消息**：路由行为快照只录 POST /question-generate 的**入队响应**（`{key, message, queued}`，见 `tests/fixtures/host-routes-snapshot.json`「POST /question-generate · 全参」），done 消息属响应之后的 fire-and-forget，不入快照（routes-probe 的既有取舍）；
2. **`learnhub_question_generate` 的成功载荷**：工具面行为快照里该工具的记录恒为 `error: Cannot read properties of undefined (reading 'length')`——探针的录制式引擎替身让任务在结果取回前就失败，**成功载荷从未进入门 ⑦ 的采集面**。

所以「探针快照零变化」是**探针面覆盖不到这件事**，不是「探针面证明了零漂移」。两处新内容的覆盖靠 `tests/question-diversity.test.ts` 的全链断言（返回值带 `diversity`、批内样本 = 本批入库题、题库累计排除归档题）。若后续要坐实在快照网里，须给该工具补一条能走到成功分支的探针（超出本票范围，登记为已知空白）。

### 4. 基线入库（可复算，不是一张数字表）

- 语料：`tests/fixtures/bank-corpus/`（vault 存档区 4 份题库 YAML 的**原始文本**快照，2026-09-10 存档课程，65 道非归档题）+ `MANIFEST.json`（来源相对路径/题量/字节数；**不记 vault 绝对路径与时间戳**——机器级配置不进仓库，重抽才可能逐字节同结果）；抽取器 `scripts/bank-corpus-extract.mts`（幂等，`--check` 比对 vault，`--vault` 可指定）。
- 基线：`tests/fixtures/diversity-baseline.json`（逐文件 = 批、全语料聚合 = 题库累计）；测量器 `scripts/diversity-baseline.mts` 与出题运行时、与 `tests/question-diversity.test.ts` **调用同一组函数**（含题目投影 `diversityQuestionOf`）——基线的数字不可能与运行时读数用两套算法。
- 执法：`tests/question-diversity.test.ts` 的基线回放测试逐值比对（含两条自检：`sameMetrics` 能被改坏的值打红——门册 ADR-0047 的纪律；以及「基线数字是人读得懂的真事实」正断言，防基线被改成恒过）。口径一改、语料一增，测试立刻红——必须重测基线并人审 diff。
- **回放复测**：生成语料捕获（#213 / ADR-0060）落地后，同一组函数可直接跑新批语料，与该基线同口径对照；批间漂移曲线由每批报告的 `batch` 读数**跨批**比较（两批题量相近）或 `stemSimilarity`（对题量不敏感）承载，不需要另建时间序列存储。

## 后果

- 结构化路线（#216 双臂协议）拿到多样性轴的**预注册基线**：「税若存在，出现在多样性轴而非正确率轴」现在有对照数字可测；#222 评审抽样池与 #220 语料回放都直接消费本报告。
- 「多样性 ≠ 质量」写死在模块头与票面：高分只说明不趋同，不与量规评分合并成单一分数。反过来说，**低分也不是缺陷判决**——本批测出熵低、self-BLEU 高只是线索，是趋同还是「本节点本来就只有一种考点」要看题材，判断权在评审抽样池。
- 语料是**只读快照**：基线随 vault 演化会过期（新批语料不自动进基线）。这是有意的——重测是一次带人审的行动，不是后台自动发生的事。
- 归档题排除口径与查重基线对齐：归档旧题后重出相似题是合法意图（ADR-0032），若把归档题算进 bank 读数会凭空造出「趋同」信号。
