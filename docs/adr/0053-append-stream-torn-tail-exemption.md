# 追加流水撕裂尾行豁免：中段损坏即 Broken

ADR-0004 立了「用户数据区分缺失与损坏」的总纲，但追加流水（JSONL）的行级损坏契约一直没定稿。#4 盘点出**两套并存且未登记决策的纪律**：宽容版 `readJsonlLines`（`engine/io.ts`，跳过任何坏行；practice/journal/erratum/band/habit/边实验账本/data-check 复诊扫描共用）与三处手写严格版（`reviewLogAll`／`receiptsAll`／`eArchiveAll`：缺失=合法空、坏行=抛 Broken），外加 `execRecsAll`（project-exec.ts）第四处手写宽容版；data-check 复诊扫描读 review-log 走宽容原语，与 store 同一文件的严格版**今天就在互相矛盾**。本 ADR 把契约定稿，唯一判据钉在 `appendFile` 单行追加的物理保证上：**换行结尾的行解析失败即 Broken；文件末行不以换行结尾且解析失败 = 撕裂尾行，合法可规范化**——appendFile 一次写「整行+\n」，进程中断最多烂在末行、且必然不带换行，这个物理特征可机械判定，不是品味。Missing（文件不在）仍是合法空态，不变。

关键裁决：

- **单一原语，全流水必经**：`readJsonlLines` 改造为唯一实现，全部 JSONL 读侧必经；三处手写严格版与 `execRecsAll` 退役改调原语（各流错误文案前缀 `[review-log]` 等保留，报错带路径+行号，沿用「（Broken）：修复或删除该行后再试」口径）。
- **一刀切，无展示原料例外**：habit repeats 等「展示原料」流同样统一——撕裂尾行豁免已精确覆盖中断场景，中段损坏没有任何无责解释；ADR-0004 的不降级原则不按消费面贵贱打折。practice.jsonl 喂 mastery/校准/错误挖掘、exec.jsonl 喂练习证据回流，静默丢行正是 ADR-0004 点名的污染场景。
- **爆炸半径 = 依赖面自然阻断，dataCheck 是唯一例外形态**：读该流的消费方显式失败（mastery/仪表盘/优化器拒算带病数据，#3 user story 10）；dataCheck 读坏流不炸，把 Broken 报成 finding——体检的本分是可见性，不是第一个被阻断的消费方。
- **生成任务注册表（单文件 JSON）Broken 的爆炸半径收在队列级**：恢复处捕获 → 队列 broken 态、生成页显式报错 + 修复指引；**broken 期间拒绝一切写回**（入队/开跑/清扫等一切注册表全量落盘路径）——否则下一次入队会把坏档全量覆盖，等于静默销毁现场。不升格为宿主硬失败：注册表不是学习事实源（任务可重新下发），这是 ADR-0004「阻断依赖它的操作」在非事实源上的应用，不是豁免。
- **提案注册表逐条最小形状契约**：`id` 正整数、`status` ∈ {pending, applied, rejected}、`artifact` 非空、`pair` 若在必须指向列表中存在的 id——`pairApplyBlock` 联动守卫与复诊对账吃这些字段的合法性，形状坏会把对账不一致静默误判成正常单边。
- **Data Check 并入现有体检**：新增 `evidence_streams`／`proposals`／`gen_jobs` 三 area（盘点矩阵见 #4 正文）；撕裂尾行以 hint 浮出（不进 status，与 archived/hint 先例同款）；gen_jobs 悬空记录不进体检（归 ADR-0039 恢复清扫，避免双重处置）。

边界：

- 配置档（`state/learnhub.json`）的宽容回落不变（ADR-0004 明文：fail loud 针对学习者数据损坏，不是配置笔误）。
- 不自动修复、清理或隔离坏数据；修复仍手工，Data Check 给定位与原因。
- 行级 JSON 合法性之外不加字段级 schema（现状流水零 schema；per-stream 字段契约属各自域票），唯一例外是提案注册表的逐条形状——动机是守卫误判，不是泛化 schema 化。
- 落地拆四票挂 #4：统一原语+全量迁移、proposals 收严+体检 area、生成任务档契约+队列 broken 态、evidence_streams 体检 area。

替代方案（否决）：

- **一刀切严格（不豁免尾行）**——把进程中断的物理残留当损坏，让学习者为一行重启残渣手工修档；豁免判据（末行无换行）可机械执行，不存在「宽容范围失控」的滑坡。
- **保留分级并登记（证据严格/展示宽容）**——双纪律继续存活，每新增一流水都要重新选边；宽容版的全部正当场景已被尾行豁免覆盖，分级不再有增量，只剩两套代码和两套口径。
- **生成任务档宿主硬失败**——把可局部修复的损坏升格为全站故障，与注册表的可重下发地位不成比例。
- **隔离坏档 + 空表启动**——写操作，违反「不自动修复或清理」；且把任务记录丢失的可见性从显式报错降为一句警告。
- **提案只做数组级校验**——形状坏（status 拼错、pair 悬空）会让联动守卫与复诊对账静默误判，恰是「结构非法」要拦的主体。
