# 填空题只考唯一写法的术语

fill_in_blank 的答案边界定为「唯一答案填空」：只允许任何学过的人写出的正确答案在文本上必然一致的题（术语、名称、符号），数字与代数式一律不进填空——数字答案走 numeric（容差判卷），表达式答案走单选（正确式 + 典型错误干扰项）。填空判卷是文本全等比较，恒等变形的等价表示无法穷举（`2(x-y)²(x-y+4)` 与 `2(x-y)²*(x-y+4)` 已然判错，`(x-y)²` 与 `x²-2xy+y²` 更无可能），靠出题端列「同义写法数组」补不齐；自写代数等价判卷在 JS 生态无可行实现（sympy 路线曾弃），AI 判卷把可靠判卷换成概率判卷并放大成本。再认对回忆的折扣是接受的真实代价——换取的判卷结果是可信证据。存量违规题不自动改写，走只读体检清单，由学习者决定是否重生成（同 ADR-0004：证据不为便利而伪造）。
