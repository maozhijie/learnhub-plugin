# ADR-0103：LLM 调用记录——生成语料升级为按任务成组的完整请求/响应存档

日期：2026-09-17 ｜ 状态：已裁决（实施归票面）｜ 相关：ADR-0060（取代其 §5 语料形态）、ADR-0073（落盘形态并入本篇）、ADR-0080（调试日志「不落原文」边界不动）、ADR-0091（防双写判据）

## 裁了什么

**把「生成语料」升级并改名「调用记录」**（CONTEXT.md 词条改名、旧词退役）：从「按站的原始产出存档」变为「按任务成组的完整请求/响应记录」。

1. **落点与分组**：按**任务（课程/节点）**成组，一任务一个可读文件；无业务键的离线调用另置归档。旧 `state/生成语料/` 冻结、不迁移不删除（插件不删用户 vault 文件）。
2. **每次调用一节**：元数据头（序号·站·**来源**〔作业/面板/agent/单节重写〕·阶段·档位·模型·供应商·耗时·token·**尝试序号**·结果）+ **请求 JSON 原文块** + **响应 JSON 原文块**（+ 工具调用）。**凡适配点技术上可得的一律入档**——恢复此前被丢的 `system`/`tools`/`temperature`/`maxTokens`/结构化 messages/思维内容/工具调用 id/真实结束原因/缓存与总 token。
3. **两条如实登记的边界**：原始 HTTP wire body **拿不到**（请求侧上限=语义级 `GenerateOptions`）；补全缝的多轮在入口已拍平成字符串，只能记单条合成 user 消息。
4. **分组键泛化为 `course/node`**：凡有业务键的调用（作业/面板/agent 工具/单节重写）落同一 node 组，用「来源」区分；离线无键者入独立归档。
5. **覆盖两条并缝 + 重试逐次各记一条**：捕获点自重试包装**外层移进环内**（此前重试不可见、首轮截断与档位降级证据丢失）；排除 spike（开发装置）。
6. **读写分离**：组文件是**唯一主写产物**（不双写）；**重建一层「按调用读侧」**，既有三条生产读侧（冒烟站表／质量评审抽样／提示词回放）改由它取值。
7. **生命周期**：常开；默认保留 90 天、跨日惰性清扫；单文件软上限分卷；每站样本下限保底。**退役「成功 25/站、失败 200/站」环形**。

## 为什么

- **原形态不可读、信息不全**：一调用一文件 + 按站散落，读一个任务要翻遍多站多文件；被丢字段恰是分析问题的关键。
- **「任务」远不止生成任务**：实测大量调用（面板 tutor/讲解反馈/自注、面板作答判卷/申诉、agent 交互工具、单节重写）在作业之外且多带 `course/node`——只按作业分组会漏近一半调用。
- **原文早已落盘，缺的是可读入口**：观测面已有原文存档（ADR-0060/0073），但按站散落、成功只留 25 件——不缺「存」，缺「按任务读全、能读」。
- **重试此前不可见**：捕获点在重试环外，一次逻辑调用一条记录；移进环内即成逐次证据。

## 否决了什么

- **新建并列文件（不动生成语料）**：制造第二份原文事实源，与 ADR-0091 防双写漂移判据冲突。
- **只加「任务→调用」索引层、不升级正文**：不治「格式不可读、信息不全」。
- **组文件当「读侧派生视图」（写侧仍一调用一文件）**：最省迁移，但落盘=双写、不落盘=无文件；取代价可控的「主写产物 + 重建读侧」。
- **收原始 HTTP wire body**：插件拿不到，如实登记为边界。
- **纳入 spike／只收作业内调用**：前者是开发装置；后者与「覆盖两条并缝」矛盾。
- **沿用「生成语料」词**：身份已从「按站语料（回归素材）」变为「按任务完整调用记录（人读分析）」，沿用旧词会把旧语义带进新定义。

## 不做什么

- 不改 ADR-0080 边界：调试日志仍**只做索引、不落原文**；本篇升级的是另一通道（原文存档），不是给日志开倒车。
- 组文件只装 LLM 调用，不装引擎阶段步骤等非模型步骤。
- 不迁移、不删除 vault 里既有的 `state/生成语料/`。
- 不动模型面/业务面文本的引用纪律（ADR-0091 相关面照旧）。

**落地面**（新增捕获与读侧、三条生产读侧迁移、门册登记、逐字固化面同步）归票面与门册；本 ADR 只记裁决。
