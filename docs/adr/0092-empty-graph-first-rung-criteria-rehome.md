# 空图首级：起点资格判据迁家为教练材料注入（不开第三族）

生长式图的第一级台阶（空图 + 学习者手加终点时教练铺出的第一个可学节点）今天靠思路官临场发挥：ADR-0040 的起点资格判据（**单一行为单元 / 零复合概念 / 常识可起步 / 宁简勿繁**，含操作化正反例）原本住种子提案模板的「起点资格」段，随种子链整体退役（#256 / ADR-0081）后**未迁家**——而首级的裁决权同期移到了教练思路官（#273 两站编排）。2026-09-16 实机复盘（「数学基础」空课首裁）确认：两族思路官模板（常规生长族 / 显式重裁族）都没有任何冷启动指引，新课后第一次「生长一步」命中的恰是显式重裁族，判据真空两族同病。本次首裁结果尚可属侥幸，不可依赖。

裁决：**判据迁家为材料注入，不开第三族提示词模板**。引擎在思路官回合组装上下文包时判定「前沿为空」（排除终点节点后，未开始节点数为零——「仅终点」是其特例，删空普通节点后同样命中），命中即向包内注入一行首级判据块（判据四条 + 一句操作化反例警示），文本住 `src/engine/prompts/` 单源（ADR-0075 章法），注入点在教练上下文包组装处、与既有「裁决纪律：交汇优先」行同域；两族模板自动共享，模板文件零改动。

关键裁决：
- **判据是裁决纪律，不是站身份**——它约束「空图这一情境下怎么裁」，而情境可由引擎判定；可由引擎判定的条件用材料表达，不为情境新开模板族。模板族编码的是站的身份与契约，情境纪律编码进模板必然随情境枚举膨胀。
- **触发口径是「前沿为空」，不是「节点数 ≤1」的字面判断**——后者错过删空普通节点的怪态，前者在终点锚语义（终点不计入可学存量，见「前瞻深度」词条）下天然正确。
- **判据本体沿用 ADR-0040 原文，不重新立法**——种子时代的实测疼点（零基础自述下首级仍含复合泛称，坡道第一级即断裂）与生长时代完全同构；操作化正反例随行迁移。
- **「该判据只约束起草，不约束人手加的节点」的豁免照旧**——起草者由种子提案通道换成了思路官，人是权威的边界不变。
- **登记义务照走**：新提示词常量入 `src/engine/prompts/` 即触发提交级登记门扫描，按章程 §8 补 `PROMPT_CHANGELOG` 条目；注入的是包材料而非模板变更，是否 prompt-bump 以门实测为准。

替代方案（否决）：
- **第三族模板（思路官冷启动）**——族间漂移与维护税：同一裁决流程、同一算子集、同一输出契约，只为一段判据复制整个模板；此后每次裁决语义演进要三处同步。触发条件（前沿为空）本是引擎一步可判的事实，硬编码进「选哪个模板」的散文分发里。
- **两族模板各加一段**——判据文本两份重复，改一次过两次版本 bump；且模板无法自判「本次是否空图」，段落只能常驻，非空图回合白吃 token。
- **恢复种子起草通道**——已裁退役（#256 / ADR-0081），不为一条判据复活一条通道。

后果：思路官上下文包出现首个**条件性材料块**（前沿非空时不注入，包形与现状一致）；生长语料里空图首裁的提示词自此带判据行，语料对照（格式漂移体检、质量评审抽样）需知悉此前此后包形不同；首级质量有了可对照的量规出处（质量评审器按量规评分时，空图首裁样本对表本 ADR 所迁判据）。

词条同步：CONTEXT.md「教练思路官」补首级判据去向；「种子」词条的判据出处句改指本 ADR。

## §修订（2026-09-17 / #310）：补绑终点、派发判据、档位——三处都是「空图首裁」的端到端质量

**实机证伪**：2026-09-16「数学基础」空课首裁（课程名＝数学基础；终点锚＝大致达到理工科本科结业水平）产出「把一件日常事拆成先后步骤 / 说清每一步的输入与输出 / 对给定的简单规则按步骤手工跑一遍」三个节点——迁来的判据四条**全过**，朝声明终点的推进**为零**。执行官照计划落地，并在 note_reason 里写明「按零复合概念纪律拆成两个节点」：错的不是执行，是本 ADR 迁来的判据只给上界、不承担方向。

**① 判据本体：原裁决「判据本体沿用 ADR-0040 原文，不重新立法」被证伪。** 判据脱离起草上下文（种子提案里目标与领域同时在场）后，四条上界可被域外解同时满足；「宁简勿繁」的不对称论证（起点过简代价趋近零）更是单向激励，方向恰与「朝终点推进」相反。修订：补两条把台阶绑回**既有输入**——课程名与终点锚（ADR-0033「视角由目标携带」；系统无「学科」，不得为此新增该概念或字段），块头点名这两样；「朝终点可辨认」升为**先决条件**，起点资格四条降为「都朝终点推进的候选之间的**选型标尺**」；「宁简勿繁」限定为同向候选间的选择偏好；域外正反例（「Python 基础语法」✗ →「装好环境并运行第一行代码」✓）删除，改判据式说明（不收具体领域 → 模型无照抄范例）。材料注入的形态与触发口径（前沿为空）不变。

**② 族派发：原裁决「两族共享材料注入」只解决了判据在场，未解决首裁被派给重裁族。** 族选择只看触发点，而面板下发 → 重裁族——重裁族的叙述（沿用/推翻上次裁决）预设了一个**不存在**的上一轮，摘要块也取不到（空课无生长批历史），模型只能自己绕过。修订：族选择改为「**触发点 + 状态**」——本课程无任何已落盘的生长批时走常规族，有历史后照旧按触发点折叠。论据与本 ADR 原有裁决同构：触发条件本是引擎一步可判的事实，此前只用它判「注不注判据块」。

**③ 档位：首裁抬 deep。** 两站拆分后语义重量（算子、朝向、台阶意图）全在思路官侧，而它恒 fast、执行官恒 deep——计划错的代价由执行官以二十倍以上 token 支付（实测首裁 1.4 秒 / 121 输出 token，换来执行官二十轮 / 33.1k token 空转）。修订：**首裁（同一个「前沿为空」判据）抬 deep，其余回合维持 fast**。**已知边界（如实登记）**：插入算子同样是高语义回合，但算子由**模型输出**决定、调用前无从派发，本次不为它造新机制；维持 fast 的回合，其产出质量按票面要求作为被测量的对象（本 ADR 与 #310 即第一批样本）。

**不做什么**：不开第三族模板（原裁决照旧）；不为「插入」新增预判机制；不改起点资格四条的语义（它们是被降格为选型标尺，不是废弃）。

**收尾口径**：空图首裁的**端到端质量**（族是否对、档位是否够、判据是否绑终点）作为整体验收对象，而非只验判据文本——质量评审器对空图首裁样本对表本节。
