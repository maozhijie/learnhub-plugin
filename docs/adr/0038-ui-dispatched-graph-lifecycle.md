# 学习图生命周期全流程进面板：UI 下发命令替代 agent 会话交接

学习图生命周期（建课种子起草、生长一步、罗盘重画、enc 回填、目标反编译、项目计划/里程碑草案、复诊结算）的发起权从「dsh 会话里的 agent」移到 Web 面板：UI 直接下发命令（POST /learnhub/api/* → 全局串行生成队列，入队即返回），不再需要跳进 agent 会话粘贴指令。与 LLM 的交互仍由引擎的 LlmComplete 缝承载（#137）——变的是谁来按按钮，不是谁来调模型。agent 路径整体保留（工具全量在册、skills 照旧），AGENT_GUIDE 中已获面板控件的动作退出指南（分流纪律：面板能做的，指南不再宣传）；会话式 LLM（与 AI 讨论本课/讲解这道题）不搬——开放式对话仍是 agent 会话的正确形态。

理由：学习图是学习者自己的课程资产，其发起动作（建课、生长、换终点）是第一人称操作，不该以「对着 agent 转述」的间接形态存在——面板下发让每条命令有 schema、有按钮、有队列可见性，而转述路径的每一步都可能走样（提示词复制不全、SOP 遵守漂移）。机械复用是既成的：引擎侧提示词与缝早已就位（罗盘初画/教练回合/目标反编译 v8、compassPaint/coachGrowthBatch/projectDecompile 全部接收 LlmComplete），缺的只是 UI 可达性；本次只补种子提案提示词（「种子提案」v1 起草面 + 引擎 seedPropose）与宿主接线。

关键裁决：
- **传输复用串行生成队列，不引 allo 的同步长请求**。allo（姊妹项目）的「UI 下发」形态是同步 HTTP + 尽力而为 WS + 内存态运行注册表；本宿主无 WS 栈，且既有生成任务注册表已落盘可恢复（「allo 同语义」注释先于本次落地存在）。反编译/计划草案/里程碑草案从同步 HTTP 调用改为队列任务（phase=反编译/计划/里程碑为新值；种子复用预留的 phase=种子；罗盘 phase=罗盘）。
- **ADR-0003 维持不破**：面板触发的生长批是触发器不是门——过受理门自动应用，不引入预览-确认步；「生长一步」按钮的确认弹窗只说明语义，不拦截产物。种子保留一次人审（提案页既有人审）；反编译双提案联合人审照旧。
- **教练回合触发五点**（词条已更新）：节点完成/节点跳过/会话开始/队列空闲/面板下发。宿主 coachTrigger 统一出口，补上此前只接了 queue_idle 的欠账（引擎注释声称三点，代码零接线）。跳过与面板下发是显式重新裁决——即时入队、豁免停摆/暂不产结构阻尼（#149 计划修订注入同款）；自动触点照旧「检查点之后入队」。会话开始走 GET /status 与 learnhub_status 共用入口，30 分钟节流（检查点逐课程 loadView，不能跟面板 5s 轮询跑）。
- **就绪核算剔除终点**（词条「前瞻深度」已更新）：终点是锚点不是课程节点——课程尾段前沿只剩终点时，固定前瞻需求（默认 3）永不可满足，教练永不停摆、队列永不空。就绪存量与前瞻需求都不计终点；除终点外前沿清空（exhausted）判据自然通过、零告警，收尾交回终点锚完成语义。
- **起草绑定字段以表单为准**：种子起草的课程名/模式/目标类型/块工作表由表单收集、引擎受理前绑定写入（模型照抄错误也被覆盖）；起点三路不进表单——引擎从输入形态推断（勾选「参考我的笔记」→ vault 先验检索熟悉边界，缺省常识基线，带项目走项目页反编译）。

边界：
- 「与 AI 讨论本课」「讲解这道题」保持宿主桥 → agent 新会话注入（learnhub:discuss/explain 不动）——开放式对话不是命令。
- enc 回填是确定性推断（共现窗口 + 置信权重，零 LLM），同步路由受理，产物富化提案照旧人审。
- 复诊「立即结算」无确认步——它是零人审自动行为（#146）的手动触发，不是新决策面。
- 面板通知是纯客户端轮询（App 级 10s 任务注册表 diff + 60s 复诊在途 diff），宿主不加推送通道；被阻尼拒掉的重拉无注册表条目，自然不通知。内容类生成任务不弹（各页已有指示器）。
- #152 门面子系统化不受阻：新增路由先进现有路由表，刀 12 宿主拆分照常覆盖。本 ADR 取号 0038，#152 文本预留的 ADR-0038/0039 顺延。

替代方案（否决）：
- 面板内嵌聊天框驱动生命周期——命令有 schema，按钮+表单比自由文本表达得准；聊天是会话式 LLM（讨论/讲解）的形态，两者不混。
- 照搬 allo 同步长请求 + WS 进度——丢失重启可恢复性，为宿主引入第二套任务模型，且「进度帧不回放、HTTP 响应才是事实源」的复杂度换不来队列页已有的可见性。
- 生长批加预览确认——已被 ADR-0003 显式否决的逐批人审回潮，不修回来。
