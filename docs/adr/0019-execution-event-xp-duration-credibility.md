# 执行事件入 XP：时长可信性判据

决议（#99，2026-09-09，wayfinder 图 #73 执行事件裁决链收口）：执行事件**按其原生专注时长入 XP 账本**，与节点学习时间同账同权、进 streak 口径，不设特例。裁决细目：

1. **入账判据 = 原生专注时长是否可信，不属于哪个区**：执行事件是会话期落账的，时长原生可信→入；回执是事后补传的证据材料，时长不可证→零 XP（ADR-0016 原样不动）；习惯重复根本没有时长语义→不进 XP（ADR-0017 原样不动）。三条记录同属无界区，命运不同的原因只有时长可信性一条。
2. **XP 本质不变**：时间账本、记录系统（1 XP ≈ 1 分钟）；练琴一小时是真专注，不记=账本对真实专注量的系统性低估，与无界区「账本永不关闭」的记录立场相悖。激励与调度反馈仍是衍生需求，不是核心。
3. **streak 口径不分家**：执行事件 XP 与其他 XP 同一派生口径；漏天压力由 streak 宽容机制（#83）统一处理，不为实践 XP carve 免进 streak 的特例（缺动机）。
4. **不设反作弊门**：时长申报/计时造假=谎报自损（账本是自己的），与全场「自报即证据」同一立场；时长具体来源（会话计时 vs 学习者申报）归「交付：执行事件调度通道」（#89）实现定。

同批被拒：零 XP 按区对齐（把「无界区记录不碰账本」当原则，实则低估真实专注）；入账不进 streak 口径（多一个无失败案例支撑的特例）。

工程影响（供执行票消费，非本决议约束）：XP 词条与执行事件词条已随本决议修订（CONTEXT.md）；回执、习惯词条不动。「裁决：自评校准面推广——JOL 预测校准作为跨域「直觉 vs 实际」基础设施」（#100）随本裁决开口——执行事件携带的「自评表现 vs 客观判分」配对是 JOL 校准画像之后的第二个潜在数据源。
