# ADR-0104：学习图形态收缩——算子二值化、收束字段化与弧建议节奏

日期：2026-09-18 ｜ 票：#335 ｜ 状态：已采纳

## 裁了什么

**生长算子从五值收缩为二值**：`GROWTH_OPERATORS` 只留「新增 / 插入」。「巩固」降为新增条目的 `consolidate: true` 字段——收束批的语义由显式字段声明，不再靠算子取值旁带（巩固本来就不是一种生长方向，而是一种收束姿态；放进枚举让「方向」与「姿态」两个正交概念挤在一个键上）。「旁支 / 换向」退役：方向语义本来就住在 `note.target_endpoints`（朝向声明），旁支=挂在非前沿处的新增、换向=改接线的新增，都是「新增」+ 朝向/接线的组合，枚举值只是同一件事的第二种写法，且五值枚举给了模型五种「长得像不同决策」的路径、形态质量不可控（同一批既能铺链又能挂支还能收束，门判据被迫逐值特判）。

**接线义务收窄归一**：新增（原前进/旁支/换向全部）必须声明 `note.target_endpoints` 朝向（硬门）；插入免接线但必须预注册复诊。operator / recheck / consolidate 三键只随生长批的 add_node 携带。

**serves_arc 保持可选（升格必答后经用户裁决退场）**：曾按票面升格为「每回合必答」（收束前必须已声明，「（无）」附理由），实施后用户裁定退回——罗盘是大视角、低频结构物，每批强制申报会退化成例行公事式硬凑，对表材料反而失真；阶段级对表（弧段走完、切换服务阶段、结构性变化时给）才是建议权的正确行使节奏。保留的增量：软对齐对「（无）」声明留痕不计连击（明确的不对应比沉默信息量大）。原「必答」裁定的动机（罗盘拿不到对表材料）由阶段性行使 + 连击告警承接，不靠强制。

**配套读数**：难度步进门（步进 >1 拒收）与宽度读数（advisor-only）随本票先行落地（见门册刀②③段）；draftFindings 增 est 失配与单链批两条非阻提示。

## 为什么（实测）

- 五值枚举期间，混算子批的审计判据每值一条特判分支，旁支/换向的门差异只剩「是否免接线」一处——枚举的表面积远大于它承载的语义差。
- serves_arc 可选期间，罗盘软对齐的连击告警长期打不响：回路不声明不是失联信号而是默认省略，告警机制无从区分「没看罗盘」与「看了不match」。→ **此条随「回归可选」裁决不再成立**：连击告警只对「声明了但指认不出」计数，未声明不进 streak，可选语义下无误报；告警价值收敛为「声明的真实性读数」。

## 否决了什么

- **「（无）」也拒收**（强制每批都服务某阶段）：会逼模型硬凑阶段标题，对表材料反而失真——「（无）」+ 理由是真实的脱节信号。
- **巩固保留为独立算子**：收束批与普通新增批的门差异（只引已教概念、 sealed 裁决）已经全部由 `consolidate` 字段与 note 朝向承载，枚举值本身无判据可用。
- **难度步进门做成软提示**：步进断层是生成期一次性决定的结构事实，事后内容生成补不回来；软提示无回滚点。

## 不做什么

- 不迁移历史图面（旧「巩固/旁支/换向」节点与边保持原样，只约束增量生长）。
- 不给宽度读数接门（advisor-only，先攒读数）。
- 不做弧建议的结构化对账（serves_arc 与罗盘阶段标题的精确匹配仍是软对齐，人审兜底）。
