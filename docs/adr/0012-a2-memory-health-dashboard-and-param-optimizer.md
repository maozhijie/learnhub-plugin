# A2 记忆健康：复习日志作地基，仪表盘四面板与 FSRS 参数优化器立项

决议（#36，2026-09-08，Arc A2）：**立项，分三步走**——(1) 新增一条 append-only 的逐次复习日志（`state/review-log.jsonl`，约 9 字段）作共同地基；(2) 统计页交付记忆健康仪表盘四面板；(3) 从真实作答历史重训 FSRS-6 个人参数（≥400 条后启用）。三步是数据就绪的先后关系，不是三个独立方向。

**复习日志记什么、为什么不塞进 practice/journal**：practice 流水是**作答证据**（对错/判词/XP），journal 是 XP/内容账目——调度事件（rating、rating_source、elapsed_days、复习前 R/S/D 快照）与它们语义不同，混流会互相污染。现状三个缺口一次补齐：复习流自评 2/3/4 档只推卡不落流水（`questionRate`）、每次推进的复习前 R/S/D 无快照、`nodeComplete` 对未作答卡的合成 rating=3 首复习无记录。`rating_source` 三态 `auto`（作答自动映射）/`self`（复习自评）/`synthetic`（完成学习的调度初始化）；synthetic 不是真实作答，诚实度统计与训练数据一律排除，只作调度锚点（保证后续 delta_t 链正确）。这条日志同时服务仪表盘（真实保留率/预测对照/遗忘曲线）与优化器（`(rating, delta_t)` 训练序列）——一次落点两个消费方。

**仪表盘**：四件同版交付，负载预报与记忆状态分布现成数据立即可算（题库 q.fsrs 全量聚合 + `srs.ts::retrievability`）；真实保留率/预测对照/遗忘曲线靠复习日志数据积累自然填充，无数据给空态。「预测 vs 真实」的预测方 = **FSRS 自身预测 R**（模型校准诚实度仪），与 E4 学习者 JOL 自预测**正交**——本票不建学习者预测输入字段（那是 E4 的 `PracticeRec.predicted`），不重叠不等待。

**参数优化器**：ts-fsrs 5.4.2 无优化器导出；官方 `@open-spaced-repetition/binding`（npm 0.5.0，Node≥20、含 win32-x64）是 fsrs-rs 优化器的 JS 封装，输入 `(rating, delta_t)` 序列训出 21 参数。**参数归属 = 学习者级一套**（记忆参数不随课程分裂）：训练数据用中心级跨全部课程的流水，写回每个启用课程的 `fsrs参数.json`（调度读法不变，`getScheduler` 零改动）。门禁与触发：手动命令触发（与 Anki「优化不自动发生」同理，个人数据少时避免被噪声参数来回扰动）；真实复习日志 ≥400 条才训（官方口径每卡每天只算第一条，Again/Good 二值已够）；月频或每 +2^n 条重训；评估（时序切分 logLoss/RMSE）不优于现参/默认不写回；写回带元数据可追溯。

**词条**：仪表盘的读侧新度量立 CONTEXT 词条「真实保留率（True Retention）」，与 Mastery / 作答正确率区分（它衡量到期复习的实际答对比例与 FSRS 预测的校准，只读不参与门禁）。实施入口：#60（复习日志）/ #61（仪表盘，被 #60 挡）/ #62（优化器，被 #60 挡）。
