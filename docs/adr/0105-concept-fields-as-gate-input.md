# ADR-0105：概念字段升格为门禁输入——概念充分性门

日期：2026-09-18 ｜ 票：#336（门实现 + 读侧归一）、#337（提示词修订·人审） ｜ 状态：已采纳（取代 ADR-0084 §④⑤）

## 裁了什么

**`teaches` / `assumes` 与概念登记表从「感知面」升格为「门禁输入」。** `pre` 不变——仍是节点间唯一的学习顺序依赖与调度输入。反转的只是 ADR-0084 §④⑤ 的「不进**门禁**」那半：概念字段成为写侧受理的硬判据，但**不进传递闭包、不进调度**（§④⑤ 的「不进调度」「不参与传递闭包」继续有效）。

**新增「概念充分性门」**（进 `editGateErrors` 序列，与 #297 的 `teaches ≥1` 门、#335 难度门同档同序，在审计门之前；**增量判据**——只裁本批新增/改动的 `assumes`，不追溯存量）。对 `add_node` 声明的每条 `assumes{概念: 档}`，按 canonical 归一后判：

- **存在性**：该概念必须出现在本节点 **pre 祖先闭包（去自身）内某节点的 `teaches`** 并集里；
- **档位**：祖先 `teaches` 的档不低于本条 `assumes` 要求的档（知道 < 会用 < 能教）；任一侧缺档不判；
- **判定域 = 本课程 pre 祖先闭包**：闭包内被教 → 过；**本课图内被教但不在闭包** → 拒（漏连 `pre`，提示去 `set_pre`）；**本课图内没人教** → 放行 + 非阻提示「本课首引」（跨课例外）。

概念名归一**复用 `canonicalizerOf` 单一出处**：别名命中即算命中，不按原始串比对（否则复现收束门 #313 C12 的误拒）。`assumes` 不必填、缺席合法，在场即受约束。

**读侧同步归一**：`concept_footprint` / `node_card` 展示 canonical + aliases，否定结论带「已读全表 + 归一」证据，不靠子串空；判据与展示同源。

## 为什么（实测）

诊断实例：课程「数学基础」在**没有任何节点教「分数/小数」「幂/平方」**的情况下，长出了「化简分式并进行分式四则运算」「解一元二次方程并检验根」。根因不是提示词措辞——`教练执行` 的【依赖契约】写了充分性条款，但**受理门全序列（结构重放 / 概念对表 / 终点锚保护 / 巩固门 / 难度步进 / 误解封顶 / 生长闸门 / 审计门）没有一道校验概念充分性**，审计 R18 亦写死「只盘点、不校验语义」。**充分性是提示词里的君子协定，系统里没有牙**：模型漏报的 `assumes` 依赖，无任何机制可见。

## 否决了什么

- **只提示不拒收（非阻 findings）**：前置缺失是生成期一次性决定的结构事实，事后内容生成补不回来，软提示无回滚点。
- **`assumes` 进传递闭包 / 进调度**：把概念感知硬化成隐式依赖——正是 ADR-0084 §⑤ 的否决理由；调度依赖继续只归 `pre`。
- **跨课概念按缺口硬拒**：登记表跨课、概念天然跨课（ADR-0089 / #287），门零 IO 分不清「别课教过」与「全库没教」，硬拒会误杀复用；改为放行 + 提示。
- **按原始串比对概念名**：别名造成「同实异辞」被读成「没教」——#313 C12 已有前车。
- **追溯存量**：对全量合并图执法会砖死既有课程（任何 edit 被同一行错误拒），沿 #297 / #313 C9 的增量判据。

## 不做什么

- 不追溯、不回填存量（只约束新出生；旧课 `assumes` 缺失恒合法）。
- 不改调度、`ready`、可学清单与 UI（概念字段不进闭包）。
- 不改概念身份/地址语义：`assumes`/`teaches` 声明仍恒精确，别名收编仍走人审（ADR-0089 不动）。
- 别名候选通道（AI 提议 + 人审）另票（归 #300 族）；概念检索/索引强化（向量 + BM25）入候选池（#285）。
