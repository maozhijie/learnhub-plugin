# 渲染能力清单只认占位符：删有占位符就注入、没占位符就追加的运行期兜底

提示词模板注入渲染能力清单（Mermaid/公式/交互模拟/chart 等面板渲染菜单）的旧口径是**双轨**：模板里有 `{{renderers}}` 占位符就在占位处替换，没有就在 `Content.loadPrompt` 里**无条件把整段菜单追加到模板末尾**（ADR-0075 §1 记过这条兜底）。全仓带占位符的模板只有一处——节生成共享尾段 `SECTION_OUTPUT_TAIL`（三风格变体），于是其余 **13 个内置站**都在运行期被追加了这段菜单：教练思路官两族、执行官、课程大纲、课程节拆分、题目生成、笔记出题、罗盘初画、项目三站、回执评审、错误对比卡。

代价不是「多一段上下文」，是**注入面覆盖了输出契约**：菜单开头就写「只能使用下列格式；未列出的格式面板无法渲染，写了等于没写」，而教练站的契约是「只输出一个 YAML 文档」／「全程用工具调用承载产物」——两者直接矛盾（`CONTEXT.md`「输出契约」词条：同一上下文包里混入与在站契约矛盾的指令即契约矛盾）。实机取证：教练思路官与执行官的生成语料里，模型照菜单说话（`bad-*` 与 `ok-*-0001` 末尾段），YAML-only 契约被一段与站点无关的格式清单稀释。

裁决：**删兜底，渲染清单只认占位符**。模板里没有 `{{renderers}}` 就是零注入——`loadPrompt` 逐字交还模板原文。vault 旧快照不走新迁移路径：既有版本升级链（`vaultVer < builtin` → 覆盖 + `.bak`）足够把旧文件带上来，本次变更不动版本号（模板文本零改动）。

关键裁决：
- **占位符是唯一注入口径**——「谁需要菜单」由模板自己声明，不由运行期猜。需要菜单的站（节生成）已经带着占位符；不需要的站从此一个字也不多。
- **这推翻的是 ADR-0075 §1 的那句兜底，不是那条裁决**：惰性文本、`{{var}}` 严格渲染、`prompts/` 单源落点全部不变（§1 已加注记指回本 ADR）。
- **用户自建模板同此口径**：`state/提示词/<站>.md` 里没写 `{{renderers}}` 就不会有菜单——要菜单就自己把占位符写进去。旧行为下「自建站默认被塞菜单」与「自建站意味着自定契约」同样相抵。
- **登记归各站**：删掉的是每站**最终 prompt** 的一段（模板文件零改动）→ 两道提示词门（提交级版本号集合差、状态级版本号对齐）都看不见，按 ADR-0072 §已知边界 ④ 走人审登记：13 个受影响站的 `PROMPT_CHANGELOG` 同版本号下各补一条（本票登记共 17 条，含判据注入与摘要修正）。

替代方案（否决）：
- **按站白名单豁免兜底**（列一份「不要菜单」的站表）——第二份事实源：新站默认错（默认有菜单），且与模板自己声明口径的能力重复。否决。
- **给 13 站补 `{{renderers}}` 占位符**——把面板渲染能力塞进「只输出 YAML」「全程工具调用」的契约里，矛盾一步没治，只是从运行期挪进了模板。否决。
- **保留兜底但改文案**（如「若本站产物是 HTML/正文才适用」）——注入面继续对每个站说一段它不该听的话，模型只能自己判断哪句适用。否决。

不做什么：
- 不为 vault 旧快照新做迁移（既有版本升级链覆盖；`.bak` 是 diff 恢复面）。
- 不动 `rendererCapabilityBlock()` 的文本与消费面（节生成三变体照旧注入，内容零改动）。
- 不追改 ADR-0075 正文段落（只加 §修订 注记）。

过门记录（ADR-0072 两步 + 章程 §8）：`prompt-bump check` ✓（同版本号下的注入面登记不进提交级门的判据，属 ADR-0072 §已知边界 ④，登记靠人审——本票共 **17** 条 `PROMPT_CHANGELOG` 条目已补：13 站去菜单 + 判据注入 3 站（思路官两族 + 执行官）+ 重裁摘要修正 1 条）；`replay` 报 3 件存量漂移（教练生长 2 件 + 种子起草 1 件，与本表 #273/#272 条目所列同一批同因，非本次变更引入）；`compare` 未做真模型对照（取不到改前/改后两份同源报告，同 #218 先例如实登记「未过门」而不是假装过了）。回退点：`Content.loadPrompt` 那一行。

后果：13 站的最终 prompt 各少一段（数百字，随站而异），输出契约回到单一声音；`tests/prompt-contract.test.ts` 钉住三变体仍注入、其余 13 站逐字等于模板原文。同期同票的另两件（同错误熔断、观测面补全）分别记在 ADR-0041 §修订补记与 ADR-0091 附录，本 ADR 只管注入口径这一件。
