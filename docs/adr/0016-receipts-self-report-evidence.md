# 外部回执入练习证据通道：自报即可信，证据不是内容

决议（#75，2026-09-09，需求池 §5 决策 2）：practice 证据通道接受学习者提交的外部回执。裁决细目：

1. **资格与可信性模型**：**自报即证据**——回执记在学习者自己的账本上，谎报损失只归自己，系统不设反作弊门。形态自由：一句话描述、纯文字、图片、软件导出（JSON/CSV）、教练签核皆可；材料的角色是**降低用户维护成本与 AI 评审成本**（大模型处理文字的成本远低于多媒体，且能动态汇总任意形态），不是可信性门槛；评审质量随材料厚度浮动。
2. **载体**：机制按通用**实践主体**建模，不预设领域（乐器/编程/运动只是「高度内隐、依赖练习乃至肌肉记忆」活动的实例）。v1 落地载体=实践节点：回执进该节点 practice_ema，ADR-0001 的 mastery 0.3 上限妥协照旧；项目载体随 P 区执行事件流、技能条目载体随 U-2 各自接入——本决议不写死载体类型。
3. **Missing/Broken 边界**：回执**永不判 Broken**（学习者提交物不是引擎契约，同笔记源精神）；**没交回执是合法常态**——练习不产生「必须存在回执」的预期，连 Missing 都不算；材料失效（链接死/文件不可读）由 Data Check 报告「回执不可达」，已入 EMA 的历史分值**不回滚**（账本只增）。另一半边界：回执是证据不是内容——永不进内容管线、不被出题、不是复习对象（与 Learner Output「过程资产兼复习对象」划界）。
4. **评分**：AI 量表评审统一给分，事件带来源枚举（自报文本/图片/导出/签核）留档、**同权进 EMA**（旧 0.7 新 0.3），不做可信度加权分层。rubric 来源=挂载对象的内容（v1：实践节点正文/交互件要点）；未来无内容可依的载体用「AI 提议通用量表 + 学习者确认」（提议非指令）。
5. **XP 与调度**：**零 XP**（承 ADR-0009：宁可账本低估，保持 XP 只走节点定价 Settle + 既有作答流水的单一口径；自报时长不足以定价）；**不推进任何 FSRS 卡**（走 ADR-0006 的练习语义侧：无自评、无调度写入）。
6. **频次**：不限次、不去重——回执记录的是已发生的真实实践；同日多回执=多次 EMA 更新，EMA 收敛特性天然防虚高，mastery 不进门禁故无作弊面。
7. **渐退反馈**：**per 实践主体**（每个挂载对象自己的反馈计划）；反馈形态=错误当下的定向量表评审（回执触发讲解，非自由答疑——反需求清单边界）；频率随历史递减（guidance hypothesis，Salmoni 1984）、学习者可控（随时可主动要完整评审）；递减曲线参数归执行票。渐退反馈暂不词条化，未来跨区复用再议。

为什么自报可信模型成立：mastery 是读侧视图、不进任何门禁（进门禁的是作答正确率），作弊无收益面；账本是学习者自己的记录系统（XP 词条本义）。为什么现在开这条通道：无界域（高度内隐、依赖真实练习的活动）在现有系统里零采样窗口，回执是唯一证据入口（综合笔记 §1 覆盖度表「运动/音乐技能：缺（F3）」行）。

工程影响（供回执反馈环票消费，非本决议约束）：`PracticeRec` 同族加来源枚举；实践节点结算页加回执入口；评分进 EMA 复用既有 `applyPracticeEvidence`；渐退反馈计划的频率状态是挂载对象上的小状态，落盘形态归执行票定。
