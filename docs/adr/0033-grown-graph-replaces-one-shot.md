# 课程图以种子+滚动教练生长，取代一次成型全图生成

课程图的存在形态从「一次成型」（单次生成全量节点与粗结构、再填充内容）改为「生长式」：课程从**种子**（1–3 个起点节点 + 终点锚，一次人审即开工）出发，由**滚动教练规划**逐批生长——每生长批一次教练回合，读固定上下文包（终点锚、行为摘要、登记表档位、误解目录、罗盘+沉淀折叠），从算子集 {前进、插入、巩固、旁支、换向} 中裁决下一步；旧的一次成型大纲管线降职为**罗盘**（课程根下常驻的非承诺路线草图，教练每批重画，学习者批注作软输入）。

三条论据。**盲区事件化优于制度化**：预先承诺的块清单/骨架一旦错了，其盲区会被完成判据、进度分母、上下文注入制度化——整个系统按错的地图宣布进展；而种子的缺口只在症状出现的当场出现，由插入按需补掉，错误半径一步、修正频率最高。**视角由目标携带不由结构携带**：预先的骨架把教科书的一次切片固化为唯一视角，且同一门学科的不同视角本就是不同的 pre DAG；视角的合法来源是学习者的目标（他自己的需要），多视角的进入机制（症状驱动的插入、螺旋升档重看、误解目录的错误视角）生长式机器里本来就有。**规划是每步重算的函数而非一次性制品**：LLM 在环使短视界滚动规划可行——每步都吃最新行为证据，兼顾教练的专业弧线意识与个人认知节奏（快则难、慢则固），这是开环大计划与纯反应式生长都给不了的。

放弃的备选：全量花名册（结构面一次成型的还魂——stub 冠层、审计常年报警、Scale Floor 的虚假规模承诺、结束条件失效）；纯种子无规划（教练失去地形感与广度洞见，进度永不可见）。后果：ADR-0003 的人审锚从「骨架+交付」重构为「终点锚一次 + 罗盘常驻可见」；Scale Floor 退役，完成判据按目标类型二分（能力锚定=终点掌握，覆盖锚定=块工作表+终点）；水位重写为沿罗盘的前瞻深度；提案/edit/audit/快照等既有机械全部复用，图纸（SKILL 阶段循环）归提示词重写规格。
