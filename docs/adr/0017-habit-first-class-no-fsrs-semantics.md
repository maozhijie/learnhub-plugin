# Habit 一等实体：执行意图 + 自动化曲线 + 宽容 streak，零 FSRS 语义

决议（#76，2026-09-09，需求池 §5 决策 3）：「习惯」进入领域词汇表为一等实体（无界实践区载体，与 Node/Project 同级），并配共享记录类型 Execution Intention。裁决细目：

1. **词条**：Habit（习惯）、Execution Intention（执行意图）入 CONTEXT.md，随本决议落库。
2. **零 FSRS 语义**：错配表（深潜 §5.6）逐项无定义——R：习惯没有提取测试事件，一次未发生≠「提取失败」（可能是线索缺失/动机/抑制失败）；S：自动化度以重复次数与情境稳定性为自变量渐近增长，与「间隔」不同源，且中断不衰减（Lally 漏天无碍）；D：行为复杂度≠难度（开车复杂而高度自动化，服药简单而难维持）。反需求清单点名「习惯塞 FSRS 卡」不建；也不并入执行事件调度通道（U-2）作退化特例——该通道吃的是离散执行事件，习惯连离散事件语义都没有。
3. **构成**：一条 Habit = Execution Intention（线索-行动规格）+ SRBAI 式自动化曲线（自评、渐近，自变量=重复次数）+ 宽容 streak（漏天无损）。
4. **生命周期**：active/archived 两态，可逆——archived 只是收纳标签，任意状态可重开回 active（承 ADR-0015「重开比重建诚实」精神）；无到期、无截止，无截止习惯合法地永驻 active、无催办义务。
5. **重复入账**：学习者自报为唯一来源；无门禁、不防作弊——习惯域的测量本就是自评量表（SRHI/SRBAI，Gardner 元分析 r+=0.44–0.46），自测不是考试。证据联动（回执/执行事件佐证重复）留后续票，不进本裁决。
6. **Execution Intention 共享**：格式锁死为「稳定线索（时间/地点锚）+ 单一具体行动」——证据合法性继承自执行意图（Gollwitzer & Sheeran 2006，d=0.65），超出此格式的堆叠（多行为链、模糊线索）掉出证据范围。Habit 持有一条作为其规格；E3 目标偏好也可挂载 intention（只覆盖推荐读侧，ADR-0009 语义不变）。**共享类型、各归其主**：habit 的意图是实体身份的一部分（持久），目标偏好的意图随其读侧语义走（可过期），跨域引用不建。
7. **三边界**：①习惯≠掌握度——无 mastery、无 FSRS 卡，自动化曲线永不进 Mastery/练习证据/XP/任何 canonical 度量（JOL 校准曲线同款纪律：只展示给学习者）；②习惯 streak≠XP streak——与 XP streak 宽容机制（#83）是两个对象各算各的，一侧宽容化不自动惠及另一侧；③习惯重复≠执行事件——U-2 通道（执行事件调度）只吃技能执行事件，习惯重复不进该通道；habit 的 intention 可指向一个练习行为，但引用不构成数据回流。
8. **调度者=情境与日历**：引擎不推送、不提醒（反需求清单点名提醒器形态：Stawarz 2015——提醒支持启动不支持形成）；引擎的职责是收自报、记重复、画曲线、算宽容 streak、展示 intention。

为什么是一等实体而不是降级方案：自动化曲线与宽容 streak 需要挂靠对象，「目标偏好附属」方案等于砍掉 U-3 全部增量；「并入执行事件通道」被错配表否决。两个备选同批被拒：目标偏好附属（曲线/streak 无处挂靠）、执行事件特例（把没有事件语义的域硬塞进事件语义，恰是错配表警告的形状失配）。

工程影响（供执行票消费，非本决议约束）：Habit 与其重复流是学习者数据对象，Missing/Broken/Data Check 语义照常适用；宽容 streak 与 XP streak 的派生各自独立（不复用 XP 的按日账函数——自变量不同：XP 按日账，习惯按自报重复）；「交付：执行意图写入目标偏好」（#84）按共享 Execution Intention 类型实现；「交付：习惯一等公民对象」（#90）按本决议实现，SRBAI 施测节奏（事件级抽查 vs 定期自评）归该票定。
