# C1 个人笔记复习源：只读镜像、零写用户笔记、漂移不判损坏

决议（#42，2026-09-08）：Arc C1 v1 立项为「把任意 vault 笔记/文件夹注册为复习源，只出题不动文」——用户对自己写的笔记做间隔复习。v1 明确排除进阶「笔记→图→补节」、交互件与跨文件图结构，等 v1 真实使用反馈再议。

数据主权：对注册的个人笔记文件，引擎**零写入**（正文与 frontmatter 都不动——笔记是用户的，节点模型里「笔记即调度事实源」不适用）；派生物（题库、per-question FSRS、源清单）全部落在学习中心镜像区。笔记内容由用户正常编辑，这是预期行为而非损坏。注册粒度 = 文件级（每份笔记一个卡池），文件夹仅为批量登记/解除入口。

演变语义与课程节点刻意不同：用户笔记**永不判 Broken**（它不是引擎契约对象）；笔记删除/改名 → 源链接 Missing（合法空态，卡池提示挂起、可重注册/移除）；正文编辑导致题面陈旧 = **内容漂移**——源清单存正文指纹，指纹不符即提示「内容已变，可重新出题或归档旧题」（手动/AI 确认，不自动改题）。题库/调度/复习队列复用现有通道；复习走既有自评语义（无节点定价、不产生节点 XP settle）。v1 不套 frontmatter/stage/mastery 模型。
