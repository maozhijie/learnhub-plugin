# 挑战点恒温器：跨区观测聚合+只读建议，「恒温器」不是自动控制器

决议（#73 Not-yet-specified 收口，2026-09-09，grill 会话）：D-2 挑战点恒温器的跨区控制面落定为**提议面**——Challenge Point（挑战点）入 CONTEXT.md（最优练习点=功能任务难度×学习者技能的个体化交点，Guadagnoli & Lee 2004，因人而异、随水平移动），特性名保留「挑战点恒温器」，但词条与实现共同锁死：**恒温器≠自动控制器，写侧零自动调整**。裁决细目：

1. **机制**：跨区挑战点观测聚合+只读建议；建议的采用走既有入口、逐条显式确认——与渐退档移动、今天学它同款「引擎提议、学习者可改」通则。
2. **观测量（零新度量）**：课程区=真实保留率带+难度带长期选择分布；项目区=Mastery 交叉 2×2 诊断+档内表现（随 P-7/P-2 落地后补，不阻塞 v1）；无界区=执行事件评级分布。全部是已有读侧信号，恒温器只做跨区聚合，不造综合「挑战分」。
3. **旋钮 v1 封顶**：A1 目标难度带默认值、检索点密度、渐退档移动提议（已有，恒温器只聚合展示）——形态=「一个跨区仪表+至多三条建议」，不新增第四旋钮。
4. **与 Difficulty Band 的关系**：难度带是会话级学习者偏好（E5），挑战点是跨区长期观测面；「可用的困难」教练提醒是课程区观测的既有成分，恒温器不重复建设。

同批被拒：自动控制器（违反提议非指令通则；Goodhart——参数一旦被自动调节，被测行为立刻失真，观测面报废）；显式数值 setpoint（伪精确，challenge point 框架无共识标度）；新造综合挑战分数（零新度量原则）。

工程影响（供执行票消费，非本决议约束）：交付票 v1 范围=课程区+无界区观测+仪表与建议面；项目区面板随 P-7（#96）后补。
