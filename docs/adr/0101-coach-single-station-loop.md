# ADR-0101：教练回单站回路——两站编排退场与读件面归位

日期：2026-09-17 ｜ 状态：已裁决（实施归票面）｜ 取代方向：#266 的两站编排（思路官 + 执行官）与 ADR-0088 的「执行官站」称谓

## 裁了什么

**教练回合回单站**：方向裁决与落图回到**同一个持只读工具回路的单站**，不再跨调用。拆出的「思路官站」及其交接计划契约（含计划 schema 门与「门拒 → 回灌重裁恰一次」）、两族提示词、零节点名契约、三段观测记录一并退场，不留开关。

- **停摆两处判**：引擎侧就绪深度检查不达标才拉回合（`ok` 即不拉任何站，主短路照旧）；其余一律拉回路，由回路以**零操作收束并给出理由**。
- **随批携带**：插入批复诊预注册、弧对齐指认、结构性重画建议三件由「随计划携带」改为**随批携带**，引擎消费口不变。
- **读件面归位**：还回拆站时丢掉的三个只读视图——行为摘要、题库概况、罗盘读。写件纪律不变（教练不持写工具，写路径仍走提案 → 受理门 → apply）。
- **组成表述更正**：ADR-0099 与 ADR-0092 里把教练称作「思路官 + 执行官」的**组成表述**随本裁决退场；两条 ADR 的实体裁决（局部最优定位、罗盘写权反转、首级判据迁家）不变。
- 生长批 note 区的形状（分歧声明、逐条目算子）**不在本裁决内**，另票。

## 为什么

- **那条跨调用通道既传不准、又不可验证**：计划被设计成零节点名、零图上引用，于是批内拓扑（谁在谁之后、汇合点在哪）**无处可写**；受理门只查结构合法性与汇合，**没有任何一道门把落成的图与计划的意图对照**。一个不承载判断、又不承载校验的通道，只剩一次额外调用与一个漂移面。实测：思路官判「前进」而执行官零产出停摆，一轮深档白烧；#316 自认「视野 1–3 步的滚动规划器 → 近景回声」。
- **举证的量纲与裁决不匹配**：拆分的动机证据是「单发 0/12 过门 vs 只读工具回路 12/12」——量的是**回路 vs 单发**，而回路本就可以加在单站上。该证据支持「教练要有回路」，不支持「教练要拆成两站」；拆分唯一的论据（机械活稀释教学判断）从未被度量，反向却有两条已证回归（近景回声、两站判据不一致）。
- **合并不丢判断质量**：方向判断的输入（上下文包六区块、全图摘要、行为摘要）两站本就共享；合并后方向判断**多拿到真图的按需自查**。
- **读件三件是净损失**：拆站只把落图搬走，却把方向侧的三只眼睛留在原地，而合并后同一颗脑子两件事都要做。

## 否决了什么

- **保留两站、把计划升为权威**：权威化要求计划写得出批内拓扑（即回到名称与引用），把「零节点名 + 单发」的老病请回来；且「计划权威」与「执行站仍须逐字对表真图」直接冲突。
- **保留两站、把批量构成判给执行官**：规模与粒度的选择正是拆分要保护的那份教学判断，判回执行站既重新混血、又让思路官更摆设。
- **取消 LLM 执行、改程序化编译计划**：计划缺的不是机械格式，而是**节点内容**（命名、成分技能边、误解先验、档位）与**接地**（引用逐字命中真图）——程序接不了地；把计划补全到可编译，就要让零工具站产出引用，退回单发幻觉。
- **同站分两段（先方向后落地）**：分段唯一收益是给方向一个独立可见产物，而该产物正是那条不可验证通道的复刻；方向的可考古性由轮次日志与批次理由承担。
- **照搬邻仓学习图回路的「生成循环 + 审计驱动修复循环 + 差异表」外壳**：那是长程一次性建图（200+ 节点）的形态；本仓空图沿症状生长，逐补丁过门与错误回灌已承担该角色，照搬只增风险。可搬的是审计行动清单（ADR-0102）与生成/修复两档思考。

## 不做什么

- 不改受理门、提案 kind、FIFO 与「结构只落、正文显式下发」。
- 不改就绪深度检查的判据量纲（仍是未开始存量，量纲纪律见 ADR-0096）；总量口径另票。
- 不动罗盘写权与教练的局部最优定位（ADR-0099 不变）；不新增提案 kind；不改图 schema。
- 不搬「先把图建满」的哲学：仍是空图 + 学习者手加终点的生长式图（ADR-0033）。
- 图质量读数、复诊账本、下游/邻域读件、预算成组、在线终审、逐条目算子——各自独立成票。
