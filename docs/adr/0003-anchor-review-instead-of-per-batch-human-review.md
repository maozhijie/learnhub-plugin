# 图谱生成期批次提案自动 apply，人审撤到骨架与交付两个锚点

旧流程要求每批 edit 提案人审后才 apply，批次节奏是节点量不足的放大器（批小、轮次多、疲劳收工），而人审挡下的主要是机械可检的问题。决定：批次提案过门禁（schema + 结构检查 + audit 无 ERROR）即自动 apply，人审只保留两个锚点——骨架提案与最终交付；独立审查由检察官补偿（维持每 ~50 ops 一次，交付前新增一次全图终审）；熔断线为连续 2 批 ERROR 或健康分环比下降 ≥10 时暂停并汇报。前置条件是同批落地的机械门禁（认知跨步候选、R6 传递冗余、空降检测、规模底线）真正接管批质量。这是刻意偏离默认安全路径的决策：提案与快照留痕可回溯，不要把逐批人审当 bug「修」回来。
