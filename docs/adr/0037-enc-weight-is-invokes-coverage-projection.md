# enc 权重 = invokes 覆盖率投影：调用站阶梯退役

enc 的权重语义从「调用强度按调用站数分档」（ADR-0008 反哺通道的 1 站 0.6 / 2 站 0.8 / ≥3 站 1.0 阶梯）改为**题目 invokes 覆盖率投影**（#148）：节点题目集按一枚 invokes 概念聚合，投影到 pre 闭包内教该概念的前置节点，w = 该前置被 invokes 的题数 ÷ 带 invokes 的题数（覆盖率份额，每题恰一枚故份额和 ≤1）。出生 w 随生长批经 set_enc 写入，作回退初值——行为侧校正通道仍不设（#136 Out of Scope），它就是初值也是缺省值。

理由：阶梯的原料是正文的 `enc_candidates` 机器块与练习 `uses` 元数据——**生成期声明**，模型写多少站它就算多少强度，与学习者真实调用什么无关。invokes 是题目出生打标的概念地址（一枚 invokes，#141/#148），「本节练习在调用哪个前置组件」由逐题标注直接回答，权重天然有语义：一道题对哪个组件失效，A3 就按 w 路由到哪个组件。语义真假回到提示词与逐题标注（纪律四六开），代码只管可判定的投影与闭包归属（E7 照旧）。

边界：
- **退役的是权重阶梯，不是反哺候选通道**。`enc_candidates`/`uses` 仍是 enc 边「存在性」的内容级声明（反哺 hints、R14/R15 一致性审计照旧）；它们提名的边若无 invokes 数据支撑，落 schema 缺省权重 1，区分度告警归 R16。
- **存量回填取消**（invokes 不回填旧题），存量 enc 回填走覆盖层通道（kind=enrich 首期，#140 已建）：候选边与 invokes 投影边一并提名，权重按本决议。
- 归档题不进投影分母；零 invokes 是合法空态（Missing），零投影不造权重。
- P-6 行为共现边（project-enc）的共现天数档是行为侧自有标尺，不随本决议退役。

替代方案（否决）：阶梯保留、仅给投影边加权重——两套权重语义并存会让同一条边有两个「真值」来源，审计与调度无从裁决；按调用站回填权重则继续把生成期声明当成调用证据。
