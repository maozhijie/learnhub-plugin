# 生成方法论补丁四票的裁决：节间连贯注入、档位声明完备、交错补丁、双重编码软指令

决议（#227/#228/#232/#233 收口，2026-09-13；缘起与文献面见各票与 `docs/research/2026-09-generation-methodology.md`）：#225 方法论调查认定的四个可执行缝隙，按「最小件、零新增模型调用、软措辞不进门禁」的同一尺度落提示词层与调用点层。四条裁决：

1. **节间连贯 = 业界最小双件（#227）**：逐节生成的最低连贯配置是「全局计划 + 前文注入」（WritingPath NAACL 2025 / Re3），本仓两者皆缺且模板空头承诺。裁决：`sectionPrompt` 注入**完整节清单（各节 id/title/type/points 标 i/N）+ 相邻前节末尾约 300 字窗口**（行首截窗；拆节后窗口取父内前子节；首节/前节未生成时整段省略不报错），前节正文**就地取材**——管线落盘成功后用过门原文刷新节清单视图，不为连贯增加任何读档或模型调用。模板（大纲 + 节生成三变体 v9→v10）按注入实态改写，禁止再声称「注入前节已生成正文」全文。**明确否决**：滚动实教摘要、跨节审读遍、整节点一次生成（证据反对）——进候选池 #234 攒语料后议。修复回灌走同一 `sectionPrompt`，连贯注入在修复轮同构在场（与块修补→整节压缩→拆节阶梯天然兼容）。
2. **调用点 effort 声明完备（#228）**：「调用点只声明语义档」（P4）此前有反例——出题站（逐节与 generic 两路）是全管线推理最重的站却不声明 effort（走部署默认），节正文初跑恒 fast 不随节点难度。裁决：出题两路与节正文初跑**必须显式声明**，口径同大纲站的 `contentEffort(highTier)`（高复杂度 deep、否则 fast）；低难节点行为不变。档位记录随任务终态进运行日志，供成本对照（#213 语料/计量落地前的观测替代）。具体档位组合允许实测微调，但「未声明 = 部署默认」这个形态本身被否决。
3. **交错的内容侧最小件（#232）**：复习队列调度侧已天然交错，生成侧不造易混对。裁决：出题提示词增一条——收尾综合/易错陷阱槽位至少 1 道**跨概念对比题**；概念登记表条目增**可选字段 `confusable`（易混对，同课程在册概念名）**，出题时随概念清单注入作候选；字段缺席 = 合法 Missing，不回填、指令静默降级；悬空/自指引用消费侧静默降级，并入合并取并集不丢数据。**内置裁决**：对比题 `invokes` 记**被区分的主概念**——恰一枚契约不破（对比题不是多概念题，是一道以区分为主旨的题）。
4. **双重编码只做软指令（#233）**：CTML 组合原则效应中等且稳（Cromley 2025 meta），硬性化推高返工率不划算。裁决：节正文硬约束 6 加半句「文字与图互引——文字提及图、图内标注与正文术语一致」（防图文两张皮）；题目解析配图对几何/函数/数据类由「可用」升「应配」（软性要求，不便配图不必勉强），**保持软措辞、零新增门禁 finding**。

工程面（供后续票消费）：#218（提示词重排）以 #227 后的节提示词构成为基线（原生 blocking 边）；#230（多样性仪表）落地后，#232 的对比题效果可经 invokes 覆盖分布观测；概念登记表 schema 演进为可选字段子格式（契约 v0.2，非主版本断裂），查重门与 validateBank 口径零改动。
