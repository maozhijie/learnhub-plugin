# ADR-0106：出生后概念打标修正通道——节点覆盖层与 set_concepts 写路径

日期：2026-09-18 ｜ 票：#299（实现）、#334（题目 invokes 段独立）、#300（概念工作台·本票硬前置） ｜ 状态：已采纳（补 ADR-0084 §①②③ 身份语义之外的**修正通道**空缺）

## 裁了什么

**节点概念字段（teaches / assumes / misconceptions）的出生后修正走「节点覆盖层」，不改写出生字段。** 出生字段是声明链快照、一字不动；修正逐概念叠在节点上一块可选的覆盖层里，图读侧有**唯一合并出口**——所有消费面（概念足迹、单节点卡、内容注入、体检读数）读的都是出生叠覆盖后的**有效值**。

- **存储**：覆盖层是节点上的单块可选键——旧库无此键 = 无修正，天然兼容（加法演化，不主版本断裂）。`teaches / assumes` 逐概念存「档位或删除」；`misconceptions` 逐概念存「该概念一族的误解列表或删除」（逐概念整体替换，以守「每概念封顶 3 条」）。
- **通道**：新增 edit 原子 op `set_concepts`（载荷 = 覆盖层），**不加 proposal kind**，受理与工具的对外契约一字不动。落层语义 = 逐概念键**并入**节点现势覆盖层（同键后写覆盖），历次修正累积、互不覆盖。
- **判据同源**：修正 op 与 `add_node` 走**同一受理门序列**，一律按**合并后有效值**判——概念引用须在册（别名归一）、自相矛盾（有效 teaches∩assumes 拒）、误解封顶（按合并计数）、teaches≥1（修正不得使非 practice、非终点节点的**有效** teaches 归零）。**不新增门**（门同源，ADR-0088）。前向约定：概念充分性门（ADR-0105，未落地）落地时，`set_concepts` 改动的 assumes 属「本批改动」，应进门。
- **读侧同源 + 收编旁路**：合并只落在图读侧一处，并**收编两处读原始出生字段的旁路**（误解封顶门、体检读数）改读同一出口——判据与展示按构造成立同源。
- **留痕**：修正的 provenance（理由/发起方/时刻）追加进覆盖层流水（只增），journal 记对应 op；**正典只放事实**（修正前原值由未动的出生字段派生，不冗余落盘）。本期只落提案事务通道，人类直发入口归 #300。
- **拆分继承**：`split_node` 的拆分件按**合并后有效值**继承父节点概念字段（`add_node` 不接受覆盖层，故把修正就地物化为新出生）——否则「拆一个已修正的节点」会静默丢修正。

## 为什么

AI 出生打标是声明链（#297 裁决一），打标错误此前**没有人工修正的正规路径**：概念字段组只随新增节点出生，富化覆盖层首期只补写 enc。修正若直改出生字段，就丢了「修正前原文」且违「出生字段 = 声明链快照」；独立第二正典文件则破「读侧只读正典」并使快照/指纹/写入单元/审计全要认第二份。覆盖层把修正做成**加法层**：出生事实保真、修正可回溯、读侧一处合并即令全部消费面同源。

## 否决了什么

- **直改出生字段**：丢修正前原文，违声明链快照。
- **独立第二正典文件**：破「读侧只读正典」，快照/指纹/写入单元/审计全面认第二份。
- **复用富化覆盖层（kind=enrich）扩条目**：与「引擎直跑 + 确定性投影回填 + sha256 指纹」的语义混淆（enrich 是正典直写，本通道是覆盖层）。
- **为修正单开一门**：判据会与既有门分叉——按合并值收进既有门序列（门同源，ADR-0088）。

## 不做什么

- 不改写出生字段历史、**存量不回填**；不做批量回填、不做修正率读数（读数是 #297 / #300 的事）。
- 历史作答统计**不动**（账本教义：修正从确认时刻起对未来读数生效）。
- 概念身份语义（合并/废弃/别名/正名）归 ADR-0084 §①②③ + 0086 + 0089，不重开。
- **不改提示词散文**（教练主动 retag 另行开票）；写件取值域回灌多一枚 op 属注入面变化，按章程 §8 登记（不改模板文本、不 bump 版本）。
- 题目 invokes 的修正通道归 #334；人面直发入口归 #300。
