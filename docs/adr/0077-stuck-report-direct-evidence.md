# 卡点自报直接成立插入症状，错归因由复诊兜底

现状补救链全是事后的：struggle 判定要 ≥3 次作答且 14 学习日窗，卡点集中度靠行为摘要窗口聚合，插入与复诊再压 5–20 学习日——从「阅读当下已察觉受阻」到「系统行动」最快隔一个教练回合、慢则数周；t=0 没有任何传感器（预测门零写入、阅读页无自报面）。更本质：用户报告的「缺前置知识」可能**根本没有节点**——图上不存在的东西无题可出、无窗口可聚合，任何基于既有结构的检测器都对此失明。

裁决：新增**卡点自报**（`CONTEXT.md` 词条，practice 流水独立 kind）作为 t=0 的一等传感器，并裁其证据地位——

- **自由文本唯一录入形态**：原文逐字落账、零结构化——不设概念 chip、不标味、不做表单预设。输入形态不可预设（跨节引用、模糊指代、情绪化描述都合法），原话是事实源，提前提炼即损耗。
- **自报即时触发教练回合（force）**：落账后立即入队一次教练回合走 force（绕过就绪即短路）——ADR-0076「添加终点 → 立即入队」同款先例。**不是新增 t=0 解读站**：解读交还给本来就带全工具的教练回合。
- **常驻全图摘要（图面块升级）**：`renderGrowthGraphView` 由「前沿细节 + 其余名单」升级为全图摘要——逐节点一行（深度/区·块/阶段/掌握度，弱掌握带 ⚠，终点行带 ⚑，pre 邻接同行；多终点接线义务与靶子必须可见）。降级：超 cap（**200 行**）→ 区/块聚合行 + 前沿细节 + 溢出行，⚠ 塌陷节点与 ⚑ 终点不截。⚠ 只标**已开始**阶段（不标会稀释成噪音），阈值 0.5（与 B2_MASTERY_LOW 同值不同域）。轻量段仍两件不带。
- **上游图摘要工具（`upstream_dag`，工具白名单净 +1 至八件）**：给定节点渲染其前置传递闭包——闭包节点逐条带深度/区·块/阶段/掌握度/到期/est，闭包内 pre 边以邻接表呈现；超 cap（**60**）按**深度升序**保留地基段 + 溢出行点名切断深度与余数。分工：摘要 = 地图集（省列），工具 = 变焦（含 due/est/teaches），兼作大图兜底。诊断「七步之前的地基」不再靠逐跳 node_card，node_card 维持单步 pre（叠加方案作废）。
- **教练回合归因与响应**：教练带自报原话归因——复习类结论给 A3 定向复习建议（ADR-0008 blocked 面复用），缺口类结论裁插入提案（受理门→预注册复诊）；插入定位按概念足迹裁（足迹非空 = 天然挂点；足迹空含缺册 = 默认挂当前节点前置），**引擎不写定位规则**。
- **自报（经教练回合解读）直接成立插入症状**：免行为窗口聚合、免前置验证。理由：复诊本身就是验证——插入边预注册复诊、不达标自动剪除恢复原粗边、无人审，错归因的代价是一个复诊周期而非永久伤。
- **频控与兜底**：同节点每学习日一条 + 每日总量上限（数值进 params）——上限同时是回合触发上限，防自报刷出回合风暴；在途自报照常落账但不重复入队，留待当次或下一次回合消费。插入率/旁支占比闸门（复诊调速器）仍是最终兜底。
- **归因映射分层（模型不猜词）**：子串 query 当发现机制会静默失败（粒度/角度/别称差异致空结果，**空 ≠ 不存在**）。三层：① 主路径 = 当前节点概念面（teaches/assumes ∪ 前置闭包 assumes，含定义的小集合）随全量包/图面可读，多数自报零查询归因；② 兜底 = `concept_registry` 无 query 全表阅读（cap 内逐条对照）；③ query 降级为收窄加速，空结果语义 = 「换宽词或读全表，不是不存在」（写进工具描述与提示词）。写侧恒精确：提案概念引用逐字命中在册名字，受理门拒收编造名；登记表扁平无层级，宽窄归属由教练裁（归最窄 presupposed 在册概念或显式缺册铸名）；交叉可多概念归因，拿不准在理由里显式说；别名变体不自动入册（人审），原话恒留账；登记表超 cap 属其自身消费面，不归自报管。
- **回路预算 6→20**：`AGENT_LOOP_MAX_TOOL_ROUNDS` 6→20（覆盖 ADR-0041 的 K≤6 登记；「不设调用方覆盖」的全局不变量保留——统一上调不分档）。理由：教练职责变重（归因 + 定位 + 插入裁决 + 在途清单消费），撞顶 fail loud 会截断重裁决。代价（天花板变松、每回合成本上限更高）由 trajectory 轨迹观测补偿。
- **登记表有效性边界（能指/所指漂移推演）**：归因下游消费粒度是节点不是概念，精度要求放宽。五场景：词形/角度漂移由别名集吸收（失效是费不是错）；粒度差由「归最窄 presupposed 条目或铸新」吸收；所指突变由「铸新 + 旧条目不删」处理；包含关系不在其职责内（登记表管身份、图管结构，包含由 assumes 边表达）；跨课漂移不存在（每课一份登记表）。轻运营纪律：教练可携别名收编提议（人审）；定义过时由质量评审兜。**不需要退役、不需要扩结构**（层级树/语义匹配在业务外）。
- **零激励纪律**：卡点自报零 XP、不进 canonical/Mastery/FSRS/完成判据；插入仍走提案→受理门→预注册复诊，写侧纪律不因证据来源改变而放松。

边界：

- **入口探针砍出范围**：进节点前的前置热身题测不了缺节点（检测面只有既有前置闭包），测已有前置不牢又有 R 软闸 + A3 覆盖。
- **预测门「不记分、零写入」裁决不动**（`CONTEXT.md` 词表，P-8 #97）：自报通道已闭环，坑前错选布尔是锦上添花；动既有裁决成本与收益不匹配，需要时走独立票。
- **回合产出对用户可见，失败不丢账**：教练回合响应走既有面板面；自报是软输入非指令，与罗盘学习者批注同款纪律；回合异常时自报留在账上由下一次回合消费。
- **注入面标题中立化**：自报走既有 `opts.inject` 通道，其块标题原写死「里程碑计划修订注入（项目消费拉动的生长请求）」，一条自报套进去会被读成换线/补支请求、指向错误算子纪律；改为中立的「外部注入（待裁决的请求材料）」（`PROMPT_CHANGELOG['教练回合']` v8）。

替代方案（否决）：

- **t=0 验证题（先出题再成立症状）**——用户否决「太麻烦」；测不出缺节点，测已有前置又是复诊的职责（错插会被剪）。
- **结构化快路径（chip 多选 + 标味 + 机械分岔）**——用户否决：不预设表达方式，chips 只覆盖最规整的输入；分岔把裁决从教练手里拿走。
- **复用 diagnostic 事件**——diagnostic 是引擎产出的「该重写哪节」建议项，与用户自报两个主体、两个方向；新 kind 是唯一不搅浑的选择。
- **等下一次自然触发的教练回合才处理**——用户否决：受阻当下必须给帮助；解法是立即入队（force）。
- **t=0 独立轻量解读站（单独一次 LLM 调用）**——产出只是「机器初判」、仍需教练终裁，同一件事做两遍，还多配一套基建。
- **自由文本做事前结构化（t=0 抽概念/味）**——原话是事实源，提前提炼是损耗。
- **引擎写插入定位规则（挂相关节点附近 vs 挂当前节点前置）**——定位是教练裁决，硬规则会在「有节点教但不在其前置路径」这类长尾误判（ADR-0076 同款）。
- **预测门错选落流水**——见边界；收益不匹配动既有裁决的成本。
