# 卡点自报直接成立插入症状，错归因由复诊兜底

现状补救链全是事后的：struggle 判定要 ≥3 次作答且 14 学习日窗，卡点集中度靠行为摘要窗口聚合（7 学习日/10 节取大），插入只在教练回合消费这些窗口证据，复诊再压 5–20 学习日——从「用户在阅读当下已经察觉受阻」到「系统行动」最快隔一个教练回合、慢则数周，而 t=0 时刻系统没有任何传感器（预测门明文零写入，阅读页无自报面）。更本质的缺口：用户报告的「缺前置知识」可能**根本没有节点**（图上不存在的东西无题可出、无窗口可聚合），任何基于既有结构的检测器对此结构性失明。

裁决：新增**卡点自报**（`CONTEXT.md` 词条，practice 流水独立 kind）作为 t=0 的一等传感器，并裁其证据地位——

- **自由文本唯一录入形态**：原文逐字落账、零结构化——不设概念 chip、不标味、不做任何表单预设。「这节课的 XXX 和 XXX 我看不懂」只是典型例，用户输入形态不可预设（跨节引用、模糊指代、情绪化描述都合法），原话是事实源，任何提前提炼都是损耗。
- **自报即时触发教练回合（force）**：落账后立即入队一次教练回合并走 force（绕过「就绪深度已满足即短路」）——ADR-0076「添加终点 → 立即入队」同款先例。即时处理的实现**不是新增 t=0 解读站**，而是把解读交还给本来就带全工具（concept_registry / graph_view / 概念足迹 / 上游图摘要）的教练回合，只是不再等下次自然触发。
- **常驻全图摘要（上下文包图面块升级）**：教练全量包的图面块（renderGrowthGraphView，现状 = 前沿细节 + 其余名单）升级为全图摘要——逐节点一行（深度/区·块/阶段/掌握度 + pre 邻接并入同行，弱掌握带 ⚠，终点行带 ⚑——多终点接线义务与禁长过目标的靶子必须可见），对教练它是预先存在的上下文：卡点归因、算子裁决、插入定位都自带全局拓扑。规模降级先写死：图超 cap 时自动降为区/块聚合行 + 前沿细节 + 显式溢出说明，⚠ 塌陷节点与 ⚑ 终点例外不截（诊断与接线价值最高的子集）。轻量段仍两件不带。它同时收掉教练全局视角的空间维度缺口与后期大图缺块聚合问题。
- **上游图摘要工具（upstream_dag，白名单 8→9）**：给定节点渲染其前置传递闭包全拓扑——闭包节点逐条带深度/区·块/阶段/掌握度/到期/est（弱掌握节点带 ⚠ 标记，塌陷点在拓扑里直接现形），闭包内 pre 边以邻接表呈现（紧凑无歧义，与图上「pre 名字列表零边字段」的边轻纪律同构）。与全图摘要的分工：摘要 = 常驻地图集（省列），工具 = 变焦（全列含 due/est/teaches），兼作超 cap 大图的闭包细节兜底。诊断「七步之前的地基」不再靠逐跳 node_card（K≤6 预算爆）。node_card 维持单步 pre 不动（闭包叠加方案被此工具取代）。
- **教练回合归因与响应**：教练带自报原话对表归因——复习类结论给 A3 定向复习建议（ADR-0008 blocked 面复用），缺口类结论裁插入提案（受理门→预注册复诊）；按概念足迹裁决插入定位（足迹非空 = 天然挂点；足迹空含缺册 = 默认挂当前节点前置），引擎不写定位规则（**概念足迹**读侧投影见 `CONTEXT.md` 词条）。
- **自报（经教练回合解读）直接成立插入症状**：免行为窗口聚合、免前置验证。理由：复诊本身就是验证——插入边预注册复诊、不达标自动剪除恢复原粗边、零人审，错归因的代价是一个复诊周期而非永久伤。在「便宜地试、自动地剪」的实验设计之上再叠前置出题门是冗余验证。
- **频控与兜底**：同节点每学习日一条 + 每日总量上限（数值进 params）——上限同时是回合触发上限，防自报刷出回合风暴；教练回合在途时的自报照常落账但不重复入队，由当次或下一次回合消费。插入率/旁支占比闸门（复诊调速器）仍是最终兜底。
- **归因映射分层（模型不猜词）**：归因不依赖「模型恰好猜中查询词」——子串 query 当发现机制会静默失败（粒度/角度/别称差异导致空结果，空 ≠ 不存在）。三层取材：① 主路径 = 当前节点概念面（teaches/assumes ∪ 前置闭包 assumes，小集合含定义）随全量包/图面直接可读，多数自报零查询归因；② 兜底 = `concept_registry` 无 query 全表阅读（cap 内，定义逐条对照——全表在手不存在「不知道查什么」）；③ query 降级为收窄加速，空结果语义 = 「换宽词或读全表，不是不存在」（进工具描述与教练提示词）。写侧恒精确：提案概念引用逐字命中在册名字，受理门拒收编造名；登记表扁平无层级，宽窄归属由教练裁（归最窄 presupposed 在册概念或显式缺册铸名）；交叉可多概念归因，拿不准在裁决理由里显式说；别名变体不自动入册（别名合并是人审），原话恒留账可复核。全表可读的前提是登记表在 cap 内，超 cap 属登记表自身消费面问题，不归自报管。
- **回路预算 6→20**：`AGENT_LOOP_MAX_TOOL_ROUNDS` 由 6 调至 20（覆盖 ADR-0041 的 K≤6 登记；「不设调用方覆盖」的全局不变量保留——天花板统一上调不分档）。理由：教练职责变重（归因 + 定位 + 插入裁决 + 在途清单消费），轮数撞顶 fail loud 虽可观测但会截断重裁决任务；常驻全图摘要会拉低平均轮数，但天花板给到 20 以容纳最重回合。代价（自激防线的天花板变松、每回合成本上限变高）由 trajectory 工具轨迹观测补偿，预算耗尽事件照旧可观测。实现时同步清扫 output-contracts 登记注记等处的 K≤6 字样。
- **登记表有效性边界（能指/所指漂移推演结论）**：归因下游消费粒度是节点不是概念——概念只需聚到足够近的节点邻域，精度要求被节点粒度放宽。五场景判定：词形/角度漂移由别名集吸收（失效模式是费不是错）；粒度差由「归最窄 presupposed 条目或铸新」渐进吸收；所指突变由「铸新条目 + 旧条目永不删除」诚实处理（沉淀旧地址不串味）；包含关系不在登记表职责内（登记表管身份、图管结构，语义包含由 assumes 边表达）；跨课漂移不存在（登记表每课一份）。两条轻运营纪律：教练回合可携别名收编提议（人审一条）；定义过时由质量评审审计面兜。不需要退役、不需要扩结构（层级树/语义匹配在业务外）。
- **零激励纪律**：卡点自报零 XP、不进 canonical/Mastery/FSRS/完成判据；插入仍走提案→受理门→预注册复诊，写侧纪律不因证据来源改变而放松。

边界：

- **入口探针砍出范围**：进节点前的前置热身题测不了缺节点（检测面只有既有前置闭包），测已有前置不牢又有 R 软闸 + A3 建议覆盖——两个生态位都被占，不做。
- **预测门「不记分、零写入」裁决不动**（`CONTEXT.md` 词汇表，源头 P-8 #97）：自报通道已闭环，坑前错选布尔是锦上添花，动既有裁决的 ADR 成本与收益不匹配；若未来实证需要，走独立票重裁。
- **回合产出对用户可见，失败不丢账**：教练回合的响应（复习指引/插入提案回执）走既有面板面呈现；自报是软输入非指令，与罗盘学习者批注同款纪律。回合异常时自报留在账上，由下一次回合消费——不丢数据。

替代方案（否决）：

- **t=0 验证题（自报后先出题验证再成立症状）**——用户明确否决「太麻烦」；且它测不出缺节点，测已有前置又是复诊已有的职责（错插会被剪），纯冗余门。
- **结构化快路径（概念 chip 多选 + 标味 + 当场机械分岔）**——用户明确否决：录入形态不应预设用户的表达方式，chips 只覆盖最规整的输入分布；机械分岔还把裁决从带工具的教练手里拿走。只有自由文本，没有快路径。
- **复用 diagnostic 事件**——语义冲突：B1 的 diagnostic 是引擎产出的「该重写哪节」内容诊断建议项，与用户自报是两个主体、两个方向；新 kind 是唯一不搅浑的选择。
- **等下一次自然触发的教练回合才处理**——用户明确否决：受阻当下系统必须给帮助；解法是立即入队（force，ADR-0076 同款先例），不是把解读推迟。
- **t=0 独立轻量解读站（上报时单独一次 LLM 调用）**——产出只是「机器初判」，仍需教练终裁，同一件事做两遍；且要新配提示词模板、输出契约登记、修复策略全套基建。立即触发教练回合复用既有裁决基建，同一件事只做一遍。
- **自由文本做事前结构化（t=0 抽概念/味）**——原话是事实源，任何提前提炼都是损耗；解读留给带工具的教练回合。
- **引擎写插入定位规则（挂相关节点附近 vs 挂当前节点前置的硬规则）**——定位是教练裁决，机械规则会在「有节点教但不在其前置路径」这类长尾上误判；足迹投影 + 教练裁决与 ADR-0076「提示词纪律，不做机器规则」同款。
- **预测门错选落流水**——见边界；收益不匹配动既有裁决的成本。
