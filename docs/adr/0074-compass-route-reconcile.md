# ADR-0074: 罗盘路线对账（周复盘现状区的非权威读数）

> **状态更新（#316，2026-09-17）**：「无锚即漂移」对账口径已撤销——对账方向反转为「给地图叠进度」，由罗盘周检讨三类读数（覆盖缺口/深度差/配比粗）取代；非权威旁挂纪律不变。

日期：2026-09-13 ｜ 票：#231 ｜ 总纲：#212 ｜ 来源：#225 生成方法论调查（问 5：教练「逐步重算 + 终点锚 + 罗盘参考轨迹」形态经查是**带终端约束的滚动时域稳健形态**（规划哲学维查无实据、不立反对票），唯一实质落差是——**罗盘路线无对账**）

## 背景与问题

「剩余路线」随生长批重写、显式非权威，于是**路线漂移静默合法**：route 重写即可自洽，无 diff 留痕、无告警；`repainted` 旗标只记「画过没」，不记「画得对不对」；周复盘 ETA 只算「还要多久」，不算「路对不对」。

而初画/重写模板的硬约束②已经给出了**可机器核对的形态**：「只把『当前图节点』里已有的节点当确定路标；你提议补的台阶/支线一律标注（候选），落图由教练生长批裁决」。于是「路对不对」有了一个零模型的粗判据——**条目引用到图面节点名，或自己声明是候选；两者皆无，就是被当作确定路标写出来、图面却无从核对的东西**。

## 裁决

### 1. 判据：条目三态，无锚即漂移

`compass.ts::reconcileRoute(routeBody, graphNames)` 逐条判三态：

- **有锚**：条目正文逐字引用到图面在册节点名（终点名也是节点，故引用终点即算锚）；
- **标候选**：条目自带「候选」标注——模板允许的未落图台阶，合法；
- **无锚**：两者皆无 = **漂移**（走 `unmoored`，证据 = 条目名）。

条目名提取三档回退：`- **阶段名**：…` 取粗体段 → 无粗体退回「行首标记后、第一个分隔符前」 → 再退回整行（对账只要一个可读的证据名，不做语义解析）。

**诚实边界**：只按名字粗比。「有锚」不证明路线正确，只证明它不是凭空写的；把「条目锚定图面节点名」做成更强的可核对形态属**候选发现**（票面边界），本票不做。

### 2. 挂载点：周复盘挂 ETA 的**同一处**顺带

`growth-subsystem.ts::compassEtaRefresh`（kataOpen 触发）逐启用课程本来就读了罗盘文本，顺带算对账、随行携带可选 `reconcile`；`kataOpen` 把它映射进现状区的 `### 罗盘对账` 小节。**对账在 ETA 标记周早退之前算**——ETA 有周幂等（同周不重算推演），对账没有：同周重复打开也要看得见漂移。

### 3. 呈现：一致一行结论、漂移告警 + 证据

小节只在**有已画路线**的课程上出现（未画路线 = 零小节 = 零噪音）：

- 一致 → 一行 terse 结论（`路线 N 条条目与图面一致（A 条有锚 · P 条标「（候选）」）`），**不列任何证据行**；
- 漂移 → 告警行点名证据条目名，并声明「路线是草图非权威：此处只告警，不改罗盘、不触发重画」。

措辞沿 ADR-0033/0025 的非承诺纪律——对账是**读数**，不产生新的权威面。

### 4. 边界

- **非权威不阻塞**：不改罗盘写权（唯一写口仍是 `compassRewrite`，调用方仍是生长批受理）、不进门禁（绿/红都不由它决定）、不触发重画（`learnhub_compass_paint` 仍纯手动）、零 canonical 写入、不写 journal。
- **不假装**：待初画占位**不是条目**——`hasPaintedRoute` 把它挡在门外（占位文案直接进对账会装成一个巨大的「漂移条目」，测试留了反向证据）；图面加载失败归 `skipped`，不挡 ETA；未播种课程与 ETA 同样 skip。
- **宽严取舍**：宁可漏报不误报——「候选」二字出现在条目任意位置即算候选标注；节点名以子串命中即算有锚（短节点名可能误锚，代价是漏报而不是噪音）。
- **不改产品契约**：`reconcile` 不出现在任何路由/命令/工具位（宿主与面板都不消费，唯一消费方是 `kataOpen`）——路由清单、探针快照、状态码、工具面、行为快照**全部零漂移**；周复盘文档新增的是 `### ` 级小节，不参与 `parseKataBody` 的 `## ` 段切分（现状段解析与四问读写不受影响）。
