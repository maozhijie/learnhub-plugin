# 图分组：不存储层级（纵向 depth + 横向派生可重叠）

`Region/Block` 是一套两级**存储式分区**，来自「全局生成图」时代（大纲式、先规划后填充）。在当前的「目标驱动的生长图」下它已没有位置，却仍在多个面上生效，并且**没有任何质量门**（区名/块名由教练自造、无人审）。它是**无主设计**：仓内没有任何 ADR 定义它，只有 `CONTEXT.md` 三行自承「概念上希望深度可变，工程当前固定两级……服务于生成，不是学习者感知的概念」。它与学习图的本性冲突——分区强制**单归属**（一个节点恰属一个块），而学习图（`pre` 前置 / `enc` 成分 / 概念引用）天生**多对多**（「导数」既属微积分又属优化）；且它**会腐**——存下来的划分图一长就没人重划，无维护回路，要么被遗忘、要么被绕过。本 ADR 把 #275 的裁决落成纸面。

## 裁决

**不存储任何层级；`Region/Block` 退役。** 分组的正确形态是「**读侧派生 + 可重叠**」，纵向与横向各取一个已有的派生轴：

- **纵向分层 = 已有的 `depth`**（拓扑深度；派生、随图重算、每节点恰一层）。**不新建纵向结构。** 环上 `depth` 作废——返回显式「无法分层」，不静默变空（照 #270 作废署名口径）。
- **横向归组 = 派生可重叠**，两个轴：
  - **概念轴**：成员 = `teaches ∪ assumes` 的并集（一个节点教多个概念 → 进多个组），复用已落地的反向索引（`Graph.taughtByOf` / `assumedByOf`，ADR-0085 / #270）；组名取概念登记表 **canonical**，别名经 `resolveConcept` 归并（否则一个概念裂成多个组）；题目 `invokes` 作为可选的第二轴。
  - **终点轴**：终点 → 服务它的节点（`serves` 形态的推广；落在 ≥2 个终点前置闭包内的节点 = 交汇），复用 `upstreamClosure`。
- **组名借自既有存储**（概念 canonical 名 / 终点节点名 / depth 段标签）——**不新增实体、不新增写词汇**。
- **图存储塌成单层**：一区一文件 → **一课程一文件**，扁平 `nodes[]`——存储层与「无层级」结论一致。
- **写侧词汇退场**：`EditOp` 删 `region`/`block`，`add_node` 不再要求坐标；`move`（语义 = 换分区）退场；残留 `region`/`block` 键与 `move` op 一律 fail loud 拒收。
- **嵌套暂不做**：触发判据 = **单层组数 > ~12 且每组仍过大**时，才派生第二级（派生、不存储）。

同一份节点于是得到四种切法：**深度分层 / 概念主题（重叠）/ 终点交汇 / 组列表**——**视图变多，结构变少**。

## 领域依据（证据表）

| 论断 | 来源 | 强度 |
|---|---|---|
| 学习结构 = 前沿关系，非分类 | KST（Doignon–Falmagne 1985，ALEKS 落地 2500 万） | 一手实证 |
| 分级分类五型；严格树（一节点一父）是最弱型；复杂多层级更适合面分类 | DAMA/DMBOK 分类法五型 | 教材共识 |
| 层级支持多父（多重层级 / 多路径） | W3C SKOS（2009）`broader/narrower` + §8.6.9 | 一手标准 |
| 动态分组随数据演化 | folksonomy / evolutionary taxonomy 文献 | 文献（二阶） |
| 静态层级 = 全局生成图遗留 | 课程知识图谱论文普遍保留「章→节→知识点」 | 反例 |

## 替代方案（否决）

- **保留 / 补建两级**——存储式单归属 = 分类法里最弱的形态，且无维护回路；区也造不出来（写通道无 `add_region`，全库只有一个区，写坐标退化，教练被迫填一个没意义的坐标还会幻觉出区名致整批失败）。
- **路径化**（可变深度）——可变深度但仍存、仍单归属，与多对多本性的冲突未解。

## 行为与门影响（分票落地）

- **写侧词表**（本 ADR 的直接行为面，T3 `#279`）：`EditOp` 去 `region`/`block`、去 `move`，`region`/`block` 进既有 `RETIRED_OP_KEYS`（fail loud）；`graph_propose` 工具描述串同步去坐标与 `move`；`learnhub-graph-optimize` SKILL 示例同步。
- **读侧视图**（`#281` / `#282` / `#283`）：`GraphDoc.nodes[].data` 去 `region`/`block`（保留 `depth`）；分析建议 `expand_blocks`→`expand_groups`、`unconverged`→`sparse_groups`、删 `merge_blocks`（「两个概念组高度重叠」让给 `#274`）；`graphBrowse` 按分组轴；UI 换轴 + 课程树 `课程→区→块→节点` 塌成 `课程→节点`。
- **提示词面**（`#282` 独占，含 `prompt-bump` 受管面）：`prompts/templates.ts` 的「区·块」图面读法段、硬约束 2 的「区/块名」、`add_node` 输出 schema 示例里的 `region`/`block`，以及 `prompts/projects.ts` 的 `COACH_GATE_FEEDBACK_BLOCK`（受理门回灌重裁段末句「区/块与节点名…逐字来自上方图面」——正是「坐标拒收→重裁」闭环里那段指导），一并归 `#282` 去掉（改生产行为，走章程 §8：同提交 bump 版本 + `PROMPT_CHANGELOG` + 两条过门）。**写侧引擎（本 ADR）先落、提示词面随后跟**——两者之间的窗口里教练回合会多跑一轮回灌重裁（可自愈，非硬停）。
- **存储塌缩**（`#284`）：`writeRegionDoc` → 单文件图写入原语；`Graph` 构造从 `regions` 改 `nodes`；schema 主版本 **3→4**（宣告式断裂，零迁移脚本）。
- **笔记路径**（`#280`）：`courseNotePath` 去 region 段（平铺 `课程/节点.md`）。
- **不得复活门**：`region`/`block` 键在图 YAML（T8 单图格式）与提案 op 两侧 fail loud——退场不会被后续改动悄悄推翻。
