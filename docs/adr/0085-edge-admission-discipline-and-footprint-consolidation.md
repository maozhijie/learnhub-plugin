# 边种与边属性的准入判据：边轻纪律成文 + 概念足迹收成一处

一条纪律在本仓**被执行却从未被定义**：`RETIRED_EDGE_KEYS`（`graph.ts`）与 `RETIRED_OP_KEYS`（`proposals.ts`）对 `origin` / `status` / `probation` 在图 YAML 与提案 op 两侧各设一道 fail loud 拒收，而「边轻纪律」在 `docs/` 里**没有一处给出判据**（只在 ADR-0077 被旁引一次）。本 ADR 把它成文（二分判据、三档逃生口、加边种准入判据），并落定概念足迹（今天**折叠散在多处**）的收拢形态。**只落文档**（本文件 + `CONTEXT.md` 两词条）；实现另开票。

**为什么成文（#127 欠账 + 一处理由更正）**：三字段被一并驱逐，但**理由其实各不相同**——`origin` **可派生**（有 `operator → 骨架/生长/修复` 映射）、`status` **跨源连接**（三值各有各的家）、`probation` **生命周期不同**（边删而记录须留、账本**即事实源**）；说成"不重复存储"等于**把事实源说成别人的副本**（**决定对、理由说错**）。而「origin 从 journal 派生」**零实现**——该词只出现在拒收文案／注释／工具描述里（实测九个 token、五个文件），**AI 会信、代码做不到**；干净的实例只有 `origin` 一个（addresser 接线并列已撤，ADR-0084）。**结构性风险（登记缺口，门另开票）**：**驱逐字段时没有任何门检查「替代派生是否真的存在」**（R1–R7 / G1–G9 与 `scan-*.mjs` 里都没有）——**驱逐**是一次性拒收（有门守），**替代派生**是要长期存在的实现（无人管）：**前者有门、后者裸奔**。

## 边属性二分判据（成文）

> **凡欲落在边上的属性，先在「声明」与「状态」之间二分：**
> - **声明（Declaration）**——**边的固有成分**、只写一次、不随生命周期演化、边消失即随之消失：住**边上**（图 YAML 内联）。实例：`enc.w`、`enc.note`。
> - **状态（State）**——**边在生命周期里的演化**、会被反复更新、且**边被删后记录仍须存活**：**不落边**。实例：`origin`、`status`、`probation`。

**两轴正交**：本判据答"落不落在边上"，「三种机制」答"不落边时去哪"（`probation` → **账本**、`status` → **跨源连接**、`origin` → **可派生**）——并成一句"不重复存储"正是要纠正的。**禁止把状态塞进边**：两道 fail loud 拒收即执法面。

## 三档逃生口（各带一个本仓既有实例）

**① 结构化状态 → 账本**（追加流水、不进图；实例＝**边实验账本** `state/边实验.jsonl`，复诊 `due`/`outcome`/`decided_at` 在账本、图 YAML 保持零边字段）；**② 非结构化说明 → 边上的自由文本**（轻微、只读、随边并存；实例＝`enc.note`）；**③ 统一适用的软硬判断 → 顶点上的布尔**（作用于一个节点与其**全部**前置边；实例＝`opt`）。**`opt` 的代价**：顶点布尔**广播**、粒度**塌到顶点级**，"对这个消费者可选、对彼必需"这类边级差异**表达不了**——它成立只因为那类判断在本仓**恰好是顶点级**；一旦出现边级差异，顶点布尔**不是**逃生口，而要重走准入判据的**新边属性**。

## 准入判据：加边种要有据

> **新增边种（或边属性）之前，必须先证明它"不可派生"**——即该信息**不在盘上**、且**无法由既有正典（图 YAML + 提案 journal + 账本 + 概念登记表）在需要时算出**。

**规则不是"永不加边种"，是"加边种要有据"。** 判据不成立的情形确实存在：**① 两节点相关但零共同概念**——该相关性**信息不在盘上**，只能作为**声明**落图；**② 边的置信度随时间演化**——它是**状态**，即使可算也只能进**账本**。首次自我适用见「裁定 2」。

## 裁定：概念足迹收拢

实测是**折叠散在多处**（概念反向 A 3 处 + 反向可达 B 4 处、其中 3 处 O(N) 扫描；`upstreamClosure` 自称"单一出处"而注释已记过"两处各写一遍 BFS"的旧教训），不是一等派生；题目侧**已收拢不动**（单实现 + providers 契约）。

1. **概念反向住 `Graph` 构造期、与正向并列**：`taughtByOf` / `assumedByOf`（概念 → 节点[]，按 `graph.names` 序 → 确定性）；**顺带完成**——`teachesOf` / `assumesOf` 本就在同一趟构造里。
2. **不做 `misconceptions` 反向**——今天无消费者；**没有消费者的不加**。**这是准入判据的第一次自我适用，必须记进本 ADR**，优先于"对称性好看"的直觉。
3. **`upstreamClosure` 独占反向可达**，B 的四处扫描改读它。依据：**集合恒等**（无环图上 `isAncestor(a,n) ≡ a ∈ upstreamClosure(n)\{n}`）+ **比较器全序**（`byDepthDesc` 无并列）→ **输出逐字不变**。**两处差异必须显式对待**：**有环时** `isAncestor` 恒 false 而 BFS 版仍走完全部可达前置（`seed.ts` 已按 `hasCycle` 分叉），故 `content.ts` 两处的环图读数**从空集恢复到真实可达集**（修复，但**行为确实变了**）；**有断边时** `upstreamClosure` 抛 `TypeError` 而扫描优雅降级——断边本是**显式容忍态**（`structureCheck` / audit E2 报断边），故收敛前**必须补 `nset` 守卫**，否则把今天不炸的扫描变成崩溃路径。**两处差异均须专门测试钉住。**
4. **统一在消费面、不在存储面**：节点侧 **eager**（数据在 `Graph` 手里）、题目侧 **lazy**（`loadView` **不含题目**，扫题库不免费，维持经 providers）；两面对外**一张脸**、**不建新模块**——题目粒度天然更大更贵，硬塞进一个 eager 存储面是"为了对称而付不值的代价"。

## 防复发门（必须有，否则会第四次散）

`upstreamClosure` 的注释写过一次教训——「口径一致靠注释，不靠代码」——随后**被违反三次**（三处 O(N) 扫描即证据，`seed.ts` 还内联了 BFS 副本）。故**要求加一条门**：**禁止在 `graph.names` 上"筛 + `isAncestor`"求祖先集，也禁止手写 `preOf` BFS 求闭包**（命中即报，指向 `Graph.upstreamClosure`）。实现随收拢票落地，按章程 §5 加门纪律（正反两向自检），阈值登记门册。

## 被拒方案

**节点与边分开存储（`nodes.yaml` + `edges.yaml`）——不采纳。** ① **逻辑上买不到卖点**：边轻纪律禁止的**恰是边上的状态**（`origin` 正是机制痕迹），拆完依然不能存；真正买到的是**边的双向可查**，而它住在**读层**（`Graph` 构造期物化反向映射，零 schema 改动）。② **制造双源**：`data/*.yaml` 今天是**唯一正典、人可读、git 可审**，拆开后从"不可能不一致"变成"必须维护一致"，写入单元的失败态从**孤儿条目（合法）**变成**断边（违约）**。③ **`opt` 与粒度**：边成一等行后顶点布尔可细化到边，代价是存量回填 + 1 条信息变 N 条，而那种边级差异**尚无消费者证明**。④ **可读性**：两级容器 `region → blocks → nodes` 同时是**分区**与**阅读结构**，拆开后读一个节点要跨文件（对 agent 亦然）。

**拆的判据**：（甲）边的**顶点类型不止一种**；（乙）边种 ≥3 且**形状异质**；（丙）边的集合需**独立审计 / 独立演化**。**「引用二分图」今天已满足（甲）**——左侧是**节点**与**题目**、右侧是**概念**，天然跨三个文件：**"数据图"不该拆，该收拢的是「引用二分图」**。其余不重开：不新增 `pre` / `enc` 之外的边种；不重开 #249（已关，本 ADR 只记录它留下的缝隙）。

## 边界

- **不动任何源码**（`Graph` 不加反向映射、折叠不收敛）——实现另票；**不做**任何存储层的拆分或合并。
- 不新增边种、不改 `pre` / `enc` 的 schema；不改概念登记表的身份语义与废弃态；不做「概念足迹」UI（#268）。
- **零代码、零行为变更**（不改路由／工具面／提示词／schema／磁盘格式），故不跑 `npm test` / `prompt-bump`（纯文档，与 #263 同款）；「防复发门」随实现票落地。取号 0085（0084 已占），票面 #267。

## 实现登记·补记（#270，2026-09-15）：收拢落地与环语义裁定

- **反向映射**已落：与正向同趟折出 `taughtByOf` / `assumedByOf`（names 序确定性）；`misconceptions` 反向继续不做（准入判据二次适用）。
- **守卫裁定**：`nset` 过滤 + `preOf[u] ?? []`——**悬空前置不入闭包、悬空名入参退化为 `{自身}`**（**闭包只认图内节点**）；`graphPath` 同口径补守卫（要**链**不要集合，G10 豁免）。
- **环语义裁定（选项 a）**：`isAncestor` 在环上也走闭包（退化为逐点 succ BFS，规模可接受），25+ 调用点保持 boolean 契约；**否决选项 b**（「环上作废」需全部调用点处理 void，改动面不成比例）；**`depth` / `edges` 保持环上作废**（`hasCycle` 旗标）。
- **作废署名「算不出」≠「没有」**：环上 `max_depth` / `unreachable` 取 `null`（不伪装成 0/[]）、健康分 `topology_void`、审计披露本轮不验 R1/R2/R4/R6、UI 深度标签「作废（图有环）」。
- **防复发门 G10**（`scripts/scan-closure.mjs`）：拦 names 筛 `isAncestor`（链式/for-of 两形态）与手写 `preOf` BFS，豁免原语之家与 `graphPath`。
