# v1→v2 断裂不蒸馏：存档只作考古，不建蒸馏桥

宣告式断裂（ADR-0034）原规划断裂时从存档机械蒸馏「沉淀引导档」，作为 v1→v2 的一次性桥、补偿卡级进度归零的已认账代价。本决议取消该桥（#151 不予修复）：v1→v2 这次断裂不做蒸馏，存档区（`学习中心/存档/pre-v1/2026-09-10/`）只作考古材料永久保留（只增不删），引擎不建任何蒸馏路径与消费路径；存档仍在，翻悔可随时复活蒸馏。

理由：桥的价值取决于存档里有什么。盘点真实存档（唯一一门 v1 数学课），六类沉淀事件的原料全部缺席——无 fsrs 参数文件（v1 参数文件已是缓存形态）、无行为流水（断裂时原地保留、未入存档）、无概念登记表（v1 时代无此物，蒸馏产物写不出合法概念地址，只能落零消费的 legacy 分区）；可机械蒸馏的仅剩审计报告、就绪清单与图形态（节点名清单），维护者裁决其参考价值不足以偿付建桥与长期 quarantine 的复杂度。沉淀层的两个结构保证（出生即写、读侧单向）不受影响——它们才是跨断裂连续性的载体；蒸馏桥只是 v1 这朝「出生即写尚不存在」的一次性补课，补课对象缺席则桥无意义。

代价：v1→v2 这次断裂的模型连续性补偿不发生——旧课的审计结论与图形态不进沉淀层，新图生长策略从零起步；ADR-0034「补偿只能走新图生长策略」在该次断裂上落空，是明码认账的代价加码，不是隐蔽背离。沉淀 legacy 分区保留为空收容位（只保留、零消费路径），不再有计划中的写入者；后续断裂零蒸馏（v2 起出生即沉淀）照 ADR-0034 原样成立。
