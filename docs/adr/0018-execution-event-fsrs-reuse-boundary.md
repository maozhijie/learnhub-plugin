# 执行事件调度通道：FSRS 数学复用边界

决议（#77，2026-09-09，需求池 U-2／总纲裁决 3 第②层的正式化；前置调研 #79）：FSRS 数学复用于执行事件成立，通道的本质是「映射通道」——调度内核与参数管线原样不动，唯一新增件是「执行表现 → 1-4 评级」的入口契约。裁决细目：

1. **词条与事件域三分**：「技能条目」（Skill Entry）、「执行事件」（Execution Event）入 CONTEXT.md，随本决议落库（ADR-0015 预留的「执行事件」词条位在此兑现）。事件域三分：执行事件=调度语义（真实执行+表现评级，推调度 lane，独立成流）；回执=证据语义（进 EMA，永不推 lane——ADR-0016 原样成立，挂哪个载体都一样）；习惯重复=无事件语义（ADR-0017）。一次实践活动可同时产生执行事件与回执，各记各的；执行事件可引用回执材料作证据附件。
2. **载体与传播**：FSRS lane v1 只挂技能条目（无界区可排期的实践主体）；与题目 FSRS 并行，不复用题目卡、不进复习队列。项目执行事件只喂渐退档移动与 2×2 诊断（ADR-0015），不跨载体传播给技能条目；项目↔技能条目关联留后续票。
3. **入口契约（通道管到哪一层）**：通道只定入口——事件必须携带 (rating: 1-4 整数, 来源枚举 auto/self/ai)，复用 ADR-0006 的评分分离纪律与 `rating_source` 先例；映射函数归各生产者。仓库推荐默认=可观测执行证据（准确率/耗时/自主求助次数）的确定性映射，不收主观自由分；无判据可测时退化为学习者自评档。**分数直喂禁止**：ts-fsrs 的 Hard/Easy 乘子按枚举精确判等，[1,4] 内分数会静默丢失乘子（契约外行为，优化器侧更是硬性整数）；**`next_state` 的 r 外部注入不采用**——「表现差但完成了→低 r」是语义错位，登记为备选、不推荐。
4. **参数沿用与混训重拟**：21 个 w 全部沿用、语义不变，无废弃、无重定义；「衰减模型重新拟合」= 执行事件过 ≥400 条门禁后放行进 `trainingSequences` 与题目事件混训；现行「写回门禁 + in-sample 新旧参对照」即污染绊线，题目侧对照劣化再拆参数集（升级路径，非起步配置）。调度内核零改动：复用 `applyRatingBlock` / `map.rating` 调用面模式。
5. **单调性阶梯**：FSRS-6 幂律 R(0)=1 且对 t 单调，表达不了运动技能间隔期主动增强（Walker 2002/2005）。v1 = 评级映射吸收 + 日粒度缓冲（`enable_short_term=false` 同构；≤24-48h 巩固窗内执行事件只记账、不推进 FSRS 状态）。数据触发后置：曲线族替换（触发面 = memory.ts 按时点遗忘曲线 ≤2 天桶出现超基线保留；真代价在优化器侧——fsrs-rs 只拟合标准曲线，须自建拟合）；换保持模型族（独立调度器）只作「第②层最终是否留在 FSRS 数学里」的远期复核备选。亚日粒度执行调度不做（反需求清单「亚秒级并发反馈引擎」的近邻）。
6. **维持性复活**：lane 内 due 驱动 + 维持节拍上限——技能条目可设维持上限（默认 30 天，可关可调），到期即到、不被间隔增长淹没（Arthur 1998：停用技能 d 滑至 -1.4，对久置运动技能保持低频接触本身有价值，不取决于预测保留率）；「迷你重做+回放」是 due 到时会话的内容形态；维持事件与习得事件靠事件种类字段在流水可区分（#89 验收项）。无独立维持调度器。
7. **不碰**：账本问题（执行时长是否入 XP）不在本裁决，另票裁决；技能条目无 mastery、不进题目门禁。

为什么是「入口契约」而不是更紧的控制：映射的保真度无文献背书（FSRS rating 语义=回忆努力度，执行表现与之不同构），任何映射都是工程近似——把映射下放给掌握判据的生产者、只锁死 1-4 整数与来源诚实登记，是把不确定性放在能观测它的位置。同批被拒：分数直喂（契约外静默行为）；中央统一映射表（生产者天然异构：迷你重做可自动判分、自由练习只能自评）；自评唯一来源（丢弃可观测判据）；起步即分参数集（两套数据各自更难过 ≥400 门禁，冷启动双盲）；起步换曲线族（优化器断链，自建拟合是大头代价）；纯 due 驱动的维持（间隔推到年级，「维持」形同注销）；独立维持调度器（新子系统，违背 U-2「其特例」定位）。

已知限制：1-4 映射的偏差方向未测，需在真保留率/校准曲线上常设观测（复用 ADR-0012 仪表面）；优化器 binding（public beta）已被 optimize.ts 隔离层对冲，升级面随 ts-fsrs 6.0 另查。

工程影响（供执行票消费，非本决议约束）：落盘复用 ReviewRec 结构、`rating_source` 扩 `'execution'` 或建并行执行日志，由「交付：执行事件调度通道」（#89）定；技能条目的实体形态（创建入口、状态落点、面板视图）归该票；「裁决：执行事件是否记 XP」另票开口。
