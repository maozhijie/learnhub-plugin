# 终点性单源派生与生长方向不变式

生长式图（ADR-0033）把课程唯一的结构承诺收缩进终点锚——锚是承诺，锚所锚定的终点节点是图上位置。但终点节点本体是普通 GNode：schema 层无类型（`NODE_TYPES` 只认 `practice`）、读侧无标记、UI 无样式，全部消费面把它当普通节点对待。实机证据（「数学」课，2026-09-13）：终点已生成正文而真实坡道未成；生长 12+ 节点无一汇入终点闭包——`endpoint.pre` 仍是种子三起点、深度恒 1；教练还长出了以终点为 pre 的「综述」节点，承诺物被当成前置，目标被长过。同型病灶在代码里处处可复发：生成链对终点零校验、T1/T2 触发器按陈旧的 `pre = starts` 把终点当普通后继写进待生成清单、前瞻深度需求侧剔终点而存量侧不剔（终点一旦有正文就虚增就绪存量，教练可误判停摆）、审计 R1 把终点当浅叶子告警、`contextPack` 把任何无后继节点误标「终点节点」。

理由：终点性的正确出处只有一个——锚。放进 schema（`NODE_TYPES` 加 `'endpoint'`）是第二事实源：reseed 换终点要多一处同步点，消费面读字段即可绕开锚去理解「终点是什么」。把终点摘出图（虚拟节点）更不可行：完成判据读终点 mastery，而 mastery、FSRS 卡与练习证据都要挂在真实节点上。所以方向反过来：节点保持普通，一切消费面在读取时从锚现算终点性——特殊性不存储、不落盘、不可能漂移；同时把「朝终点长」从罗盘散文升级为受理门的结构事实，因为提示词软约束已被实机证伪。

关键裁决：

- **终点性单源派生（读侧 isEndpoint）。** 分析载荷、GraphDoc、UI 图面、教练图面与教练上下文包全部读锚派生终点标记，恒标终点——轻量回合也带（一行名字的 token 代价，换裁决不盲；现状轻量段连终点锚区块都不注入）。`contextPack` 的「（无后继，终点节点）」结构启发式废除，改读锚。
- **方向不变式进受理门。** 三句：① 任何 `add_node` 以终点为 pre 直接拒——目标之后不是本课程的生长域，扩承诺走 reseed；② 主线批（前进/换向）含新节点时，ops 必须含 `set_pre { node: 终点, pre: 批内新前沿 }`——**替换**语义，真实坡道取代种子粗边，不给终点留直通起点的跳级边；终点深度随主线生长，完成判据的闭包健康自然覆盖真实坡道；③ **收尾接线批**——课程允许停止生长：教练裁决「既有节点已满足终点要求」时停摆照旧合法（前瞻深度 exhausted 判据不动），但若终点.pre 尚未指向其认定的最终台阶，须先出一条零 add_node 的纯 `set_pre` 接线批再停摆——把「我觉得够了」落成结构事实，而非留在罗盘散文里。违反走 ADR-0050 回灌重裁。
- **生成门。** 终点与普通节点同规则：进入学习前沿（前置闭包达标）才解锁正文生成入口，手动与自动同认这把锁；T1/T2 待生成清单不再登记终点；前瞻深度**教练账双侧**剔终点（需求侧已剔，存量侧 `readySet` 补上），学习者就绪与推荐照常含终点——终点照常被学，只是不再被提前产料、不再冒充就绪存量。
- **口径豁免。** 审计 R1「浅叶子」豁免终点（设计上的终点不是缺陷叶子）；`stats.leaves` 与健康分的 leaves/floats 分母剔除终点；`max_depth` 保留终点且正名为主线深度——不变式落地后它从「恒 1 的死数」变成「课程长到哪里」的进度读数。

边界：

- **不追溯清档**：存量已生成的终点正文保留，生成门只约束未来的生成动作。
- **旁支/巩固/插入豁免接线义务**：它们是症状驱动的合法离线产物（插入靠复诊自灭），不强行汇入终点闭包；不变式只管主线。
- 锚保护既有范围不变（`del_node`/`rename` 照拦），方向门是新增检查，不改既有门清单语义。
- 快速迭代期的存量歪接线（「数学」课三病俱全：陈旧终点.pre、离线 blob、长过目标的综述节点）不做专门对账提案，留作异常态恢复路径的实测样本。

替代方案（否决）：

- **schema 加 `type: 'endpoint'`**——第二事实源；reseed 换终点要多一处同步，且给了消费面绕开锚理解终点的通道。
- **虚拟节点（终点不入图）**——完成判据与 mastery/卡/练习证据域整体重写，为模型洁癖付重写税。
- **教练提示词软约束（现状）**——「前进：沿终点方向给当前前沿补下一步台阶」早已写在提示词里，实机图照样长歪；判断必须落成结构事实。
- **引擎 apply 后自动接线**——违反「在图即断言」的边纪律：哪些节点构成达标的最后台阶是教练的裁决，引擎伪造 pre 边等于替教练裁决。
