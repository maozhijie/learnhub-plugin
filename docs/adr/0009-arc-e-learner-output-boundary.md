# Arc E 学习者产出边界：过程资产与复习对象，不进 Mastery/XP/FSRS

决议（#33，2026-09-08，决策先行项 3）：Arc E 的学习者产出（自注解释、自造卡、讲解稿、JOL 预测、目标偏好）领域语义定稿为**过程资产与复习对象**——它们是学习机制（自解释/费曼/生成效应），不是掌握度测量证据。三不进：不进 Mastery（`frontmatter` 的 mastery/practice_ema/fsrs 及其聚合）、不进 XP 账本（产出零 XP，含 E2 讲解等真实专注——宁可账本低估，保持「XP 只走节点定价 Settle + 既有作答流水」单一口径）、不推进 canonical FSRS（不写节点代表卡与 master 题库卡的任何调度/统计字段，不参与 R gate / 复习队列 / 完成门禁）。产出只活在 E 独立命名空间：档案本体（含 AI 是非反馈判词存档）、E 池内自注/自造卡的**隔离自调度**（复习对象按自己的节奏重见、永不汇入 canonical）、`PracticeRec.predicted` 元标注（JOL 作答前预测）、E3 目标/计划偏好（只覆盖推荐读侧）、E 池派生统计视图（产出次数/时长、校准曲线）。

为什么不能入掌握度——理由不是「过程资产不配」，而是**证据校准性**：Mastery 是读侧测量仪表，必须由经图管线审计、有可判键的证据驱动（稳定度 + 练习 EMA）；产出物与节点的关联未校准（自造卡易打偏考点，Myers 2024），直接入账会「误校准比欠校准更糟」（虚高 → 错误放行）。但这不等于开放产出没有外部判据：**边界要求开放产出必得 LLM 是非反馈**（对/错/部分对 + 偏离定位，对照该节点已教要点），供学习者自校准与 E4 校准曲线使用；判词只入 E 档案、不产生 XP、不写 canonical 任何字段。未来若产出能成为「经审计的节点开放题」或经 rubric 可靠性验证的对照评分通道，才有资格升格为练习证据——需单独决议，不作静默放行（记入地图 Not yet specified）。
