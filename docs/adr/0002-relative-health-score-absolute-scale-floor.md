# 健康分保持纯相对指标，绝对规模走独立规模底线

> **状态（2026-09-11）**：本决策的「规模底线（Scale Floor）」半区已随 #138 cutover 被 [ADR-0033](0033-grown-graph-replaces-one-shot.md) 取代——生长式图没有 scope 阶段与交付规模门槛，完成判据按目标类型二分（能力/覆盖锚定）；「健康分保持纯相对指标」的裁决仍然有效。

健康分五项（动作句、est 覆盖、前置完备、收敛度、结构卫生）全是相对/比例指标，小图也能拿满分，「健康分 ≥80 就收工」因此成为可博弈的提前收工通道（MathToDev 184 节点、61/65 块不足 5 节点即为例证）。决定：不把绝对节点数并入健康分公式——相对分保持跨课可比，也避免生成器为凑规模而稀释节点定义；规模改为独立门槛：scope 阶段宣布目标节点区间（Scale Floor），analyze 对照输出缺口，技能结束条件追加「规模达标」。被拒方案：健康分加第六维规模——一个分数混两种量纲，公式与权重都要重配，且无法表达「区间」语义。
