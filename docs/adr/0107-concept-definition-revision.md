# 概念 definition 跨课程修订权：人审直动作，提请挂首引、能力通用

登记表契约从 v0.x 起从未裁决 definition 的修订权：写侧只有铸名写入与并入缺省承继两条入路——「条目在册语义以先到者为准」只说了先到优先，「补定义走人审」没说人审拿什么动作去补。概念跨课程化（ADR-0089）后这是真裂缝：「对称」数学课先铸、音乐课后引，数学课写下的定义切片随四处判据呈现跨课泄漏——撞名底细、跨课首引复核提示、合并候选的名面匹配（definition 参与文本相似度）、教练只读工具。第二学科发现定义不合用时，引擎无通道表达「定义偏了」，人也没有修订动作，唯一出路竟是废弃+重铸。#341 拾起裁决。

## 裁决

1. **definition 可修订，修订权归人审直动作**（同废弃标记/正名规格）：一个纯函数（与 `mergeConceptEntries` 同层同规格：地址精确解析、目标不在册即错误不落盘、失败抛错登记表保持原样）+ 注册表执行面 + 一次 save。修订是新值整体替换旧值；AI 不得自行改在册定义，提议沿用 `note.reason` 一句话先例（同正名）。
2. **修订语义是条目级、全库生效**：definition 是「这个概念是什么」的判据面，不是某课程的视角切片。第二学科发现不合用即可修订，不存在「只有先铸学科有权定义」。真·同名异实（两个学科指的就不是一物）不是 definition 修订问题——那是地址问题，走消歧名分立（ADR-0089 裁决 4 更正），修订不越权改地址。
3. **「改定义毁第一学科生成」不成立**：概念引用恒精确匹配名字地址、永不模糊匹配，已生成的图/题目/沉淀按地址书写，定义文本变化不动任何既有引用；definition 只进判据呈现与候选派生的读侧面，既不参与身份（身份=条目）也不参与调度。第一学科存量产物零波及。
4. **修订提请的呈现挂跨课首引复核提示①段**：首引时刻是全系统唯一「判据在场」的时刻（ADR-0089 裁决 8 同一理由），定义不合用应当场能提请——在①段语义现状之后附修订提请出口（非阻，不进 errors；具体文案归实现票）。引擎能力通用不限现场：修订执行面是注册表通用动作，不与首引场景绑死。
5. **否决「不可修订——废弃+重铸」**：重铸丢足迹、别名、易混对等沉淀，历史地址永久污染——铸名原子性纪律（#341 A）赖以成立的正是这条可逆性不对称。definition 不动身份与地址、不删条目，修正在可逆性谱系的最轻端，拿废弃+重铸这支最重的刑具罚最轻的过错不成比例（旧值是否留痕及形态归实现票）。
6. **否决「AI 提案修订」（新提案 kind）**：定义语义判断归人，同 ADR-0089 裁决 4/9 的人审口径；一句话提请 + 人审直动作已覆盖回路。新提案 kind 属于 ADR-0089「明确不做」清单第①条明文不做的形态（AI 无提案权的合理场景不因字段换了一个而改变）。

## 影响

- **实现另票**：本票只裁修订权与呈现位置；执行面（工具/路由）与 provenance 形态落地时再裁。「执行面先备、面板接面另票」口径沿 ADR-0089（`recanonicalize` 先例）。
- 泄漏面四路自动受益：修订后的定义随读侧派生即时生效，零迁移、零快照。
- 本票纯裁决零代码；redefine 落地票按章补门册行为登记。
