# N-of-1 实验：单主体内随机化，只动内容参数不动调度核心

决议（#73 Not-yet-specified 收口，2026-09-09，grill 会话）：D-1 n-of-1 实验引擎的实验设计与统计口径落定为**主体内随机化的自我实验通道**——N-of-1 实验（N-of-1 Experiment）入 CONTEXT.md，定义性特征=在单一学习者身上把同一批合格对象（卡/节点/会话）随机分臂、用其真实学习结果测干预效应。人群效应对个体不可信（Czyż 2024：CI 保持实验室 SMD 0.92 vs 现场 0.23 不显著）正是它存在的理由；仪器已备（逐次复习日志 ADR-0012 + 真实保留率）。裁决细目：

1. **实验变量白名单（红线）**：只允许动引擎可控的**内容/课程设计参数**——PS-I 顺序（C-2）、检索点位置与密度（P-3）、CI 编排、难度带默认值、复习会话组成。调度核心（FSRS 转移、推进门、XP 账本语义）永不作实验变量：canonical 事实源不是赌注，拿它做实验等于拿账本做赌注。
2. **随机化**：v1 只做**卡级随机化**（同一批合格卡随机分臂；卡=交换单位，与 FSRS 逐卡调度天然兼容，统计上最干净）；会话/节点级参数退到批次交替。不建 ABAB/洗脱期等序列设计。
3. **统计口径**：主结局**预登记**（调度侧干预=真实保留率，练习侧=EMA）；分析=臂间比较+置换检验+效应量区间；报告用直白话（「检索点前置，你的真实保留率高 N 个点」）；不做序贯监控；最短观察窗=每臂 ≥N 次真实推进（N 随交付票定）；实验开停手动。
4. **启动通道**：提案-确认制——v1 从预置实验模板库发起，引擎按当前数据推荐合格卡池与参数，学习者逐项确认后开跑；不自动侦测「值得实验的异质性」（观察面先行，出现真实信号再议）。沿用「提议非指令」通则。
5. **数据边界**：臂标注进复习日志（实验条件是一等数据，留痕供归因）；零 XP（实验是条件重排，不新增专注）；不进 Mastery/任何 canonical 度量；FSRS 参数优化器默认混训不特判（过滤留给未来，标注已在）。

同批被拒：调度参数作实验变量（canonical 赌注）；日级 ABAB 交替（样本效率低且与学习日口径纠缠）；自动异质性侦测驱动实验立项（无观察面前提）；人群式 p 值显著性报告（单主体语境效应量+区间更诚实）。

工程影响（供执行票消费，非本决议约束）：复习日志的实验标注字段与模板库 schema 由交付票定；实验模板 v1 先收录已上线参数（难度带默认、会话组成），PS-I/检索点模板随各自交付票解锁。
