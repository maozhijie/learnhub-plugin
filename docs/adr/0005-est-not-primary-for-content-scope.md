# est 不作内容规模主信号：复杂度档案（difficulty × bloom × 前置规模）接管生成预算

图谱实测（2026-09 audit，280 节点）显示 est 是"档位感常数"：10–35 分钟无离散、与 difficulty 相关 0.52 却与图深度仅 0.365，按它推导节段数会让简单节点膨胀、复杂节点展不开。决定：内容生成（节段数区间、篇幅预算、题量、模型 effort）改由 `complexityTier` 折叠 difficulty × bloom × 前置闭包规模为低/中/高三档后锚定，est 降级为容量上界（≤30 分钟约定）并在 difficulty 缺失时作回退信号，不再进入分档。它是可逆的工程取舍：若 est 标注纪律恢复区分度（健康分"分布压缩"项）且实证支持，可重新引入 est 作修正因子，届时只需改折叠函数与锚点表，不需动 prompt v6 文本之外的结构。
