## 0. 一句话

项目产物不是一节课，是一张**任务卡**：复用课程生成管线的机械（清单校验→逐次生成→质检→修复一轮→落盘），不复用其节段类型菜单；里程碑计划是项目的大纲位，里程碑产物是节位，产物内部结构固定四块，档位只改配比。

## 1. 工作区文件布局（对齐 V-5 约定）

```
学习中心/projects/<id>/
├── 项目.md              # 身份与计划：frontmatter 承载下述 schema
└── milestones/
    ├── 01-<slug>.md     # 里程碑产物（四块固定结构，单文件单次生成）
    └── 02-<slug>.md
```

`项目.md` frontmatter 关键域：`id`、`name`、`lifecycle`（active/paused/delivered/archived，ADR-0015）、`tier`（骨架/补全/独立，项目属性）、`goal`（学习者目标描述原文）、`plan`（里程碑计划 YAML，见 §3）、`created/updated`。

## 2. 里程碑产物：固定四块模板

每个里程碑一个文件，**单次生成**（不走逐节循环）。六类课程节段菜单（概念/例题/演示/小结/练习/交互）不进项目域；产物内部结构固定：

```markdown
## 给定
（预置/已完成部分 + 情境起点。骨架档=近完整示范路径+分步说明；
  补全档=部分成品+【待补全】缺口显式标注；独立档=只给情境与起点，不含解法路径）
## 待办
（学习者要做的事：有序步骤或自由任务描述，动词开头）
## 验收清单
- [ ] 行为句条目（可自核对；档位越高粒度越细——骨架档每步一条，独立档只留达标标准）
## 支持
（即时信息：执行规则/提示/常见坑。骨架档最厚；独立档退化为自查提示）
```

四块即 4C/ID completion task 的产品化：`给定`×档位 = 预置部分的渐退；`支持` = just-in-time information（随熟练度渐退）；验收清单 = 常规任务的达标口径。

## 3. 里程碑计划：项目的大纲位

- **输入 v1**：学习者目标项目描述（prose）。Vault 先验注入（V-2/#95）后置，不进本设计。
- **产出**：`plan` YAML 数组落 `项目.md` frontmatter——每项 `{ id, name, task_class（简→繁梯度描述）, acceptance_hints（验收要点草案） }`。这是 #92（Proposal 泛化）与 #95（目标反编译）共同依赖的关键接口：反编译产出的就是同一结构。
- **粒度引导**（提示词约束）：每里程碑=一个可交付检查点，1–2 周粒度，全项目 3–8 个；任务类由模型按内容排简→繁梯度。
- 渐退档是**项目属性**（ADR-0015），计划不写 per-里程碑档位；生成产物时读项目当前档。

## 4. 三档配比与档位移动作用域

| 块 | 骨架 | 补全（主战场） | 独立 |
|---|---|---|---|
| 给定 | 近完整示范+分步说明 | 部分成品+缺口标注 | 情境与起点（无路径） |
| 待办 | 照做复现 | 补全缺口 | 全自主规划执行 |
| 验收清单 | 每步一条（最细） | 覆盖缺口 | 达标标准（最粗） |
| 支持 | 执行规则全量 | 关键提示 | 自查提示/常见坑 |

**档位移动不回溯**：已生成里程碑产物保持原档；新档位作用于后续里程碑生成。已生成者可显式「按新档重生成」——走带快照的提案通道，不静默覆盖（档位移动判据=档内表现、引擎提议学习者可改，归 ADR-0015/执行事件流，不在本设计）。

## 5. 过点语义与门禁隔离

- 验收清单勾选 = 学习者自报（ADR-0016「自报即证据」同精神），**勾选本身不是门禁**；允许带未勾条目过点（Kulik 1990 完成率警戒：项目区不设题目门，也不设清单门）。
- 里程碑完成 = 学习者显式「过点」动作（面板发起）；引擎可在清单全勾时**提议**过点，不代按。过点动作落 journal 流水，对账定价归 #94（journal 新 kind，对齐 `xp_settle` 先例——本设计只锁「过点是显式动作」）。
- 项目域全体零 XP、零 FSRS、不进 sessions/srs；项目文件不进课程复习队列（项目日志注册复习源属 V-5，后置执行；工作区布局预留 `日志.md` 位置，不强制建文件）。

## 6. 质检与提示词

- **轻量结构机检**（替代课程域渲染/题目门）：四块齐全；验收清单条目=行为句（动词开头、可核对）；无题目泄漏（不出题）；档位一致性（骨架/补全档「给定」非空且含路径性成分，独立档「给定」不含解法路径）。生成→质检→修复一轮的循环机械照旧复用。
- **提示词模板**两份进 PROMPT_KINDS 家族：`项目里程碑计划`、`项目里程碑产物`（用户可编辑 + 快照语义同现有）。风格变体（苏格拉底/费曼）对项目产物不适用，走默认路径。
